# 시뮬 온보딩 안내 + 허브 무료 표기 — 구현 플랜

> **For agentic workers:** 인라인 실행(executing-plans). Steps use `- [ ]`.

**Goal:** 시뮬 상황 선택 화면에 "이게 뭐야?" 안내 칩(고도화 가이드)을 넣고, 허브 상품 목록에 무료 배지(연애상담 정적 · 시뮬 동적)를 붙인다.

**Architecture:** 순수 프론트. 배지 라벨은 순수 헬퍼로 분리(TDD). 시뮬 배지는 기존 `GET /sim/quote` 를 허브가 상대별 1회 호출해 공급. 라우트/DB/마이그레이션 0.

**Tech:** Next 16, React 19, TS strict, Tailwind v4, node:test.

**Spec:** `docs/superpowers/specs/2026-08-14-시뮬-온보딩-무료표기-design.md`

- [ ] **Step 3: 구현** — `lib/relationship/sim.ts` 하단에 추가:

```ts
/** 허브 시뮬 카드의 무료 배지 라벨(쿼트 기반). 쿼트 없으면(로딩/실패) null → 배지 생략. */
export function simFreeBadge(
  q: { funding: "runway" | "hook" | "paid"; cost: number; runwayRemaining: number } | null
): string | null {
  if (!q) return null;
  if (q.funding === "runway") return `무료 ${q.runwayRemaining}판 남음`;
  if (q.funding === "hook") return "이번 주 무료 판";
  return `판당 ${q.cost}별`;
}
```

- [ ] **Step 4: 통과 확인** — 위 명령 → PASS(기존 포함).
- [ ] **Step 5: 커밋** — `git add lib/relationship/sim.ts lib/relationship/sim.test.ts && git commit -m "feat(sim): 허브 무료 배지 라벨 헬퍼 (TDD)"`

- [ ] **Step 1: 쿼트 state** — 다른 state 근처에 추가:

```tsx
const [simQuote, setSimQuote] = useState<{ funding: "runway" | "hook" | "paid"; cost: number; runwayRemaining: number } | null>(null);
```

- [ ] **Step 2: selected 변경 시 쿼트 fetch** — `selected`/`selectedRel` 파생 근처에 useEffect 추가(실제 사람일 때만, `me`/미선택이면 null):

```tsx
useEffect(() => {
  if (!selectedRel || selected === "me") { setSimQuote(null); return; }
  let alive = true;
  setSimQuote(null);
  fetch(`/api/relationship/sim/quote?relationshipId=${selected}`, { cache: "no-store" })
    .then((r) => (r.ok ? r.json() : null))
    .then((q) => { if (alive && q && typeof q.cost === "number") setSimQuote(q); })
    .catch(() => {});
  return () => { alive = false; };
}, [selected, selectedRel]);
```
(⚠️ `selected`·`selectedRel` 의 실제 변수명/타입을 현재 파일에서 확인해 맞출 것. `selectedRel` 은 line ~256 파생.)
