## 7. 관측 규율

1. **베이스라인 7일 · 판정 7일 = 총 14일 동안 광고 예산·소재·가격 무변경.** 어기면 판정이 통째로 무효다 (2026-07-31 에 광고 배급 붕괴로 사이클 하나를 통째 버린 전례).
2. **재방문은 퍼센트가 아니라 실인원으로 읽는다** (분자가 1~3명).
3. **날짜 버킷은 KST 자정.** SQL 은 `(created_at at time zone 'UTC' + interval '9 hours')::date` — `at time zone 'UTC'` 생략 금지.
4. **어드민 숫자가 의심되면 raw SQL 로 대조** (`scripts/run-prod-query.mjs`, read_only).
5. `ad_spend` 는 **같은 날짜를 다시 입력하면 새 행이 생긴다**(UNIQUE 키에 자유텍스트 3개 포함). 입력 후 반드시 중복 확인.
