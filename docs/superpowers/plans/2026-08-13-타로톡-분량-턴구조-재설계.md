> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 타로톡 전체 대화 분량(첫풀이+후속)을 유료 별 가격에 정합시킨다 — 첫풀이 분량은 유지하고, nudge 시점(turn)·chars 게이트·톤·절단을 luna 실측 기반으로 재조정.

**Tech Stack:** Next 16 · chat 모델=`gpt-5.6-luna`(OpenAI 어댑터, `CHAT_MODEL`) · QA 하네스 `npm run qa`(dev 서버 필수, `QA_CHAT_MODEL` 미설정 시 luna) · 프로브 `npx tsx`(standalone, dev 재시작 불필요) · 테스트 `node --import tsx --test`.
