# 앱 화면 손보기 2단계 — 시트 공통 틀 + 알림 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 아래에서 올라오는 시트(`Sheet`)와 가운데 확인창(`Dialog`)의 공통 틀을 만들고, 알림 쪽 겹창 4개를 그 틀로 옮긴다.

**Architecture:**
- 겹창 쌓기·스크롤 잠금·끌어내리기 판정은 순수 모듈 `lib/app-shell/overlay-stack.ts` 에 둔다. 이 모듈을 테스트로 잠근다.
- `components/common/Sheet.tsx` 와 `Dialog.tsx` 는 이 모듈 위에 얹힌 껍데기다. 포털·뒤 배경·닫기 요청을 맡는다.
- 앱 전용 꾸밈(손잡이·올라오기/내려가기·끌어내리기)은 `html[data-app]` CSS 와 `useAppInfo` 로만 붙인다. 웹은 지금 모양 그대로다.

**Tech Stack:** Next.js 16 · React 19 · Tailwind v4 · node:test

**Spec:** `docs/superpowers/specs/2026-11-07-앱-화면-design.md` §8(공통 시트 틀) · §11(단계) — 2단계 = "§8 Sheet·Dialog · RevisitSheet · 알림 설정 화면"

## Global Constraints

- **웹(브라우저) 모양:** 지금과 같아야 한다. 끌어내리기·손잡이 없이 그린다. 앱 전용 꾸밈은 `app-only` 또는 `useAppInfo` 로만 붙인다(§8 "둘 다").
- **앱↔웹 메시지는 4단계 몫이다.** `ui.overlay`·`ui.back`(§7)은 이번에 보내거나 받지 않는다. 그래도 4단계가 바로 쓸 수 있게 스택에 "맨 위 하나 닫기" 함수를 만들어 둔다(§11 표: 메시지·`caps` 에 `ui` 는 4단계).
- **Dialog 모양:** 지금 확인창들 그대로 둔다. 여는 법과 닫는 법만 통일한다(§8).
- **칩·버튼·글자 꾸밈은 고치지 않는다.** 그건 다음 일(전체 디자인 다듬기)이다. 알림 시안은 그때까지 임시 정답이다(§8 알림 화면).
- **아이폰 움직임 값:** 화면 전환과 같은 곡선 `cubic-bezier(0.32, 0.72, 0, 1)` 을 쓴다(2026-11-08 실기기 확정).
- **반복 규칙:** 테스트는 `node --import tsx --test …`. 패키지 설치 금지. 커밋은 `git commit -F <파일> -- <경로>`. 공개 저장소라 키·풀 UUID·사업 숫자를 쓰지 않는다. 운영 배포 없음 — 다음 운영 배포는 앱 출시 때다.

## 정해 둔 것 (스펙이 비워 둔 값)

| 항목 | 값 | 이유 |

## Review Focus

- **겹창 위 겹창**(PushAskSheet 가 열린 채 결과 통지가 뜸): 위 창을 닫아도 스크롤 잠금은 남아야 하고, 마지막 창이 닫힐 때만 풀린다 → Task 1 테스트 "잠금은 마지막이 풀릴 때만"
- **닫는 함수 없이 사라지는 창**(동의 성공 뒤 부모가 시트를 바로 지움): 스택·스크롤 잠금이 남으면 화면 스크롤이 영영 막힌다 → Task 1 테스트 "제거는 두 번 불러도 한 번만" + Task 2 Step "언마운트 정리"
- **닫기를 두 번**(나중에 연타, 바깥 누르기 + 끌어내리기 동시): `onClose` 는 한 번만 불린다 → Task 1 `onceClose` 테스트
- **웹 모양:** 손잡이·미끄러짐이 보이면 안 된다 → Task 4 웹 모드 전후 스크린샷
- **움직임 줄이기 설정(prefers-reduced-motion):** 미끄러짐 없이 바로 열리고 닫힌다 → Task 2 CSS + Task 4 확인

### Task 1: 겹창 스택·스크롤 잠금·끌어내리기 판정 (순수)

**Files:**
- Create: `lib/app-shell/overlay-stack.ts`
- Test: `lib/app-shell/overlay-stack.test.ts`

**Interfaces:**
- Produces:
  - `createOverlayStack(setLocked: (locked: boolean) => void): { push(close: () => void): () => void; closeTop(): boolean; size(): number }`
    - `push` 는 맨 위에 올리고, 제거 함수를 돌려준다. 제거 함수는 두 번 불러도 한 번만 동작한다.
    - `closeTop` 은 맨 위 `close` 를 부르고 true 를 돌려준다. 비었으면 false.
    - `setLocked(true)` 는 0→1 일 때만, `setLocked(false)` 는 1→0 일 때만 부른다.
  - `overlayStack` — 문서용 기본 인스턴스. `setLocked` 가 `document.documentElement` 와 `body` 의 `overflow` 를 `hidden` 으로 바꾸거나 원래대로 돌린다.
  - `shouldDismissSheet(dy: number, velocity: number): boolean` — 위 표의 120px / (24px·0.6px/ms) 규칙
  - `onceClose(fn: () => void): () => void` — 처음 한 번만 부른다

- [ ] **Step 1: 실패하는 테스트**

```ts
test("맨 위부터 닫는다 — closeTop 은 마지막에 올린 것만", () => {
  const s = createOverlayStack(() => {}); const log: string[] = [];
  s.push(() => log.push("a")); s.push(() => log.push("b"));
  assert.equal(s.closeTop(), true); assert.deepEqual(log, ["b"]);
});
test("빈 스택의 closeTop 은 false", () => { assert.equal(createOverlayStack(() => {}).closeTop(), false); });
test("잠금은 첫 창에서 걸고 마지막이 풀릴 때만 푼다", () => {
  const calls: boolean[] = []; const s = createOverlayStack((l) => calls.push(l));
  const ra = s.push(() => {}); const rb = s.push(() => {});
  rb(); assert.deepEqual(calls, [true]); ra(); assert.deepEqual(calls, [true, false]);
});
test("제거는 두 번 불러도 한 번만 — 다른 창의 자리를 빼지 않는다", () => {
  const s = createOverlayStack(() => {}); const ra = s.push(() => {}); s.push(() => {});
  ra(); ra(); assert.equal(s.size(), 1);
});
test("끌어내리기 — 120px 넘으면 닫고, 짧아도 빠르면 닫는다", () => {
  assert.equal(shouldDismissSheet(121, 0), true);
  assert.equal(shouldDismissSheet(119, 0.1), false);
  assert.equal(shouldDismissSheet(30, 0.7), true);
  assert.equal(shouldDismissSheet(20, 2), false); // 24px 미만은 속도가 빨라도 탭으로 본다
  assert.equal(shouldDismissSheet(-50, 3), false); // 위로 끈 것
});
test("onceClose — 연타해도 한 번", () => { let n = 0; const c = onceClose(() => n++); c(); c(); assert.equal(n, 1); });
```

### Task 2: `Sheet` · `Dialog` 공통 틀

**Files:**
- Create: `components/common/Sheet.tsx`, `components/common/Dialog.tsx`, `components/common/overlay-close.tsx`(닫기 요청 컨텍스트)
- Modify: `app/globals.css`(앱 전용 시트 움직임 — 웹은 지금의 `animate-fade-in` 그대로)

**Interfaces:**
- Consumes: Task 1 `overlayStack.push`, `shouldDismissSheet`, `onceClose`
- Produces:
  - `Sheet({ label, onClose, dismissible = true, z = 80, children }: { label: string; onClose: () => void; dismissible?: boolean; z?: number; children: ReactNode })`
  - `Dialog({ label, onClose, dismissible = true, z = 105, role = "dialog", children }: { label: string; onClose: () => void; dismissible?: boolean; z?: number; role?: "dialog" | "alertdialog"; children: ReactNode })`
  - `useOverlayClose(): () => void` — 안쪽 버튼(나중에·확인 등)이 부르는 닫기 요청. 시트는 앱에서 내려가는 움직임을 끝낸 뒤 `onClose` 를 부르고, 확인창과 웹은 바로 부른다.
- 부모가 보여 줄 때만 그린다(지금처럼 조건부 렌더). `open` 속성은 두지 않는다.

- [ ] **Step 1: `Sheet`**
  - **겉:** 포털(`document.body`) + 뒤 배경. 배경은 지금 시트의 겉 클래스를 그대로 쓴다: `fixed inset-0 flex items-end sm:items-center justify-center bg-night/50 backdrop-blur-sm animate-fade-in`, z 는 `style={{ zIndex: z }}`. `dismissible` 이면 배경을 눌러 닫는다.
  - **판:** 지금 시트 판 클래스를 그대로 쓴다: `w-full max-w-md mx-auto bg-cream rounded-t-3xl sm:rounded-3xl p-6 pb-[max(env(safe-area-inset-bottom),24px)] sm:pb-6 max-h-[88vh] overflow-y-auto overscroll-contain`, `role="dialog"`, `aria-label={label}`.
  - **앱 전용 손잡이:** 판 맨 위에 `app-only` 손잡이(`mx-auto -mt-2 mb-3 h-1.5 w-10 rounded-full bg-lilac-mid/60`)를 둔다.
  - **끌어내리기:** 판 위 44px 띠에서 pointer down → 판을 `translateY(dy)`(아래로만) → up 때 `shouldDismissSheet` 면 닫기, 아니면 0.2초 동안 제자리로 돌아간다. 끌기는 `useAppInfo().app` 이 있을 때만 붙인다.
  - **스택:** 마운트 때 `overlayStack.push(requestClose)`, 언마운트 cleanup 에서 제거한다(Review Focus 2). `requestClose = onceClose(...)`.
- [ ] **Step 2: `Dialog`**
  - **겉:** 지금 확인창 겉 클래스 `fixed inset-0 flex items-center justify-center px-6 bg-night/45 backdrop-blur-[2px] animate-fade-in` + z.
  - **판:** 판 모양은 `children` 이 가진다. 지금 확인창의 안쪽 `div`(`w-full max-w-sm bg-cream rounded-3xl p-6`)를 Dialog 가 감싸고, `role`·`aria-label` 은 Dialog 가 단다.
  - 스택 등록과 닫기 요청은 Sheet 와 같다. 움직임은 없다(지금처럼 페이드).
- [ ] **Step 3: CSS (`app/globals.css`)**
  - 앱에서만 판이 올라오고(`html[data-app] .sheet-panel` 열릴 때), 닫기 요청 때 `data-closing` 으로 내려간다.
  - 값은 위 표의 플랫폼별 시간·곡선을 쓴다.
  - `prefers-reduced-motion: reduce` 면 움직임이 없다.
  - 웹은 판 움직임 없이 지금의 겉 `animate-fade-in` 만 둔다.
- [ ] **Step 4: 타입** — `npx tsc --noEmit --incremental false` 0
- [ ] **Step 5: 커밋** — `feat(app-shell): 공통 시트·확인창 틀(Sheet·Dialog)`
