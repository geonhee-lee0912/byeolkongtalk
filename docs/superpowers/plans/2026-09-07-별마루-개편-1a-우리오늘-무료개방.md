# 별마루 개편 1A — 우리 오늘 무료 개방 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 우리 오늘을 완전 구독 잠금에서 "무료 = 오늘 1칸 룰 판정 + 정적 한 줄 / 유료 = 30일 캘린더 + LLM 서술"로 개방하고, 상대 등록(watch)도 비구독에 연다.

**Architecture:** 판정(`pair-day.ts`)은 이미 룰 100%(LLM 0)라 무료로 열어도 변동비 0. 캘린더 라우트 subject 경로는 지금 비구독을 `locked:true`로 완전 차단하는데, 이를 **소유 검증 후 자격별 분기**(비구독=오늘 1칸+정적, 구독=30일)로 바꾼다. LLM 서술(`pair-narrative`)은 유료 유지. 상대 목록·추가(`watch` 라우트)의 `requireEntitled` 게이트를 로그인-only 로 완화한다(별 코스트 2무료+5별은 `watch.ts`에 그대로 있어 유지).

**Tech Stack:** Next.js 16 (App Router, route handlers) · React 19 (client component) · TypeScript strict · Tailwind v4 · 테스트 = `node:test` + `node:assert/strict` (tsx 경유).

**검증 모델(이 레포 관행):** 순수 로직(`lib/*`)은 `node:test` 로 TDD 한다. **라우트·컴포넌트는 이 레포에 유닛 하네스가 없다** — `npx tsc --noEmit` + `next build` + **브라우저 라이브 E2E**(세션 주입 = `byeolkong_user_id` 쿠키에 userId 원문)로 검증한다. 각 라우트/UI 태스크의 "검증" 스텝은 이 방식을 따른다.

**전제:** 이 태스크들은 현재 `ByeolmaruView` 레이아웃 위에서 동작한다. Phase 1B(홈 A 재편)가 이후 레이아웃을 재구성하지만, 여기서 만드는 **무료/유료 우리 오늘 렌더 로직(PairDayDetailCard)** 과 **백엔드 게이팅**은 그대로 계승된다.

```ts
/** 무료 우리 오늘 정적 한 줄 — 오늘 톤/태그로 룰 조합(LLM 0). 구독 LLM 서술의 자리를 무료로 메운다.

export function getPairStaticLine(cell: PairDayCell): string {
  const t = cell.tags;
  if (t.friction) return "오늘은 둘 사이 결이 살짝 엇갈릴 수 있어. 말 한마디를 천천히 골라보면 좋아.";
  if (t.spark && t.bond) return "오늘은 끌림도 결속도 같이 도는 날이야. 마음이 자연스럽게 가까워져.";
  if (t.spark) return "오늘은 둘 사이에 끌림이 도는 날이야. 작은 신호에 마음이 움직여.";
  if (t.bond) return "오늘은 서로 편안하게 이어지는 결이야. 함께 있는 시간이 순해.";
  if (cell.tone === "good") return "오늘은 둘 사이 흐름이 순한 날이야.";
  if (cell.tone === "caution") return "오늘은 서로 조금 챙겨주면 좋은 결이야.";
  return "오늘은 둘 사이 무난하게 흐르는 날이야.";
}
```

```ts
    // 완전 블러 없이도 데이터 누출이 없다. 자격은 분량으로 가른다(비구독=오늘 1칸, 구독=30일).

    if (subject && subject !== "me") {
      const { data: pRow, error: pErr } = await getServiceSupabase()

        .eq("id", subject)
        .eq("user_id", userId)
        .maybeSingle();
      if (pErr) {

      if (!pRow || pRow.is_primary || !pRow.birth_date) {

      const partnerSaju = calcSaju(profileRowToSajuInput(pRow));
      const pairCells = buildPairCalendar(saju, partnerSaju, temporal.dailyLuck, todayKst);
      const backdrop = pairBackdrop(saju, partnerSaju);
      const todayGanji = temporal.day.stem + temporal.day.branch;
      const ent = await getEntitlement(userId);

      if (!ent.entitled) {
        // 무료 = 오늘 1칸 룰 판정 + 정적 한 줄(30일·LLM 아님). dailyLuck 이 오늘부터라 [0]이 오늘이지만

          entitled: false,
          today: todayKst,
          todayGanji,
          partnerName: pRow.display_name,
          cells: [todayCell],
          backdrop,
          staticLine: getPairStaticLine(todayCell),
        });
      }

      return NextResponse.json({
        subject,
        entitled: true,
        today: todayKst,
        todayGanji,
        partnerName: pRow.display_name,
        cells: pairCells,
        backdrop,
      });
```
