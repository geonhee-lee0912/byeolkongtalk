# 별자리 포커스/걸어다니기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 지도 탭을 "나+누른 별 2개 확대"에서 **"나 + 누른 별 + 그 별과 연결된 지인들"(X 중심 3단 포커스)**로 바꾸고, 이웃 별 탭으로 관계망을 **걸어다니며**(breadcrumb), 지인-지인 선을 눌러 그 관계를 **열람**한다.

**Architecture:** 포커스는 transform 줌이 아니라 **재배치**로 확대한다 — `buildFocusGraph(centerId, graph)`(순수)가 {나·X·X이웃} 부분그래프(X 중심 spoke 엣지)를 만들고, `computeLayout(..., {centerId})`가 X를 중심에 놓는다. Canvas 는 넘겨받은 그래프를 그대로 렌더(focusMode 면 비특별 선도 중립선으로 그리고 선 클릭 허용). View 가 focusPath 스택으로 걸음/breadcrumb 을 관리.

**Tech Stack:** Next.js 16 / React 19 / TS strict, SVG, node:test.

**Spec:** `docs/superpowers/specs/2026-08-21-별자리-포커스-걸어다니기-design.md`

```ts
export function computeLayout(
  nodes: GraphNode[],
  opts?: { center?: number; radius?: number; centerId?: string }
): Map<string, Point> {
  const center = opts?.center ?? 50;
  const radius = opts?.radius ?? 34;
  const map = new Map<string, Point>();
  if (nodes.length === 0) return map;

  let centerIdx = opts?.centerId
    ? nodes.findIndex((n) => n.id === opts.centerId)
    : nodes.findIndex((n) => n.isHost);
  if (centerIdx < 0) centerIdx = 0;
  map.set(nodes[centerIdx].id, { x: round(center), y: round(center) });

  const others = nodes.filter((_, i) => i !== centerIdx);
  others.forEach((n, i) => {
    const a = ((-90 + (i * 360) / others.length) * Math.PI) / 180;
    map.set(n.id, { x: round(center + radius * Math.cos(a)), y: round(center + radius * Math.sin(a)) });
  });
  return map;
}
```

```ts
import type { StarGraph, GraphEdge, GraphNode } from "./types.ts";

/** centerId 중심의 포커스 부분그래프. 이웃 = centerId 와 엣지가 있는 노드 + 같은 삼합 멤버.
 *  엣지 = centerId 발(spoke). 실제 엣지가 있으면 재사용, 삼합-only 이웃은 중립 spoke 합성. */
export function buildFocusGraph(centerId: string, graph: StarGraph): StarGraph {
  // 삼합 mate
  const triadMates = new Set<string>();
  graph.triads.forEach((t) => {
    if (t.memberIds.includes(centerId)) t.memberIds.forEach((id) => triadMates.add(id));
  });
  triadMates.delete(centerId);

  // centerId 와 엣지 있는 상대
  const edgePartners = new Set<string>();
  graph.edges.forEach((e) => {
    if (e.a === centerId) edgePartners.add(e.b);
    else if (e.b === centerId) edgePartners.add(e.a);
  });

  const neighborIds = new Set<string>([...edgePartners, ...triadMates]);
  const nodeIds = new Set<string>([centerId, ...neighborIds]);
  const nodes = graph.nodes.filter((n) => nodeIds.has(n.id));

  const edgeByPair = (x: string, y: string): GraphEdge | undefined =>
    graph.edges.find((e) => (e.a === x && e.b === y) || (e.a === y && e.b === x));

  const edges: GraphEdge[] = [];
  neighborIds.forEach((nid) => {
    const real = edgeByPair(centerId, nid);
    if (real) edges.push(real);
    else {
      // 삼합-only 이웃 → 중립 spoke 합성(heavenly/six false → 렌더서 중립선)
      edges.push({
        a: centerId, b: nid, element: "", labelAtoB: "", labelBtoA: "",
        tenGodAtoB: "", tenGodBtoA: "", inyeon: 0,
        triadShared: true, heavenlyCombo: false, sixCombo: false,
      });
    }
  });

  const triads = graph.triads
    .map((t) => ({ element: t.element, memberIds: t.memberIds.filter((id) => nodeIds.has(id)) }))
    .filter((t) => t.memberIds.length >= 2);

  return { ok: true, shareId: graph.shareId, claimed: graph.claimed, nodes, edges, triads };
}
```
(⚠️ GraphNode/GraphEdge 필드는 `lib/byeoljari/types.ts` 정본에 맞출 것 — 위 합성 엣지 필드가 GraphEdge 와 정확히 일치하는지 확인.)
