**Scope:** saju_full·monthly·compat/compat_social·daily 뷰 + 프롬프트. **범위 밖(2b-2):** 오행 차트/대운 표 주입(대운 데이터 적재 필요).

### Task 1: bespoke 프롬프트 5종에 마크다운 [서식]

**Files:** Modify `lib/fortune/prompt.ts`

bespoke 5개 가이드(`daily`·`monthly`·`saju_full`·`compat`·`compat_social`)의 `[규칙]` 문자열은 모두 아래 **동일한 말미**로 끝난다(소스 기준, 백틱 템플릿 리터럴 안):

```
JSON 문자열 안에서 큰따옴표는 escape(\")하고 줄바꿈은 넣지 마.
```

이 5곳을 전부 아래로 교체한다(런타임 문자열 기준 — 소스에선 `\n`·`\"` 이스케이프가 각각 `\\n`·`\\"` 로 들어가야 함. 파일을 읽어 정확한 바이트로 편집할 것):

```
\n[서식] 각 서술형 텍스트 필드를 다채롭고 읽기 쉽게 마크다운으로 써라: 핵심 단어·구절을 문단마다 1~2곳 **굵게**(한 문단 통째 굵게 금지, 핵심만), 관련된 2~4문장을 한 문단으로 묶고 문단 사이에만 빈 줄(\n\n)로 나눠라(한 문장마다 띄우지 말 것). 나열형 내용(강점·조심할 점·조언 등)은 각 줄 "- " 로 시작하는 불릿으로(어울리면 3~5개), 가장 중요한 팁 1개는 "> " 로 시작하는 콜아웃 줄로(항목당 최대 1개, 남발 금지). 형식을 섞어 지루하지 않게 — 억지로 다 넣진 말 것. JSON 문자열 안 큰따옴표는 escape(\")하고, 줄바꿈은 반드시 \n 으로 이스케이프해라(생 줄바꿈 금지).
```

⚠️ `genericGuide`(179)·`life_full`(504)은 이미 [서식]이 있으니 **건드리지 말 것**. daily/monthly/saju_full/compat/compat_social 만.

- [ ] Step 1: `lib/fortune/prompt.ts` 를 읽어 위 말미 5곳 확인 → 각각 교체.
- [ ] Step 2: `npx tsc --noEmit` (exit 0).
- [ ] Step 3: commit `feat(fortune): bespoke 프롬프트 마크다운 [서식]`.

- 다크 종합운 요약 `<p ... whitespace-pre-line>{report.summary}</p>` → `<MarkdownLite text={report.summary} tone="dark" className="text-[13.5px] leading-[1.85] text-white/90" />`.
