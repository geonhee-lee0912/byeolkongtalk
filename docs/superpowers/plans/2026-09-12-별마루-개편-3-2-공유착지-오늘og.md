# 별마루 개편 Phase 3-2 — 공유 착지 + 오늘 타로/사주 OG (Loop 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 무료 결과 공유가 별마루로 이어지게(바이럴 Loop 2). ① 오늘 타로·오늘 사주에 **공유 버튼 신설**(가장 punchy) + 무상태 OG 카드 ② fortune 결과 **死페이지 공유 링크를 `/byeolmaru`로** 착지 ③ MBTI·별자리 공유 착지 페이지에 **`별마루에서 더 보기` CTA**(라이브 유지 + 허브 연결). 스펙 §7 Loop 2.

**Architecture:** OG는 스크래퍼가 쿠키 없이 치므로 **무상태**여야 한다 — 오늘 타로/사주 OG는 카드·등급을 **URL 파라미터**로 받아 렌더(세션·DB·PII 0). saju-mbti OG(`app/api/og/saju-mbti/route.tsx`)가 정확히 이 패턴(rate-limit·params 검증·Pretendard·다크 ImageResponse). 공유 버튼은 별마루에 처음 생기지만 `shareToKakao`(`lib/kakao-share.ts`) + 전역 KakaoSDK가 이미 준비돼 있어 배선만. 오늘 타로/사주는 `readings`가 아니라 룰 결과라 `has_sensitive` **무관**(rate-limit만). 착지는 전부 `/byeolmaru`(P3-1 게스트 구경 모드와 연결).

**Tech Stack:** Next.js 16 `next/og` ImageResponse(runtime nodejs), `shareToKakao` feed 공유, TypeScript strict.

## 컨텍스트 (구현자가 알아야 할 것)
- `shareToKakao(input): boolean` — `input = {title, description, imageUrl, link, buttonTitle?}`. `imageUrl`=OG(1200×630), `link`=클릭 착지. `isKakaoReady()` false면 false 반환(호출자 폴백). 전역 `<KakaoSdkLoader/>`(`app/layout.tsx`) 마운트됨.
- 무상태 OG 템플릿 = `app/api/og/saju-mbti/route.tsx`: `runtime="nodejs"`, `checkRateLimit({namespace, key:getClientIp(req), max:30, windowMs:60_000})` → 429, `searchParams.get(...)` 검증 후 무효면 400, Pretendard fetch+fontCache, `ImageResponse(<div 다크그라데이션+골드별+텍스트>, {width:1200,height:630,fonts})`.
- 카드 아트: `app/api/og/tarot/[readingId]/route.tsx`에 카드 webp→jpeg base64 헬퍼(`getCardImageDataUrl` 류, `:37-58`) — satori `<img>`는 webp 미지원이라 sharp 변환 필요. 오늘 타로 OG가 재사용(로컬 함수면 추출).
- 오늘 카드 데이터: `DailyCardBlock.tsx`의 `state.card = {cardId, reversed}`(drawn 섹션 `:201-207`), `getCard(cardId)`(`@/lib/tarot/cards`)로 이름·키워드. 공유 버튼 자리 = drawn 섹션(`:213-273`) 하단.
- 오늘 등급 데이터: `SajuTodayView.tsx`의 오늘 셀(등급 label·tone + ganji). `DayGrade`(`lib/byeolmaru/day-score.ts`: tone good/normal/caution, label "잘 맞는 날"/"무난한 날"/"살짝 챙길 날"). 공유 버튼 자리 = 오늘 셀/DayDetailCard 근처(`:107` 부근).
- fortune 결과 공유: `app/fortune/result/page.tsx`의 `handleKakaoShare`(대략 `:397-408`) — `imageUrl:${origin}/api/og/fortune/${id}`, `link:${origin}/fortune/result?id=${id}`. **link을 `/byeolmaru`로 바꾼다.**
- MBTI 공유 착지: `/fortune/saju-mbti?r={token}` → `SajuMbtiFlow sharedToken={r}`(`app/fortune/saju-mbti/page.tsx:50`). 별자리: `/fortune/byeoljari/{shareId}`(`app/fortune/byeoljari/[shareId]/page.tsx`).

## 결정 (승인 시 확정)
- **D1. 오늘 타로 OG** = 카드 아트(sharp 재사용) + 카드명 + 키워드 + 별마루 브랜드. `?card=<0-77>&rev=<0|1>`. 파라미터 범위 밖이면 400.
- **D2. 오늘 사주 OG** = 등급 라벨 + 오늘 간지 + 별마루 브랜드(텍스트, 카드아트 없음). `?grade=<good|normal|caution>&ganji=<간지>`. 무효 grade면 400(ganji는 표시용, 없으면 생략).
- **D3. 착지** = 오늘 타로/사주 공유 = `link:/byeolmaru`(게스트 구경 모드로). fortune 결과 = `/byeolmaru`. MBTI/별자리 = 라이브 유지 + `별마루에서 더 보기` CTA(착지 자체는 안 바꿈).
- **D4. 시각 투자** = Phase 5가 UI 재설계하므로 OG·공유버튼은 기능+on-brand(saju-mbti OG 톤 재사용) 수준. 과투자 금지.
