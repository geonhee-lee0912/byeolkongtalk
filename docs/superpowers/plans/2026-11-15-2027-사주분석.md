# 2027년 사주 분석 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사주 운세 탭에 `saju_2027`("2027년 사주 분석", 60별)을 추가하고, `saju_full`(2026) 전용 틀을 연도를 값으로 받게 바꾼다.

**Architecture:** 연도 사양 표(`SAJU_YEAR_SPECS`)를 `lib/fortune/saju-full-report.ts` 에 두고 프롬프트·저장본·결과 화면·목차가 모두 그 표에서 연도를 꺼낸다. 저장본은 새 필드 `yearPillar` 로 쓰고, 옛 2026 저장본의 `year2026` 은 읽을 때 `yearPillar` 로 정규화한다.

**Tech Stack:** Next.js 16 · TypeScript · node:test(`node --import tsx --test`)

**Spec:** `docs/superpowers/specs/2026-11-15-2027-사주분석-design.md`

## Global Constraints

- 2027 = 정미년 / 丁未 (천간 정, 지지 미). 2026 = 병오년 / 丙午
- 이름 "2027년 사주 분석" · 한 줄 "2027년 한 해의 흐름을 내 사주로 한 장에" · 60별 · "약 2만 자" · MAX_TOKENS 30000 · 칩 `timing` · 진열 `saju_full` 바로 앞
- DB 변경 없음. `saju_full` 의 가격·진열은 그대로
- `saju_full` 프롬프트 출력 문자열은 이 작업 전과 **한 글자도 달라지지 않아야** 한다(2026 구매자 품질 회귀 방지)
- 테스트 명령: `node --import tsx --test $(find . -name "*.test.ts" -not -path "./node_modules/*" -not -path "./qa/*" -not -path "./mobile/node_modules/*")` · 타입: `npx tsc --noEmit --incremental false`
- 커밋은 `git commit -F <파일> -- <경로>`, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

- `saju_full` 프롬프트가 리팩터 전과 같다 → Task 2 테스트(리팩터 전 문자열 sha256 고정)
