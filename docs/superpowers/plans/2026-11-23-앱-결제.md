# 앱 결제(②) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱(웹뷰) 안의 별 충전을 애플·구글 소모성 인앱결제로 바꾸고, 서버가 스토어에 직접 확인해 별을 주며, 환불되면 남은 만큼 회수한다.

**Architecture:** 웹 상점·충전 시트는 앱 안이면 브리지(`iap.buy`)로 앱에 결제를 맡긴다. 앱은 `expo-iap` 로 결제한 뒤 거래 식별자를 앱 토큰과 함께 `POST /api/payment/iap` 로 보내고, 서버는 애플 App Store Server API·구글 Play Developer API 로 확인 → 토스와 같은 지급 함수(`grantStarPackage`)로 별·첫충전 보너스를 준다. 환불은 애플 서버 알림 v2·구글 RTDN 을 받아 새 RPC `clawback_stars` 로 회수한다.

**Tech Stack:** Next.js 16 · Supabase(Postgres RPC) · `@apple/app-store-server-library@3.1.0` · `google-auth-library@11.3.4` + fetch(REST) · Expo SDK 58 · `expo-iap@6.5.1`(SDK 58 호환 미확인 — Task 7 Step 1 이 관문)

**Spec:** `docs/superpowers/specs/2026-11-23-앱-결제-design.md`

## Global Constraints

- 상품 ID = 패키지 id `star_10`·`star_30`·`star_70`·`star_150`·`star_300`(`lib/constants.ts` `STAR_PACKAGES` — 값 안 바꿈). 소모성
- 가격은 웹과 같다. 앱 화면 가격 글자는 스토어 현지 가격 문자열
- 첫충전 보너스 = `Math.round(stars * FIRST_CHARGE_BONUS_RATE)`(0.2), 원장 `bonus_claims(kakao_id_hash, bonus_type='first_charge')` — 웹·앱 공용 1인 1회
- 환불 회수 = 그 결제의 `stars_given + bonus_stars`, 잔액이 모자라면 0 까지만, 모자란 양 기록. `bonus_claims` 는 지우지 않는다
- 별 잔액은 `lib/stars.ts` 래퍼로만. RPC 직접 호출 금지
- 새 `SECURITY DEFINER` 함수는 `REVOKE EXECUTE … FROM PUBLIC, anon, authenticated` 셋 다 + `GRANT EXECUTE … TO service_role`
- 마이그레이션(Task 1)은 그걸 읽는 코드와 **다른 PR** 로 먼저 dev 에 올리고 Supabase 체크 success 뒤 나머지
- `pg_tid` 는 `VARCHAR(100)` — `apple:<transactionId>` / `google:<orderId>`(테스트 결제는 `apple-sandbox:` / `google-test:`), 구매 토큰을 넣지 않는다
- 샌드박스(애플 Sandbox·구글 purchaseType 0)도 별은 준다(심사자 구매) — `amount_won = 0`
- 앱 안에서 토스 결제창·웹 결제 유도 문구를 보이지 않는다(애플 3.1.1)
- 브리지 `BRIDGE_VERSION` 은 올리지 않는다 — 새 type 만 더한다. 앱 기능 표시는 caps 에 `"iap"`
- 서버 비밀값: `APPLE_IAP_KEY_ID` · `APPLE_IAP_ISSUER_ID` · `APPLE_IAP_PRIVATE_KEY` · `APPLE_APP_ID`(숫자 — Production 검증 필수) · `GOOGLE_PLAY_SERVICE_ACCOUNT`(JSON) · `GOOGLE_PUBSUB_PUSH_EMAIL`(푸시 서비스 계정 이메일) · `GOOGLE_PUBSUB_AUDIENCE`. 없으면 해당 라우트만 503
- 커밋은 `git commit -F <파일> -- <경로>`, 제목 다음 줄 비움. 공개 저장소 — 키·풀 UUID 금지
- 테스트: `node --import tsx --test <파일>` · 타입 `npx tsc --noEmit --incremental false` · 앱 `cd mobile && npx tsc --noEmit -p .`

## Review Focus

1. 결제는 됐는데 서버 확인 전에 앱이 꺼짐 → 다음 실행·로그인 때 미완료 거래를 다시 보내 별이 들어와야 한다(Task 7 `resumePending` 테스트)
2. 같은 거래가 리스너와 재전송으로 **동시에** 두 번 옴 → 별은 한 번(Task 3 경합 테스트)
3. A 회원 결제 중 로그아웃 → B 로그인 뒤 그 거래 재전송 → B 에게 지급 안 함, 거래 마무리도 안 함(Task 3 계정 토큰 불일치 409, Task 7 `account_mismatch` 면 finish 안 함)
4. 같은 환불 알림이 두 번·순서 뒤바뀌어 옴 → 한 번만 회수(Task 4 테스트)
5. 앱 심사자 샌드박스 구매가 운영 매출에 잡힘 → `amount_won 0`(Task 3 테스트)
