# 타로 로그인 전 맛보기 (입구 반반) — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈 태그 → 고민 → 메뉴 → 카드 뽑기까지 로그인 없이 가고, 뽑은 카드를 공개한 순간 로그인 창을 띄운다. 로그인하고 돌아오면 버튼 없이 풀이를 이어 준다. 익명 쿠키 반반으로 옛 흐름(먼저 로그인)과 비교한다.

**Architecture:** 그룹은 `lib/tarot/entry-ab.ts` 의 `entryArmOf(anonId)`(익명 쿠키 끝 글자 짝 = 새 흐름) 하나로 계산한다. 스위치 `ENTRY_AB` 기본 `"old"`, 메뉴판이 반반(`MENU_AB==="split"`)이면 항상 `"old"`. 화면은 `/api/stars/balance` 의 `entryArm` 으로 받는다. 진행은 localStorage `byeolkong:pending_draw`(`lib/tarot/pending-draw.ts`)에 저장해 로그인·결제·'나중에' 왕복 뒤 `/tarot/draw?resume=…` 가 복원한다. 로그인 전 가격은 '선물 15별을 막 받은 신규 회원' 표시용 지갑(`guestWallet`)으로 기존 메뉴판 함수를 그대로 탄다. DB 마이그레이션 없음 · `proxy.ts` 무변경.

**Tech Stack:** Next.js 16 App Router(클라이언트 컴포넌트) · React 19 · TypeScript strict · Tailwind v4 · node:test + tsx

**스펙:** `docs/superpowers/specs/2026-10-11-타로-로그인전-맛보기-design.md` — §0 사용자 결정 · §5 구조 · §7 판정이 기준이다.

**prod:** 이 계획은 dev 까지다. 켜는 배포(`ENTRY_AB="split"` + `MENU_AB` 승자 고정)는 메뉴판 판정(10-25 21:29 이후) 뒤 사용자 go 로 따로 한다.

```ts
// 타로 로그인 전 맛보기 — 입구 반반 비교(A/B)의 그룹 계산 단일 원천. 순수 함수(클라 안전).
// 그룹은 저장하지 않고 익명 쿠키(byeolkong_anon_id)로 계산한다. 판정 SQL·감시 쿼리와 같은 규칙:
//   position(lower(right(anon_id,1)) in '02468ace') > 0  → 새 흐름
// 스펙: docs/superpowers/specs/2026-10-11-타로-로그인전-맛보기-design.md §5-1 · §7
import { MENU_AB, type MenuAbMode } from "./menu-ab.ts";

export type EntryArm = "new" | "old";
export type EntryAbMode = "split" | EntryArm;

/** 스위치 — 'old' = 전원 지금 prod(구현 중 기본값: 중간 커밋이 dev→main 에 섞여 나가도 무해) · 'split' = 반반 · 'new' = 전원 새 흐름.
 *  상수라 바꾸면 재배포(prod 는 사용자 go). entry-ab.test.ts 의 "기본 스위치 = old" 테스트는 일부러 걸리게 해 뒀다 — 켤 때 그 테스트도 같이 고칠 것. */
export const ENTRY_AB: EntryAbMode = "old";

/** 새 흐름 그룹의 익명 쿠키 끝 글자 — 판정 SQL·감시 쿼리와 같아야 한다(entry-ab.test.ts 가 SQL 파일과 대조) */
export const ENTRY_LAST_CHARS = "02468ace";

/** 홈이 새 흐름으로 보낸 방문자 표시(sessionStorage) — 고민 쓰기가 "풀이는 카카오로 3초…" 안내를 띄운다 */
export const ENTRY_FLOW_KEY = "byeolkong:entry_flow";

/** 이 방문자의 입구 그룹(앱용 — 스위치 ENTRY_AB 를 따른다).
 *  🔴 메뉴판이 아직 반반(MENU_AB='split')이면 항상 'old' — 로그인 전 가격(비로그인 = 옛 그룹)과 로그인 뒤 가격(회원 그룹)이 어긋나 409 가 난다(스펙 §5-1 가드). */
export function entryArmOf(anonId: string | null | undefined): EntryArm {
  return entryArmForMode(anonId, ENTRY_AB, MENU_AB);
}

/** 규칙 본체 — 스위치를 인자로 받는다(테스트 전용). 🔴 앱 코드는 entryArmOf 를 쓸 것 */
export function entryArmForMode(
  anonId: string | null | undefined,
  mode: EntryAbMode,
  menuMode: MenuAbMode
): EntryArm {
  if (menuMode === "split") return "old";
  if (mode !== "split") return mode;
  const last = (anonId ?? "").trim().slice(-1).toLowerCase();
  return last !== "" && ENTRY_LAST_CHARS.includes(last) ? "new" : "old";
}

/** 새 장치(진행 저장·회원 충전 왕복 복원)가 켜졌나 — 스위치가 'old' 가 아니고 메뉴판이 반반이 아닐 때만. 스펙 §5-2 · §8 */
export function entryFeaturesOn(): boolean {
  return entryFeaturesOnFor(ENTRY_AB, MENU_AB);
}

export function entryFeaturesOnFor(mode: EntryAbMode, menuMode: MenuAbMode): boolean {
  return mode !== "old" && menuMode !== "split";
}
```

```ts
// 저장소를 인자로 받는다(유닛 테스트용 가짜 저장소). 화면에선 localStorage 를 넘긴다 — 탭을 닫아도 같은 브라우저면 남게.
// 고민 원문이 기기에 최대 7일 남는다 — 풀이가 시작되거나(goToReading) 로그아웃·탈퇴하면 지운다.
// 스펙: docs/superpowers/specs/2026-10-11-타로-로그인전-맛보기-design.md §5-2
import { PENDING_KEY, type EmotionTag, type PendingConsultation } from "../emotions.ts";
import type { DrawnCard, SpreadCategory, SpreadType } from "./spreads.ts";
import { TAROT_SPREAD_KEY, type TarotSpreadSelection } from "./session.ts";

export const PENDING_DRAW_KEY = "byeolkong:pending_draw";
/** 홈 태그 → 고민 쓰기가 읽는 감정 태그 키(app/page.tsx·app/concern/page.tsx 와 같은 문자열) */
export const EMOTION_KEY = "byeolkong:emotion";
export const PENDING_DRAW_TTL_MS = 7 * 24 * 60 * 60 * 1000;

export interface PendingDraw {
  v: 1;
  emotion: EmotionTag;
  concern: string;
  spreadType: SpreadType;
  spreadCategory: SpreadCategory;
  /** 메뉴판에서 가격을 보고 고른 선택(lib/tarot/session TarotSpreadSelection.consented) — 로그인 뒤 잔액이 되면 확인 팝업 없이 시작 */
  consented?: boolean;
  drawnCards: DrawnCard[];
  savedAt: number;
}

type ReadStore = Pick<Storage, "getItem" | "removeItem">;

export function savePendingDraw(
  store: Pick<Storage, "setItem">,
  sel: TarotSpreadSelection,
  drawn: DrawnCard[],
  now: number = Date.now()
): void {
  const p: PendingDraw = {
    v: 1,
    emotion: sel.emotion,
    concern: sel.concern,
    spreadType: sel.spreadType,
    spreadCategory: sel.spreadCategory,
    ...(sel.consented ? { consented: true } : {}),
    drawnCards: drawn,
    savedAt: now,
  };
  try {
    store.setItem(PENDING_DRAW_KEY, JSON.stringify(p));
  } catch {
    // 가득 참·차단 — 저장 못 하면 복원도 없다(뽑기 화면이 pending_draw_missing 으로 잰다)
  }
}

function isDrawnCard(c: unknown): c is DrawnCard {
  const o = (c && typeof c === "object" ? c : null) as Record<string, unknown> | null;
  return (
    !!o &&
    typeof o.position === "number" &&
    typeof o.label === "string" &&
    typeof o.card_id === "number" &&
    (o.direction === "upright" || o.direction === "reversed")
  );
}

function isPendingDraw(p: unknown): p is PendingDraw {
  const o = (p && typeof p === "object" ? p : null) as Record<string, unknown> | null;
  return (
    !!o &&
    o.v === 1 &&
    typeof o.emotion === "string" &&
    typeof o.concern === "string" &&
    o.concern.length > 0 &&
    typeof o.spreadType === "string" &&
    typeof o.spreadCategory === "string" &&
    typeof o.savedAt === "number" &&
    Array.isArray(o.drawnCards) &&
    o.drawnCards.length > 0 &&
    o.drawnCards.every(isDrawnCard)
  );
}

/** 유효하고 7일 안이면 돌려준다. 깨졌거나 만료면 지우고 null. 저장소가 던지면 null. */
export function loadPendingDraw(store: ReadStore, now: number = Date.now()): PendingDraw | null {
  let raw: string | null;
  try {
    raw = store.getItem(PENDING_DRAW_KEY);
  } catch {
    return null;
  }
  if (!raw) return null;
  let parsed: unknown = null;
  try {
    parsed = JSON.parse(raw);
  } catch {
    parsed = null;
  }
  if (!isPendingDraw(parsed) || now - parsed.savedAt > PENDING_DRAW_TTL_MS) {
    clearPendingDraw(store);
    return null;
  }
  return parsed;
}

export function clearPendingDraw(store: Pick<Storage, "removeItem">): void {
  try {
    store.removeItem(PENDING_DRAW_KEY);
  } catch {
    // noop
  }
}

/** 같은 판인가 — 이어가기 표시 없이 돌아온 경우(옛 결제 링크 등) 지금 선택과 맞춰 본다 */
export function matchesSelection(
  p: PendingDraw,
  sel: Pick<TarotSpreadSelection, "spreadType" | "concern"> | null
): boolean {
  return !!sel && sel.spreadType === p.spreadType && sel.concern === p.concern;
}

/** 복원 — 기존 화면들이 읽는 sessionStorage 키를 다시 채워 지금 코드 경로를 그대로 탄다(뒤로 가기 → /tarot · /concern 포함). 복원한 선택을 돌려준다 */
export function restoreSession(session: Pick<Storage, "setItem">, p: PendingDraw): TarotSpreadSelection {
  const sel: TarotSpreadSelection = {
    spreadType: p.spreadType,
    spreadCategory: p.spreadCategory,
    emotion: p.emotion,
    concern: p.concern,
    ...(p.consented ? { consented: true } : {}),
  };
  const pending: PendingConsultation = { emotion: p.emotion, concern: p.concern, type: "tarot" };
  session.setItem(EMOTION_KEY, p.emotion);
  session.setItem(PENDING_KEY, JSON.stringify(pending));
  session.setItem(TAROT_SPREAD_KEY, JSON.stringify(sel));
  return sel;
}

/** 이 화면에 돌아온 길 — 로그인 창(login) · 충전(payment) · 홈 '아까 뽑은 카드'(home) */
export type ResumeVia = "login" | "payment" | "home";

export function resumeHref(via: ResumeVia): string {
  return `/tarot/draw?resume=${via}`;
}

export function parseResume(search: string): ResumeVia | null {
  const v = new URLSearchParams(search).get("resume");
  return v === "login" || v === "payment" || v === "home" ? v : null;
}
```

```ts
/** 모자란 별을 덮는 가장 작은 시트 패키지 값(원) — 첫 충전 보너스 포함(신규 회원의 첫 결제). 0 이하는 0, 시트 칸으로 못 덮으면 null */
export function minTopUpWon(short: number, arm: MenuArm): number | null {
  if (short <= 0) return 0;
  const pkg = [...sheetPackages(arm)]
    .sort((a, b) => a.stars - b.stars)
    .find((p) => receivedStars(p, true) >= short);
  return pkg ? pkg.price : null;
}

const won = (n: number) => `₩${n.toLocaleString("ko-KR")}`;

/** 상품 한 줄 — 가격 P 를 선물 15 기준으로. free = 선물로 다 된다 */
export function guestShortLine(price: number, arm: MenuArm): { free: boolean; text: string } {
  const short = price - WELCOME_BONUS_STARS;
  if (short <= 0) return { free: true, text: "가입 선물로 무료" };
  const w = minTopUpWon(short, arm);
  return { free: false, text: `가입 선물 + ⭐${short}만 더${w ? ` (${won(w)}부터)` : ""}` };
}

/** 로그인 창 가격 줄 */
export function guestSheetLine(price: number, arm: MenuArm): string {
  const short = price - WELCOME_BONUS_STARS;
  if (short <= 0) return "첫 풀이는 가입 선물로 무료";
  const w = minTopUpWon(short, arm);
  return `가입 선물 ${WELCOME_BONUS_STARS}별 + ⭐${short}만 더${w ? ` (${won(w)}부터)` : ""}`;
}
```

```tsx
    const t = setTimeout(() => setWelcomeToast(false), 2600);
    return () => clearTimeout(t);
  }, [welcomeToast]);

  const labels = useMemo(
    () =>
      selection
        ? getPositionLabels(
            selection.spreadType,
            selection.spreadCategory,
            selection.emotion
          )
        : [],
    [selection]
  );

  if (!selection || !mounted) {
    return (
      <main className="flex flex-1 items-center justify-center px-5">
        <p className="text-text-light text-sm">카드를 섞는 중…</p>
      </main>
    );
  }

  const info = SPREAD_INFO[selection.spreadType];
  const accent = info.accent;
  const cardCount = info.cardCount;
  const spreadType = selection.spreadType;
  // 새 장치(진행 저장·회원 충전 왕복 복원) — 스위치가 'old' 면 꺼져 지금 prod 그대로(스펙 §5-2 · §8)
  const featuresOn = entryFeaturesOn();

  // 뽑은 카드는 인자로 받는다 — setPendingDrawn 직후의 state 는 아직 옛 값이다
  // price = 이 판에 보여 준(쓴) 가격(팝업 가격 · 팝업 생략이면 그 자리에서 계산한 가격) — 대화 화면이 서버에 실어 보내 서버 가격과 대조한다(다르면 차감 없이 409)
  const goToReading = (drawn: DrawnCard[], price: number) => {
    if (leavingRef.current) return;
    leavingRef.current = true;
    // 이 판을 시작한다 — 저장해 둔 진행은 더 필요 없다(뒤로 가 다시 들어와도 복원하지 않게)
    clearPendingDraw(localStorage);
    // 동의는 한 판에 한 번 — 이 판을 시작하는 모든 길(팝업 생략·팝업 확인)에서 여기서 소모한다.
    // 뒤로 가 다시 뽑으면 확인 팝업이 다시 뜬다(Task 4·8 리뷰). 충전 경로는 여기를 안 거쳐 동의가 남는다.
    if (selection.consented) setSelection(spendConsent(sessionStorage, selection));
    // sessionStorage 로 넘기고 /tarot/reading 이 직접 POST — 동의 표시는 대화로 넘기지 않는다(필드를 골라 담는다)
    const payload: TarotDrawResult = {
      spreadType: selection.spreadType,
      spreadCategory: selection.spreadCategory,
      emotion: selection.emotion,
      concern: selection.concern,
      drawnCards: drawn,
      expectedCost: price,
    };
    sessionStorage.setItem(TAROT_DRAW_KEY, JSON.stringify(payload));
    router.push("/tarot/reading");
  };

  const openSheet = (trigger: SheetTrigger, price: number) => {
    setSheetOpen(true);
    trackUiEvent("login_sheet_shown", {
      meta: { spread: spreadType, price, short: Math.max(0, price - WELCOME_BONUS_STARS), trigger },
    });
  };

  // 카드를 다 뽑으면 잔액·반반 그룹을 그 자리에서 읽어 이번 판 가격을 정한다(서버 차감과 같은 tarotPrice).
  //  - 로그인 전 맛보기(새 흐름 그룹 비로그인) — 확인 팝업 대신 카드 공개 + 로그인 창. 진행을 저장해 로그인 뒤 이어간다(스펙 §3·§5-2)
  //  - 메뉴판 그룹 + 메뉴판에서 동의한 선택(consented)이고 잔액이 충분하면 확인 팝업 없이 바로 대화로(스펙 §4)
  //  - 그 밖(옛 그룹 = 지금 prod 흐름 · 잔액 부족)은 확인 팝업 → 잔액 부족이면 충전 시트
  //    (그 팝업의 잔액 부족 노출이 paywall_shown = Meta AddToCart 원천이라 자리를 그대로 둔다)
  //  - 못 읽으면(실패·5초 초과) 팝업 없이 '다시 눌러줘' 한 줄 — 완료 버튼을 다시 누르면 다시 읽는다
  const onDrawn = (drawn: DrawnCard[]) => {
    setWalletError(false); // 다시 누름 = 다시 읽기 — 앞선 실패 줄을 지운다
    if (leavingRef.current) return; // 대화로 넘어가는 중엔 완료를 다시 눌러도(키보드 등) 지갑 조회를 또 내보내지 않는다
    setPendingDrawn(drawn);
    if (checkingRef.current) return;
    checkingRef.current = true;
    setChecking(true);
    const here = window.location.pathname; // 이 판을 시작한 주소 — 응답 때 달라졌으면 떠나는 중이다
    void (async () => {
      const w = await fetchWallet("tarot_draw");
      checkingRef.current = false;
      // 떠나는 중이거나 떠났으면 대화로 끌고 가지 않는다(떠난 뒤 차감 방지) — 뒤로 가기는 주소가 먼저 바뀌고 화면 정리(aliveRef)는 한 박자 늦는다
      if (!aliveRef.current || window.location.pathname !== here) {
        setChecking(false); // 언마운트면 아무 일도 안 한다 · 화면이 보존돼도(Activity) "잠시만…" 이 남지 않게
        return;
      }
      // 못 읽었다(실패·5초 초과 — 계측은 fetchWallet 의 wallet_fetch_failed) → 팝업·paywall_shown·이동 없이 '다시 눌러줘'.
      // 예전엔 잔액 0(parseWallet(null))으로 잔액 부족 팝업을 띄워, 별이 있는 유저를 충전으로 밀고 가짜 AddToCart 를 쐈다(사용자 결정 2026-10-09 B)
      if (!w) {
        setChecking(false);
        setWalletError(true);
        return;
      }
      // 로그인 전 맛보기 — 새 흐름 그룹 비로그인
      if (w.isGuest && w.entryArm === "new") {
        setChecking(false);
        const price = tarotPrice(spreadType, w.menuArm);
        savePendingDraw(localStorage, selection, drawn);
        setGuestPrice(price);
        setSheetPriceText(guestSheetLine(price, w.menuArm));
        setGuestMode(true);
        if (revealed) {
          // 이미 공개된 판(복원) — 바로 창
          openSheet(loginFailed ? "fail" : "auto", price);
        } else {
          // 새로 뽑은 판 — 공개 애니메이션이 끝나면 CardReveal 이 onRevealed 로 창을 올린다
          autoRanRef.current = true;
          setRevealed(drawn);
          trackUiEvent("cards_revealed", { meta: { spread: spreadType, count: drawn.length } });
        }
        return;
      }
      const price = tarotPrice(spreadType, w.menuArm);
      // 팝업 생략은 메뉴판 그룹만 — 남은 동의 선택(같은 탭에서 옛 그룹 계정으로 바꿈 · 스위치를 'legacy' 로 돌림)이어도 옛 그룹은 늘 확인 팝업
      if (selection.consented && w.menuArm === "menu" && w.balance >= price) {
        goToReading(drawn, price); // 동의 소모는 goToReading 안에서 · 안내(checking)는 화면이 넘어갈 때까지 켜 둔다
        return;
      }
      setChecking(false);
      setCost(price);
      setBalance(w.balance);
      // 다시 온 회원 — 로그인 전 맛보기에서 '가입 선물'을 보고 왔는데 선물이 없다(카카오 계정당 1회) → 팝업에 한 줄(스펙 §4)
      const via = resumeRef.current;
      const short = price - w.balance;
      const returning = (via === "login" || via === "home") && !w.giftUnused && short > 0;
      setReturningShort(returning ? short : null);
      if (returning) trackUiEvent("returning_short_shown", { meta: { short } });
      setShowConfirm(true);
    })();
  };

  // 공개 애니메이션이 끝났다 — 새로 뽑은 판(비로그인)은 로그인 창, 복원한 판은 '뽑은 뒤' 단계를 이어간다(버튼 없이, 한 번만 — 스펙 §3 ⑤)
  const onRevealed = () => {
    if (guestMode) {
      openSheet(loginFailed ? "fail" : "auto", guestPrice ?? 0);
      return;
    }
    if (autoRanRef.current || !revealed) return;
    autoRanRef.current = true;
    onDrawn(revealed);
  };

  // 처음부터 다시 뽑기 — 저장한 판을 버리고 의식으로
  const restart = () => {
    clearPendingDraw(localStorage);
    setRevealed(null);
    setGuestMode(false);
    setSheetOpen(false);
    setPendingDrawn(null);
    setReturningShort(null);
  };

  // 충전하러 간다 — 새 장치가 켜졌으면 진행을 저장해 결제 뒤 다시 뽑지 않게(스위치 'old' 동안엔 지금 prod 그대로)
  const openRecharge = () => {
    if (featuresOn && pendingDrawn) savePendingDraw(localStorage, selection, pendingDrawn);
    setRechargeSheetOpen(true);
  };

  return (
    <main className="flex flex-1 flex-col items-center w-full">
      {/* 단계 인디케이터 */}
      <div className="mt-14 mb-8">
        <ProgressSteps current={3} />
      </div>

      {revealed ? (
        <div className="w-full max-w-md mx-auto px-5 pb-16 flex flex-col items-center">
          <CardReveal drawn={revealed} accent={accent} onRevealed={onRevealed} />
          {/* 창·팝업을 닫았을 때 다시 잇는 버튼 */}
          {!sheetOpen && !showConfirm && !rechargeSheetOpen && !checking && (
            <div className="w-full mt-8 flex flex-col items-center gap-3">
              <button
                type="button"
                onClick={() => (guestMode ? openSheet("reopen", guestPrice ?? 0) : onDrawn(revealed))}
                className="w-full py-3.5 rounded-xl text-white font-bold text-[15px] active:scale-[0.98] transition"
                style={{ background: accent, boxShadow: `0 6px 18px ${accent}55` }}
              >
                {guestMode ? "로그인하고 풀이 보기" : "이 카드로 풀이 시작하기"}
              </button>
              <button type="button" onClick={restart} className="text-[12px] text-text-light/80 underline">
                처음부터 다시 뽑기
              </button>
            </div>
          )}
        </div>
      ) : (
        <CardDrawRitual
          cardCount={cardCount}
          slotLabels={labels}
          accent={accent}
          ritualLabel={info.label}
          completeLabel="고민 상담 시작하기"
          relationshipLayout={spreadType === "relationship_5"}
          backLabel="리딩 방법 선택"
          onBack={() => router.push("/tarot")}
          onComplete={onDrawn}
        />
      )}

      {showConfirm && cost !== null && (
        <StarConfirmModal
          spreadLabel={info.label}
          cost={cost}
          balance={balance}
          loading={false}
          accent={accent}
          surface={RECHARGE_SOURCE.tarotDraw}
          extra={
            returningShort !== null ? (
              <p className="mb-4 rounded-2xl bg-lilac-soft/50 px-4 py-3 text-center text-[12.5px] font-bold leading-relaxed text-eye-purple">
                다시 와줘서 반가워! 가입 선물은 처음 한 번뿐이라
                <br />
                별 {returningShort}개가 더 필요해
              </p>
            ) : undefined
          }
          onConfirm={() => {
            if (pendingDrawn) goToReading(pendingDrawn, cost); // 팝업이 보여 준 가격 그대로
          }}
          onCharge={openRecharge}
          onClose={() => setShowConfirm(false)}
        />
      )}
      {/* 🔴 닫혀 있으면 마운트하지 않는다 — 시트는 useTossPayment 를 호출해서
          마운트만으로 /api/auth/me + 토스 SDK 초기화가 돈다. 상시 마운트하면
          공개 지면(사주 운세 설명 20개 등) 방문자 전원에게 그 비용이 걸린다. */}
      {rechargeSheetOpen && cost !== null && (
        <RechargeSheet
          open
          returnTo={featuresOn ? resumeHref("payment") : "/tarot/draw"}
          need={cost}
          balance={balance}
          source={RECHARGE_SOURCE.tarotDraw}
          onClose={() => setRechargeSheetOpen(false)}
        />
      )}
      {sheetOpen && (
        <LoginSheet
          concern={selection.concern}
          priceText={sheetPriceText}
          kakaoHref={`/api/auth/login/kakao?next=${encodeURIComponent(resumeHref("login"))}`}
          failed={loginFailed}
          spread={spreadType}
          onDismiss={() => setSheetOpen(false)}
        />
      )}
      {/* fixed 덮개라 이 <main>(또는 조상)에 transform 이 남는 애니메이션(예: animate-fade-in)을 붙이면 fixed 의 기준이 화면이 아니라 그 요소가 돼 깨진다 — StarConfirmModal 이 포털을 쓰는 이유와 같다 */}
      {checking && (
        <div
          className="fixed inset-0 z-50 flex items-center justify-center"
          role="status"
          aria-live="polite"
        >
          <p className="px-4 py-2 rounded-full bg-white/90 text-text-light text-sm shadow-[0_4px_18px_rgba(90,62,140,0.15)]">
            잠시만…
          </p>
        </div>
      )}
      {/* 잔액 조회 실패 한 줄 — 탭을 막지 않는다(pointer-events-none) · 완료 버튼을 다시 누르면 사라지고 다시 읽는다 */}
      {walletError && (
        <div role="alert" className="fixed inset-x-0 bottom-36 z-50 flex justify-center px-4 pointer-events-none">
          <p className="rounded-full bg-white/95 px-4 py-2 text-[13px] font-bold text-eye-purple shadow-[0_4px_18px_rgba(90,62,140,0.15)]">
            잔액을 못 불러왔어 — 다시 눌러줘
          </p>
        </div>
      )}
      {/* 가입 선물 토스트 — 막지 않는다 */}
      {welcomeToast && (
        <div role="status" className="fixed inset-x-0 top-20 z-50 flex justify-center px-4 pointer-events-none">
          <p className="rounded-full bg-gold-soft px-4 py-2 text-[13px] font-bold text-eye-purple shadow-[0_4px_18px_rgba(232,194,106,0.35)]">
            🎁 가입 선물 별 {WELCOME_BONUS_STARS}개 받았어
          </p>
        </div>
      )}
    </main>
  );
}
```

```sql
--   login_fail 이 한쪽에 몰린다                 → 새 흐름 로그인 경로 고장
```

- [ ] **Step 5: `scripts/ab-bootstrap.mjs`**

```js
// 반반(A/B) 판정 부트스트랩 — 단위 행(방문자·가입자)에서 두 그룹 평균 차이의 95% 구간.
// 사용: node scripts/ab-bootstrap.mjs <rows.json> [--a new] [--b old] [--metric signed_up] [--metric rev48] [--iters 10000]
// rows.json = run-prod-query 출력(JSON 배열 — 각 행에 arm 과 지표 열). 지표를 안 주면 signed_up·rev48.
// 결정론적 난수(재실행해도 같은 구간). 판정 문구: 구간이 0 위 = "확실히 +", 0 아래 = "확실히 −", 걸치면 "걸침".
// 스펙: docs/superpowers/specs/2026-10-11-타로-로그인전-맛보기-design.md §7 (메뉴판 판정에도 --a menu --b legacy 로 쓸 수 있다)
import { readFileSync } from "node:fs";

const args = process.argv.slice(2);
const file = args[0];
if (!file) {
  console.error("사용: node scripts/ab-bootstrap.mjs <rows.json> [--a new] [--b old] [--metric m]... [--iters N]");
  process.exit(1);
}
const opt = (k, d) => {
  const i = args.indexOf(`--${k}`);
  return i >= 0 ? args[i + 1] : d;
};
const metrics = args.flatMap((a, i) => (a === "--metric" ? [args[i + 1]] : []));
const A = opt("a", "new");
const B = opt("b", "old");
const iters = Number(opt("iters", "10000"));
const rows = JSON.parse(readFileSync(file, "utf8"));

// mulberry32 — 시드 고정
let seed = 20261011;
const rand = () => {
  seed = (seed + 0x6d2b79f5) | 0;
  let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
};
const mean = (xs) => xs.reduce((s, x) => s + x, 0) / xs.length;

for (const m of metrics.length ? metrics : ["signed_up", "rev48"]) {
  const a = rows.filter((r) => r.arm === A).map((r) => Number(r[m]));
  const b = rows.filter((r) => r.arm === B).map((r) => Number(r[m]));
  if (!a.length || !b.length) {
    console.log(JSON.stringify({ metric: m, error: "그룹이 비어 있다", n_a: a.length, n_b: b.length }));
    continue;
  }
  const diffs = new Array(iters);
  for (let i = 0; i < iters; i++) {
    let sa = 0;
    let sb = 0;
    for (let j = 0; j < a.length; j++) sa += a[Math.floor(rand() * a.length)];
    for (let j = 0; j < b.length; j++) sb += b[Math.floor(rand() * b.length)];
    diffs[i] = sa / a.length - sb / b.length;
  }
  diffs.sort((x, y) => x - y);
  const lo = diffs[Math.floor(0.025 * iters)];
  const hi = diffs[Math.ceil(0.975 * iters) - 1];
  const verdict = lo > 0 ? "확실히 +" : hi < 0 ? "확실히 −" : "걸침";
  console.log(
    JSON.stringify({ metric: m, a: A, b: B, n_a: a.length, n_b: b.length, mean_a: mean(a), mean_b: mean(b), diff: mean(a) - mean(b), ci95: [lo, hi], verdict })
  );
}
```

**계획과 달라진 것**
- 로그인 전 가격·위기 배너는 **새 흐름에만** — 계획은 가격을 `wallet.isGuest`(비로그인 전부), 위기 배너를 스위치 무관·회원 포함으로 잡았다. 배너는 기존 high 정규식의 연애·일상 문장 오탐 때문에 좁혔다(old 에선 안 뜬다 — Task 15 Step 2 의 배너 확인은 새 흐름에서만). 스펙 §5-5
- 새 흐름 비로그인 판정은 `isNewFlowGuest`(`lib/tarot/entry-ab.ts`) 하나 — 홈·`/tarot`·가격 줄·뽑기 화면이 제각각 쓰던 것을 모았다
- 롤백 안전 — `entryFeaturesOn()` 이 꺼지면 뽑기 화면은 복원·이어가기·실패 표시를 안 하고, 홈은 저장된 판을 지운다
- 이어가기 주소 `?resume=1` → `?resume=login|payment|home` · 금액 `₩X` → `X원부터` · 로그인 창에 약관 동의 줄 · 카드 공개는 페이드 인(뒤집기 아님)
- 로그인 복귀 이동 경합 — `AuthBootstrap` 이 `/tarot/draw` 주소를 안 건드리고 뽑기 화면이 `replaceState` 로 직접 정리
- 카드 공개 버튼 줄 sticky(`b3b879a8`) — 7장 판에서 하단 탭 아래로 밀리던 것(자동 게이트로 못 잡고 화면 확인에서 발견)
- 감시 SQL — 로그인 실패는 새 그룹 왕복 실패율로, 가격 어긋남은 배포 24시간 뒤만, 노출 어긋남 진단 추가. 판정 `rev48` 은 첫 방문 후 48시간 창(스펙 §7 정정)
