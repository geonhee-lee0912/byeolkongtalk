# 타로톡 질문 메뉴판 + 별 경제 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 타로톡의 스프레드 고르기 화면을 질문 메뉴판(맛보기 → 3장 → 깊게 → 끝까지)으로 바꾸고, 별 패키지·타로/사주 가격을 그 사다리에 맞춘다. 맛보기가 끝나면 같은 질문의 깊게 상품을 정가로 이어서 보게 한다.

**Architecture:** 상품 32개는 `lib/tarot/menu.ts` 한 곳의 데이터다(전부 기존 스프레드 재포장 — 가격은 `SPREAD_INFO`, 카드 자리는 `getPositionLabels` 에서 읽고 다시 정의하지 않는다). 가격 표시 규칙·비교 수치는 순수 함수 `lib/tarot/menu-price.ts`, sessionStorage 저장은 `lib/tarot/menu-session.ts`. 서버는 그대로 권위다 — 차감은 `/api/consultations/tarot` 가 `SPREAD_INFO` 로 하고, "이어서 깊게"는 기존 tarot-fresh 이어가기 경로를 탄다. DB 마이그레이션 없음.

**Tech Stack:** Next.js 16 App Router(클라이언트 컴포넌트) · TypeScript strict · Tailwind v4 · node:test + tsx · Supabase(service role)

**스펙:** `docs/superpowers/specs/2026-10-05-타로톡-메뉴판-별경제-design.md` (이름 검수 반영 `06cea7c7`)

**prod:** 사용자가 명시적으로 go 하기 전엔 배포하지 않는다. 스펙 §12 의 10-10~11 목표는 계획 시점(10-09)에 다시 정해야 한다.

 * 유료: 모자란 만큼 — 선물을 아직 안 썼으면 "선물 쓰면 ⭐N만 더", 썼으면 "⭐N만 더", 충분하면 "지금 잔액으로 바로".

    sub: w.giftUnused ? `선물 쓰면 ⭐${short}만 더` : `⭐${short}만 더`,

  onTeaser: () => void;

  }, []);

    else onClose();
