# 별자리 인터랙션 재설계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 별자리 상세 뷰를 "지도를 덮는 모달(OneToOnePanel)"에서 **리스트 인터랙션(아코디언)과 지도 인터랙션(줌+하단 카드)으로 분리**하고, 별을 둥근 원으로 바꾸며 배경 신수 확대·관계선 투명도를 조정한다.

**Architecture:** 선택 상태를 `selection: {id, source: 'map'|'list'} | null` 하나로 두어 상호배타. `source==='list'` 면 순위 리스트의 해당 행이 아코디언으로 펼쳐지고 지도는 중립(줌·dim 없음). `source==='map'` 이면 지도가 나+상대 중점 기준으로 줌 인 + 나머지 dim, 상세는 지도 **바로 아래** 카드로. 상세 내용은 공용 `InyeonDetail` 컴포넌트 하나로 두 곳에 렌더. 기존 `OneToOnePanel` 은 삭제.

**Tech Stack:** Next.js 16 / React 19 / TypeScript strict, Tailwind v4, SVG(viewBox 0..100), node:test(`node --import tsx --test`).

## 설계 근거 (왜 분리하나)

지도는 페이지 상단, 순위 리스트는 그 아래에 있다. "하나의 선택으로 지도 하이라이트 + 리스트 아코디언을 동시에" 움직이면, 리스트 하위 행을 누를 때 지도 하이라이트가 화면 밖(위)이라 **둘을 한 화면에 못 본다**. 그래서 두 인터랙션을 자기완결적으로 분리한다:

- **리스트**: 행 탭 → 그 자리 아코디언으로 전체 근거. 지도 안 건드림(어차피 화면 밖).
- **지도**: 별 탭 → 나+상대 줌·하이라이트, 나머지 dim, 상세는 지도 바로 아래(둘이 한눈에).

`selection` 하나에 `source` 태그만 붙여 상호배타로 두면 상세는 **항상 한 곳에만** 뜬다(중복 없음).

```ts
/** 두 점(나·상대)의 중점을 화면 중심에 두고, 거리에 맞춰 배율을 정해 둘 다 뷰에 담는 줌 변환.
 *  focusTransform 이 한 점만 중심에 두는 것과 달리 쌍(pair)을 프레이밍한다. */
export function focusPair(
  a: Point,
  b: Point,
  opts?: { margin?: number; maxScale?: number; center?: number }
): { tx: number; ty: number; s: number } {
  const margin = opts?.margin ?? 22; // 쌍 양옆 여백(viewBox 단위) — 라벨/노드 반경 확보
  const maxScale = opts?.maxScale ?? 2;
  const mid = { x: (a.x + b.x) / 2, y: (a.y + b.y) / 2 };
  const dist = Math.hypot(a.x - b.x, a.y - b.y);
  const s = round(Math.max(1, Math.min(maxScale, 100 / (dist + margin))));
  return focusTransform(mid, s, opts?.center);
}
```
