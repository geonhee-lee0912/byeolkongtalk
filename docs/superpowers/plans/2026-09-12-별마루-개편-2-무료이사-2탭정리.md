# 별마루 개편 Phase 2 — 무료상품 이사 + 2탭 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "사주 운세" 2탭(`/fortune`)을 **유료 전용**으로 만들고, 유저별 LLM `오늘의 운세`(`/fortune/daily`)를 **폐지**한다(무료 오늘 사주는 별마루 룰 버전이 대체 → DAU LLM 원가 소멸).

**Architecture:** 카탈로그 단일 원천 `lib/fortune/types.ts`에서 `daily`를 진열대(FORTUNE_LIST)·무료 칩에서 내리고 `active:false`로 은퇴시킨다(good_days 선례와 동일 기제 — `create/route.ts`의 active 가드가 생성을 자동 차단). `/fortune` 페이지의 무료 칩 하드코딩 카드(MBTI·별자리)를 제거한다(진입점은 이미 별마루 hub가 제공). `/fortune/daily` 전용 페이지는 `/byeolmaru`로 서버 리다이렉트. daily를 무료 리텐션 훅으로 쓰던 크로스셀·광고 랜딩을 끊는다. **daily 리포트 생성기(`lib/fortune/daily-report.ts`)·프롬프트·모델·렌더러는 별마루 유료 오늘 사주가 재사용하므로 절대 건드리지 않는다.**

**Tech Stack:** Next.js 16(App Router, `redirect()` from `next/navigation`), TypeScript strict, `node:test` 계약 테스트.

## 결정 사항 (승인 시 확정 — 기본값은 권고안)

- **D1. `/fortune/daily` 폐지 방식** = 전용 페이지를 `/byeolmaru`(허브)로 **서버 리다이렉트**. (삭제 대신 리다이렉트 → 옛 북마크·광고 링크가 무료 오늘 사주의 새 집으로 착지. 허브는 로그인 게이트를 자체 처리.)
- **D2. counsel 크로스셀의 daily 훅** = `FORTUNE_CONFIG.daily`(무료 리텐션 훅)를 **별마루 오늘 사주 수동 카드**로 교체(무료 훅 취지 유지, 목적지만 `/byeolmaru`).
- **D3. `create/route.ts` 의 daily 생성 분기** = **그대로 둔다**(active:false 로 도달 불가한 죽은 코드. good_days 선례가 생성 분기를 보존. 옛 daily 리딩 재열람 경로도 유지).
- **D4. `/api/fortune/daily-status`·`lib/fortune/daily-lookup.ts`** = **그대로 둔다**(daily 페이지 리다이렉트 후 앱에서 미호출되는 죽은 라우트지만 무해. 최소 변경 원칙).
- **D5. `daily` config 레코드·category** = **유지**(§절대 보존).
