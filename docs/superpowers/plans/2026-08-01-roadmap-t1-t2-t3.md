## T3 — 페르소나 조정 → 모델 대체 테스트

**착수 시 조사부터 새로 설계한다.** (2026-08-01: 이탈 분석 접근 1건을 시도했다가 폐기했다 — 재활용하지 않는다.)

### 3-1. 페르소나 조사
- 착수 시점에 무엇을 어떻게 조사할지 새로 정한다
- 유지되는 방법론 제약: **실제 대화 원문 읽기 기반**. 정규식·LLM judge 로 화법을 재려던 시도는 오탐 100% 전력 — 정규식은 읽을 표본을 고르는 필터로만 ([[measure-persona-by-reading-not-matching]])

### 3-2. 페르소나 조정
- **조정은 1회로 끊는다** ([[persona-tuning-pendulum]] — 조이면 반대편 과잉으로 튐)
- T1 배포 주와 분리. 판정은 그 조정의 메커니즘 지표(객관 단언 계열 — LLM judge 불신)
- QA 하네스 자체 검증 + 페르소나 수정 후 dev 서버 재시작(모듈 캐시)
- ⚠️ 코어 편집 = 전 종목 전역 변경 → 광범위 회귀 QA 필수

### 3-3. E5b 상품별 모델 믹스 (마지막)
- 무료(오늘의 운세)=저가 모델, 고민톡=고성능. 후보 GPT·DeepSeek 계열 — **착수 시점에 라인업·단가·한국어 품질 조사 후 확정**
- 대화형 모델 교체 = 페르소나 전면 재검증 + **새 `PROMPT_VERSION` 코호트** — 그래서 3-2 가 안정된 뒤
