# 별마루 개편 Phase 3-1 — 비로그인 구경 모드 + /byeolmaru OG (Loop 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 별마루 hub를 **비로그인도 구경**할 수 있게(카드 그리드 미리보기 + 탭하면 로그인 게이트) + `/byeolmaru` **전용 공유 OG 카드**를 만든다 → 공유 링크가 로그인 벽에 부딪혀 바이럴 루프가 끊기던 문제 해소(스펙 §7 Loop 1).

**Architecture:** calendar API(`/api/byeolmaru/calendar`)는 로그인+프로필+생일을 하드 전제로 401/404를 준다 — **API는 안 건드리고**(원가 0 철학), `ByeolmaruHub`가 401(`need_login`)일 때 로그인 벽 한 장 대신 **정적 게스트 그리드**(카드 이름+한 줄 소개)를 렌더한다. 개인화(등급·dots·출석·크로스셀)는 0, 별마루-개인화 카드(오늘 사주·오늘 타로·우리 오늘)는 탭하면 `/login` 게이트, 무료 툴(MBTI·별자리)은 로그인 없이 바로 진입. `/byeolmaru` OG는 파일 컨벤션 `opengraph-image.tsx`(byeoljari 선례) + noindex 유지한 채 openGraph 블록으로 브랜디드 카드.

**Tech Stack:** Next.js 16(App Router, `next/og` ImageResponse, 파일 컨벤션 OG), React 19 client component, TypeScript strict.

- `components/byeolmaru/ByeolmaruHub.tsx`: `refresh()`(`:39-50`)가 `/api/byeolmaru/calendar`를 fetch → 401이면 `setState({kind:"need_login"})`(`:42`), 404면 `no_profile`(`:43`). 렌더에서 `need_login`(`:66-71`)은 **"로그인하러 가기" 벽 한 장**만, `no_profile`(`:72-77`)은 "생일 입력" 벽. 실제 그리드(`:85-127`)는 `ready`에서만.
- ready 그리드 구성: 헤더(`:87-90`, 오늘 간지), AttendanceStrip(`:92`), 오늘 사주 히어로 Link→`/byeolmaru/saju`(`:94-105`), DailyCardBlock(`:107`), 2열 grid[우리오늘→`/byeolmaru/woori`, 사주 MBTI→`/fortune/saju-mbti`, 별 인연 지도→`/fortune/byeoljari`](`:109-122`), CrossSellCard(`:124`).
- MBTI(`/fortune/saju-mbti`)·별자리(`/fortune/byeoljari`)는 **로그인 없이 쓰는 무료 툴**(게스트도 바로 진입 OK). 오늘 사주·오늘 타로·우리 오늘은 별마루 개인화(로그인+생일 필요).
- `/byeolmaru` 메타: `app/byeolmaru/page.tsx:6-9`가 `noindexMetadata({title:"별마루", description:"..."})` — openGraph 미선언이라 루트 범용 카드 상속. 전용 OG 없음.
- OG 선례: `app/opengraph-image.tsx`(루트 범용, `next/og` ImageResponse + Pretendard CDN + 다크 그라데이션 + 골드 별 파티클), `app/fortune/byeoljari/[shareId]/opengraph-image.tsx`(동일 패턴) + `app/fortune/byeoljari/[shareId]/layout.tsx:8-24`(**noindex + openGraph title/desc/siteName/locale/type 재선언**, images는 파일 컨벤션 위임).
- 🔴 메타데이터 병합 함정(`lib/seo/metadata.ts:5-10`): 페이지에서 `openGraph:{title}`만 주면 루트 siteName·locale·type이 조용히 사라진다 → openGraph 블록엔 siteName·locale·type을 **반드시 다 재선언**(byeoljari layout 선례 그대로).

## Task 1: 비로그인 게스트 구경 그리드 (ByeolmaruHub)

TDD가 자연스럽지 않은 클라 UI 변경이라, **정적 게스트 그리드 컴포넌트를 추가**하고 tsc/build + 브라우저 렌더로 검증한다.

- [ ] **Step 1: 게스트 카드 정의 + 그리드 렌더 추가**

`ByeolmaruHub.tsx` 안(컴포넌트 밖, 파일 상단 `DOT` 상수 근처)에 게스트 카드 목록과 렌더 함수를 추가한다. 개인화 카드는 `/login?next=/byeolmaru`로 게이트, 무료 툴은 직접 링크.

```tsx
// 비로그인 구경 모드 — 카드 그리드(뭐가 있는지 + 한 줄)만 보이고, 개인화 카드는 탭하면 로그인 게이트.
// 개인화 0(스펙 §7 Loop 1). 무료 툴(MBTI·별자리)은 로그인 없이 바로 진입.
const GUEST_CARDS: { emoji: string; title: string; desc: string; href: string; gated: boolean }[] = [
  { emoji: "🗓", title: "오늘 사주", desc: "오늘 잘 맞는 날인지, 살짝 챙길 날인지", href: "/login?next=/byeolmaru", gated: true },
  { emoji: "🃏", title: "오늘 타로", desc: "카드 한 장으로 오늘을 가볍게 짚어봐", href: "/login?next=/byeolmaru", gated: true },
  { emoji: "💞", title: "우리 오늘", desc: "그 사람과 나, 오늘 둘 사이 흐름", href: "/login?next=/byeolmaru", gated: true },
  { emoji: "🧭", title: "사주 MBTI", desc: "사주로 보는 내 유형", href: "/fortune/saju-mbti", gated: false },
  { emoji: "✨", title: "별 인연 지도", desc: "내 인연들을 별자리로", href: "/fortune/byeoljari", gated: false },
];

function GuestPeek() {
  return (
    <main className="mx-auto w-full max-w-md space-y-4 p-4">
      <header>
        <h1 className="font-display text-2xl text-eye-purple">별마루</h1>
        <p className="text-sm text-text-light">무료로 다 보는 곳 · 오늘 네 하루를 별콩이가 짚어줄게</p>
      </header>
      <div className="grid grid-cols-2 gap-3">
        {GUEST_CARDS.map((c) => (
          <Link
            key={c.title}
            href={c.href}
            onClick={() => trackUiEvent("byeolmaru_guest_peek_tap", { meta: { card: c.title, gated: c.gated } })}
            className="rounded-2xl bg-cream-warm p-4"
          >
            <div className="font-display text-base text-eye-purple">{c.emoji} {c.title}</div>
            <div className="mt-1 text-xs text-text-light">{c.desc}</div>
            {c.gated && <div className="mt-2 text-[11px] text-lilac-deep">로그인하면 열려 →</div>}
          </Link>
        ))}
      </div>
      <Link href="/login?next=/byeolmaru" className="block rounded-xl bg-lilac-deep px-4 py-3 text-center text-cream">
        로그인하고 내 오늘 보기
      </Link>
    </main>
  );
}
```

- [ ] **Step 2: noindex 유지한 채 openGraph 문구 선언(layout)**

`app/fortune/byeoljari/[shareId]/layout.tsx:8-24`를 선례로, `app/byeolmaru/layout.tsx`를 만들어 openGraph title/description을 선언한다. 🔴 `lib/seo/metadata.ts:5-10` 병합 함정 — `siteName`·`locale`·`type`을 반드시 재선언(안 하면 루트값 소실). images는 파일 컨벤션(Step 1)에 위임하므로 **openGraph.images는 선언하지 않는다**.

    locale: "ko_KR",

- [ ] **Step 3: page.tsx metadata 중복 정리**

`app/byeolmaru/page.tsx:6-9`의 `export const metadata = noindexMetadata(...)`가 layout과 title/robots가 겹친다. **page의 metadata는 유지하되**(title "별마루"·description은 페이지 문서용), layout이 openGraph를 얹는 구조로 공존 가능(Next는 layout+page metadata를 병합, page가 title을 덮음). tsc/lint 충돌 없으면 그대로, `noindexMetadata`가 openGraph를 비우지 않는지만 확인(안 비움 — 애초에 openGraph 미선언). 만약 page의 title이 layout openGraph.title을 덮어써 카드 제목이 어긋나면, page title은 그대로 두고 layout openGraph.title이 og:title을 담당(별개 필드)하므로 문제없음.
