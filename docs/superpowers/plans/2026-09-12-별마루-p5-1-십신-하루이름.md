# 별마루 P5-1 — 십신 하루 이름 + 원인 마크 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 별마루 하루 등급이 `잘 맞는 날 / 무난한 날 / 살짝 챙길 날` 3종뿐이라 30일 달력이 평평한 문제를, **십신 10종 하루 이름 + 원인 마크(✧◇△＋)**로 갈라 해소한다.

**Architecture:** 판정 엔진(`day-score.ts`)은 **건드리지 않는다.** 십신은 지금 점수가 쓰는 `elementRelation`(5종)을 음양으로 쪼갠 것이라(생아=정인·편인 …) 새 계산이 아니다. 신규 순수 모듈 `lib/byeolmaru/day-label.ts` 가 `tenGod` → 이름/한 줄, `DayFactors` → 마크를 매핑하고, `buildCalendar` 가 `DayCell` 에 실어 내린다. 표시는 기존 화면 3곳(`CalendarGrid`·`DayDetailCard`·`ByeolmaruHub`)에 최소 배선한다 — **허브 전면 재조립은 P5-3 소관**이다.

**Tech Stack:** TypeScript strict · Next.js 16 App Router · `node:test` + `node:assert/strict` (러너 `node --import tsx --test`) · Tailwind v4 `@theme` 토큰

**Spec:** `docs/superpowers/specs/2026-09-12-별마루-p5-화면개편-design.md` §5

export interface DayMark {
  glyph: string;
  label: string;
}

/**
 * 그날을 그렇게 만든 원인 마크. 달력 셀 우상단 + 상세 칩에 쓴다.
 * 우리 오늘 셀의 ✨끌림·🔗결속과 같은 어법 — 두 탭이 한 문법을 쓰게 한다.
 * 순서는 고정(천간합 → 육합 → 충 → 빈 곳)이라 같은 날이 늘 같은 순서로 보인다.
 */
export function dayMarks(f: DayFactors): DayMark[] {
  const out: DayMark[] = [];
  if (f.heavenlyCombo) out.push({ glyph: "✧", label: "천간합" });
  if (f.sixCombo) out.push({ glyph: "◇", label: "육합" });
  if (f.clash) out.push({ glyph: "△", label: "충" });
  // scarce(1개)는 마크를 붙이지 않는다 — "아예 없던 게 채워지는" 날만 눈에 띄게 한다.
  if (f.scarcity === "absent") out.push({ glyph: "＋", label: "빈 곳 채움" });
  return out;
}

### Task 6: 실제 일진으로 라벨 빈도 재측정

> 스펙 §15-7: 앞선 분포는 **조합 전수**라 실제 빈도가 아니다. 천간합·육합·충은 60갑자 중 특정 짝일 때만 나오므로 실제 달력에선 더 드물다. 마크가 **너무 안 뜨거나 너무 자주 뜨면** 글리프 설계를 다시 봐야 하므로 여기서 실측한다.

**Files:**

- [ ] **Step 1: 측정 스크립트를 만든다**

`scripts/byeolmaru-label-freq.ts`:

```ts
// 별마루 하루 이름·마크의 실제 30일 빈도 측정(P5-1 검증용, 읽기 전용·네트워크 없음).
// 실행: node --import tsx scripts/byeolmaru-label-freq.ts
import { calcSaju, calcTemporalLuck, baseDateForKst } from "@/lib/saju/calc";
import { buildCalendar } from "@/lib/byeolmaru/calendar";

const BIRTHS = [
  { year: 1994, month: 5, day: 17, hour: 14 },
  { year: 1988, month: 11, day: 3, hour: 9 },
  { year: 2000, month: 2, day: 29, hour: 23 },
  { year: 1979, month: 8, day: 8, hour: 6 },
  { year: 2003, month: 12, day: 25, hour: 18 },
];
const TODAY = "2026-09-12";

const markCount: Record<string, number> = {};
const nameCount: Record<string, number> = {};
let cells = 0;

for (const b of BIRTHS) {
  const saju = calcSaju({ ...b, isLunar: false });
  const t = calcTemporalLuck(baseDateForKst(TODAY), b.year, { includeMonth: true });
  if (!t.dailyLuck) continue;
  for (const c of buildCalendar(saju, t.dailyLuck, TODAY).slice(0, 30)) {
    cells++;
    nameCount[c.name] = (nameCount[c.name] ?? 0) + 1;
    if (c.marks.length === 0) markCount["(없음)"] = (markCount["(없음)"] ?? 0) + 1;
    for (const m of c.marks) markCount[m.label] = (markCount[m.label] ?? 0) + 1;
  }
}

console.log(`표본 ${BIRTHS.length}명 × 30일 = ${cells}칸\n`);
console.log("하루 이름:");
Object.entries(nameCount).sort((a, b) => b[1] - a[1])
  .forEach(([k, v]) => console.log(`  ${k.padEnd(16)} ${v}칸 (${((v / cells) * 100).toFixed(1)}%)`));
console.log("\n마크:");
Object.entries(markCount).sort((a, b) => b[1] - a[1])
  .forEach(([k, v]) => console.log(`  ${k.padEnd(10)} ${v}칸 (${((v / cells) * 100).toFixed(1)}%)`));
```
