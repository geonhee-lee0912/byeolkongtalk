# 사주 상품 설명 페이지 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/fortune` 에서 상품을 누르면 바로 뜨던 결제 모달 앞에, 같은 URL 에서 **설명을 읽고 그 자리에서 사는** 지면을 깔고, 상품별 일러스트 20컷을 새로 제작해 랜딩·결과 화면에 건다.

**Architecture:** `/fortune/[type]` 을 서버 컴포넌트로 돌리고 기존 구매 로직은 `FortunePurchasePanel` 클라 섬으로 **이동만** 한다. 라우트 신설 0 이라 `cfg.href`·크로스셀·PV 역매핑이 무회귀다. 목차는 지어내지 않고 코드 원천에서 읽거나(공용 12종) 원천 대조 테스트로 묶는다(전용 7종). compat 2종·MBTI 는 같은 랜딩 셸에 구매 모듈만 갈아 끼운다.

**Tech Stack:** Next.js 16 App Router (RSC) · React 19 · TypeScript strict · Tailwind v4 · `node --import tsx --test` · higgsfield `nano_banana_pro`

**정본 스펙:** `docs/superpowers/specs/2026-09-27-사주-상품-설명-페이지-design.md`

### Task 1: `GENERIC_GUIDE_SPEC` 분리 (프롬프트 문자열 불변 보장)

`lib/fortune/prompt.ts` 의 `SECTION_GUIDE` 에서 12개 종목이 `genericGuide({...})` 에 객체 리터럴을 **인라인으로** 넘긴다. 그 리터럴들을 상수로 끌어내 랜딩이 heading 을 읽을 수 있게 한다. **프롬프트 출력 문자열은 한 글자도 바뀌면 안 된다** — 바뀌면 전 종목 리포트 품질이 흔들린다.

- [ ] **Step 2: 타입과 상수를 만든다**

`lib/fortune/prompt.ts` 의 `genericGuide` 함수 **바로 위**에 추가:

```ts
/** 공용 섹션 리포트의 구성 원안 — 프롬프트(genericGuide)와 랜딩 목차(lib/fortune/outline.ts)가
 *  같은 원천을 본다. 여기 heading 을 고치면 리포트와 랜딩이 함께 움직인다(드리프트 불가). */
export interface GenericGuideSpec {
  title: string;
  intro: string;
  sections: { heading: string; spec: string }[];
  note: string;
  tone?: string;
}
```

그리고 `genericGuide` 의 인자 타입을 `opts: GenericGuideSpec` 으로 바꾼다(본문은 그대로).

- [ ] **Step 3: 12개 리터럴을 상수로 옮긴다**

`SECTION_GUIDE` **선언 앞**에 `GENERIC_GUIDE_SPEC` 을 만들고, 지금 `nature_self: genericGuide({ ... })` 안에 있던 객체 리터럴을 **잘라내 그대로** 옮긴다. 12개 전부(`nature_self` `talent_path` `user_manual` `element_balance` `love_self` `love_year` `marriage` `wealth_vessel` `wealth_year` `career_timing` `fact_bomb` `past_life`).

⚠️ `as const` 때문에 `sections` 가 readonly 가 된다. `genericGuide` 가 `forEach` 만 쓰므로 동작엔 문제없지만 타입이 안 맞으면 `GenericGuideSpec` 의 `sections` 를 `readonly { heading: string; spec: string }[]` 로 바꾼다.

```tsx
"use client";

// 구매 모듈이 뷰포트에 들어온 순간 1회. "설명을 읽고 내려왔나"를 CTA 점프와 분리해 잰다.
import { useEffect, useRef } from "react";
import { trackUiEvent } from "@/lib/analytics/ui-events";

export default function PurchaseReachedBeacon({ type }: { type: string }) {
  const ref = useRef<HTMLDivElement>(null);
  const sent = useRef(false);

  useEffect(() => {
    const el = ref.current;
    if (!el || sent.current) return;
    const io = new IntersectionObserver((entries) => {
      if (entries.some((e) => e.isIntersecting) && !sent.current) {
        sent.current = true;
        trackUiEvent("fortune_landing_purchase_reached", { meta: { type } });
        io.disconnect();
      }
    });
    io.observe(el);
    return () => io.disconnect();
  }, [type]);

  return <div ref={ref} aria-hidden className="h-px" />;
}
```
