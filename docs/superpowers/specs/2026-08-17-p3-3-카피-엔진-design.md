# 별자리(byeoljari) P3-3 카피 엔진 — 설계 (2026-08-17)

P3-3의 남은 조각. 1:1 관계 뷰의 문구를 **관계분류(친구·연인·지인·윗사람)에 따라 해석이 바뀌도록** 풍부하게 채운다. 룰 100%·LLM 0(원가0·결정적).

## 0. 현재 상태 / 문제

- `OneToOnePanel`이 보여주는 것: ①관계분류 뱃지 ②오행관계 한 줄(`elementRelationLabel`) ③"내가 보는 그"=십신 라벨(`TEN_GOD_LABEL`) ④"그가 보는 나"=역방향 십신(골드) ⑤케미✨/결속🔗.
- **문제:** ③④가 `TEN_GOD_LABEL[tenGod]` 단일 테이블이라 **친구든 연인이든 윗사람이든 같은 문구**가 나온다. 스펙(2026-08-15) §3의 "관계분류 = 해석까지 바뀜"이 미구현.
- 방향성은 이미 처리됨: `orientEdge(edge, pivotId)`가 pivot 기준으로 `iSeeThem`/`theySeeMe`/`element`를 정렬(pivot이 `edge.b`면 label 스왑 + `invertElementRelation`).

## 1. 카피 축 (확정)

- **십신 10종**(방향성): 비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인. "내가 보는 그"는 내 일간→그의 십신, "그가 보는 나"는 그의 일간→내 십신(비대칭).
- **관계분류 4종**: `friend`·`lover`·`acquaintance`·`senior`.
- **오행관계 5종**(비화·생아·아생·극아·아극): 관계 전체의 **큰 흐름 요약 한 줄**. **관계분류 무관 공통**(십신 40칸이 이미 관계 색을 담으므로 오행까지 쪼개면 중복). 현재 `ELEMENT_RELATION_LABEL` 유지.

**핵심 = 관계분류(4) × 십신(10) = 40칸 문구 테이블.** "내가 보는 그"·"그가 보는 나" 둘 다 **같은 관계분류**(그 사람의 분류) 안에서, 방향만 다른 십신으로 이 테이블을 각각 룩업.

## 2. 40칸 카피 테이블 (전량 · 별콩이 톤: 반말·낙인 제거·완곡)

`RELATION_TEN_GOD_COPY[relationType][tenGod]`:

| 십신 (성격) | friend(친구) | lover(연인) | acquaintance(지인) | senior(윗사람) |
|---|---|---|---|---|
| **비견** (대등·닮음) | 말 안 해도 통하는 친구 | 편하게 닮아가는 사람 | 왠지 나랑 비슷한 사람 | 결이 닮은 선배 |
| **겁재** (경쟁·자극) | 티격태격해도 붙어 다니는 친구 | 밀당이 은근 재밌는 상대 | 묘하게 경쟁되는 사람 | 자꾸 비교하게 되는 선배 |
| **식신** (베풂·편안) | 챙겨주고 싶은 친구 | 다 해주고 싶은 사람 | 나도 모르게 돌봐주는 사람 | 살뜰히 챙기게 되는 분 |
| **상관** (표현·끼) | 내 텐션 올려주는 친구 | 나를 반짝이게 하는 사람 | 내 얘기 술술 꺼내게 하는 사람 | 내 재능 알아봐 주는 분 |
| **편재** (주도·활달) | 내가 앞장서게 되는 친구 | 내가 리드하는 사람 | 내가 먼저 나서는 사람 | 내가 먼저 다가가는 분 |
| **정재** (아낌·안정) | 오래 곁에 두고 싶은 친구 | 곱게 아끼는 사람 | 잘 지내고 싶은 사람 | 신뢰를 쌓고 싶은 분 |
| **편관** (긴장·강) | 정신 번쩍 들게 하는 친구 | 자꾸 밀당하게 되는 상대 | 괜히 신경 쓰이는 사람 | 어렵지만 날 키우는 어른 |
| **정관** (규율·보호) | 믿고 기댈 친구 | 듬직하게 안아주는 사람 | 은근히 의지되는 사람 | 배울 게 많은 어른 |
| **편인** (영감·독특) | 생각을 넓혀주는 친구 | 새로운 세계를 보여주는 사람 | 묘하게 끌리는 사람 | 영감을 주는 멘토 |
| **정인** (보살핌·따뜻) | 마음이 놓이는 친구 | 포근하게 감싸주는 사람 | 편히 기대게 되는 사람 | 따뜻하게 이끌어 주는 분 |

- 톤 규칙: 친구="~친구", 연인="~사람/상대", 지인="~사람", 윗사람="~분/선배/어른/멘토". 단정적 예언 없음(관계 성격 묘사라 완곡체 OK). 십신 한자명·민간 낙인(편관=칠살 등) 노출 금지.

## 3. 오행 요약 5종 (공통 · 현재 유지)

`ELEMENT_RELATION_LABEL`(display.ts) 그대로 — 나 기준, 관계분류 무관:
- 비화: "나란히 선 비슷한 결" · 생아: "나를 북돋아 주는 기운" · 아생: "내가 힘을 실어 주는 사이" · 극아: "나를 팽팽하게 다잡는 기운" · 아극: "내가 이끌어 가는 흐름"

## 4. 데이터 흐름

카피 조립은 **클라(프레젠테이션) 레이어**에서 한다 — pivot(나)이 클라에서 정해지고(meId), 관계분류는 target(그)의 것이라 서버는 "누가 pivot"인지 모른다. 서버는 십신 **코드**까지만 실어 보낸다.

1. **`types.ts` `GraphEdge`에 십신 코드 추가**: `tenGodAtoB: string; tenGodBtoA: string;` (기존 `labelAtoB`/`labelBtoA` 중립 라벨은 **폴백용으로 유지**).
2. **API route**(`[shareId]/route.ts`): `pairRelation`이 이미 `tenGodAtoB`/`tenGodBtoA`(TenGod)를 반환 → edge에 그대로 실음(문자열로).
3. **`orientEdge`**(layout.ts): 십신도 pivot 기준 방향 정렬. 반환에 `iSeeThemTenGod`/`theySeeMeTenGod` 추가. (오행처럼 뒤집는 게 아니라 a↔b 스왑만: pivot이 `edge.a`면 iSeeThem=`tenGodAtoB`, pivot이 `edge.b`면 iSeeThem=`tenGodBtoA`.) 기존 `iSeeThem`/`theySeeMe`(중립 라벨)도 폴백용 유지.
4. **`lib/byeoljari/copy.ts`**(신규): 40칸 테이블 + 방어적 룩업 `relationTenGodCopy(relationType: string, tenGod: string): string | null`. relationType이 enum 밖이거나 tenGod 조회 실패면 `null` 반환(크래시 금지 — [[recurring-crash-class-config-by-dynamic-key]]).
5. **`OneToOnePanel`**: `relationTenGodCopy(target.relationType, oriented.iSeeThemTenGod) ?? oriented.iSeeThem`(COPY 우선, 없으면 중립 라벨 폴백). "그가 보는 나"도 동일하게 `theySeeMeTenGod`으로.

## 5. UI (OneToOnePanel) — 구조는 현행 유지, 문구만 관계분류 반영

1. 관계분류 뱃지(현행) 2. 오행 요약 한 줄(현행 `elementRelationLabel`) 3. "내가 보는 그" = COPY 룩업 4. "그가 보는 나" = COPY 룩업(골드) 5. 케미/결속(현행).
- **톤 통일**: 현재 "이 별과의 궁합은 아직 비공개예요."(존댓말) → 반말 "이 별과의 궁합은 아직 볼 수 없어."로. (별콩톡 반말 브랜드 정합. create 페이지 등 다른 UI 마이크로카피 톤 통일은 비스코프 — 이 화면만.)
