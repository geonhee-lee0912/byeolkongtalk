**B 습관형 기반 + 낙수 수익화** — 매일 오는 이유를 만들고, 그 풀에서 일부가 결제.

- 앱/PWA/알림 **전부 보류, 웹만.** RN 전환 = UI 35~40k 라인 재작성(lib 14.8k·API 80라우트는 재사용 가능) + **IAP 수수료 15~30% vs 현재 토스 3.4%** → 월 ₩29~66k 추가 유출로 1순위와 정반대. 리워드 광고 수익 ₩5~15/시청으론 상쇄 불가하고 웹은 지면도 제한적.
- 재방문 장치는 **앱 내부**부터 (스트릭·미완결 후크·연속 방문 보상)

### 6.3 레버 판단 (사용자 확정)
**전환율은 3%대에 고정, 움직이는 건 티켓.**

**₩1,000으로 다음 판이 되므로 아무도 그 이상을 살 이유가 없다.** 첫결제 55.1%가 star_10인 이유.

|---|---|---|---|---|---|---|---|
| star_10 | 76 | 1.47 | 14.5% | ₩1,891 | **₩1,421** | **₩1,159** | **₩37,100**(고래) |

- **star_10 첫결제자 76명 중 나중에 star_30 이상을 산 사람은 3명(3.9%)** — 상향하지 않는다

- 일 API 원가 **₩211~622 (21일 평균 ₩342)** = 월 ~₩10k.
- 같은 트래픽을 전량 sonnet 으로 돌렸다면 ₩99,200/21일(월 ~₩142k) — **13.2배 절감**. 모델 검증(₩142k/월 추정 vs 08-10 콘솔 실유저분 ₩137.5k/월 실측 = 오차 3%).
- → **원가 레버는 끝났다. 남은 레버는 전부 매출(전환율 × 티켓)과 리텐션 쪽이다.**

### 9.6 🔴 격자(§6.8)는 목표선에 닿는가 — 산수 검증

재현: `scripts/` 밖 임시 모델(코호트 실측 → 상한 계산). 코호트 = **08-10~08-22 가입 350명**(어드민 제외, ₩10k 구간).

**기준선 실측**

| 항목 | 값 |
|---|---|
| 전환율(가입→결제자) | 34/350 = **9.71%** |
| 평균 첫티켓 | **₩2,121** (첫결제 SKU: star_10 52.9% · star_30 38.2% · star_70 8.8%) |
| 재결제배수(결제자당매출 ÷ 첫티켓) | **1.528** |
| 가입당 매출 | 코호트 ₩315 → **달력 ₩369** (보정 1.172) |

**가입당 매출 = 전환율 × 첫티켓 × 재결제배수**. 격자는 이 중 **첫티켓 하나만** 건드린다(star_10 제거 → 최소 SKU ₩2,800, 평균 첫티켓 ₩2,121→₩3,074 = ×1.45).

**격자 단독 예상치** (k = star_10 구매자가 ₩2,800으로 안 올라오고 이탈하는 비율)

| k | star_10 제거(₩2,800 하한) | 대안: 20별 ₩1,900 신설 |
|---:|---:|---:|
| 0% | **₩535** ✅1차 | ₩452 |
| 10% | ₩509 | ₩434 |
| 20% | ₩483 | ₩417 |
| 30% | ₩457 | ₩399 |
| 50% | ₩406 | ₩364 🔴현상보다 악화 |

- **격자 단독 상한 = ₩535** (k=0, 즉 이탈 0)
- **1차 목표 ₩516 달성 조건 = k ≤ 6.6%** — star_10 구매자의 **93% 이상이 2.8배 가격으로 올라와야** 한다. 설문에서 충전 망설임 1위가 "가격"(5/17)인 걸 감안하면 낙관적이다.
- **2차 목표 ₩643 은 상한(₩535)보다 높다 → 격자만으로는 산술적으로 도달 불가.**
- 현상유지 손익분기 k = 58.6% (그 이상 이탈하면 격자가 손해).

**⚠️ 이 상한조차 고래에 기대고 있다.** 재결제배수 1.528은 코호트 안의 **1명(₩37,100 = 코호트 매출의 33.7%)**이 만든 값이다. 그 1명을 빼면 배수 1.028 = 사실상 전원 1회 결제이고, 상한도 같은 비율로 내려간다. [[cost-unit-economics]] 계열 관측(반복 3.5%가 매출 31.8%)과 일치하는 구조적 현상이다.

**레버 크기 비교** (달력 가입당 매출)

| 재결제배수 | 격자 없이 | 격자와 함께 |
|---|---:|---:|
| 1.53 (현재) | ₩369 | ₩535 |
| 2.0 | ₩483 | **₩700** ✅2차 |
| 2.5 | ₩604 | ₩875 |

→ **재결제배수 1.53 → 2.0 하나가 격자 전체(×1.45)보다 크다.**

### 9.7 ✅ 결론 — 격자의 위치 재정의

1. **격자는 그대로 배포한다.** 근거(웰컴 자연실험)는 유효하고, k가 58.6% 미만이면 손해가 아니다. 다만 역할은 **"목표 달성 도구"가 아니라 "₩1,000 앵커 해체 + 첫티켓 정상화"**로 재정의한다.
2. **1차 목표(월 손익 0)는 격자 + 광고 롤백으로 사정권**, 단 k ≤ 7% 라는 조건부다. → §6.9 단계 0의 **결제퍼널 계측 3종이 k 를 재는 유일한 수단**이므로 반드시 격자보다 먼저 배포한다.
3. **2차 목표(월 +₩100k = 가입당 ₩643)는 재결제배수를 1.53 → 2.0 이상으로 올려야만 닿는다.** 이게 3탭 리텐션 허브·무료 상품(§7-2·7-3)의 존재 이유이고, "있으면 좋은 것"이 아니라 **2차 목표의 유일한 경로**다.
4. 20별 ₩1,900 대안은 상한이 ₩452라 1차 목표에 못 닿는다 → **채택하지 않는다.** (k가 30%를 넘길 게 확실해지면 롤백 옵션으로만 보류)
