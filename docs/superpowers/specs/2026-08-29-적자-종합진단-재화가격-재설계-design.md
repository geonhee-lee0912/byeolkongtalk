**B 습관형 기반 + 낙수 수익화** — 매일 오는 이유를 만들고, 그 풀에서 일부가 결제.

- 앱/PWA/알림 **전부 보류, 웹만.** RN 전환 = UI 35~40k 라인 재작성(lib 14.8k·API 80라우트는 재사용 가능) + **IAP 수수료 15~30% vs 현재 토스 3.4%** → 월 ₩29~66k 추가 유출로 1순위와 정반대. 리워드 광고 수익 ₩5~15/시청으론 상쇄 불가하고 웹은 지면도 제한적.

### 6.3 레버 판단 (사용자 확정)
**전환율은 3%대에 고정, 움직이는 건 티켓.**

- **star_10 첫결제자 76명 중 나중에 star_30 이상을 산 사람은 3명(3.9%)** — 상향하지 않는다
- 손익분기: **star_10 결제자의 40~50%가 star_30으로 올라가면 본전**
