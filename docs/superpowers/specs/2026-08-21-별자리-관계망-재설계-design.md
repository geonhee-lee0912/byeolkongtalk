# 별자리 지도 관계망 재설계 — 설계 (2026-08-21)

지도를 "모든 쌍을 잇는 오행색 실선" → **"특별 인연(천간합·육합·삼합)만 잇는 깔끔한 관계망"**으로 바꾼다. 친구끼리 관계를 공개해 진짜 관계망을 살리고, 상단 필터를 관계타입으로 교체하고, 용어·등급명을 정리한다.

## 0. 배경 / 문제

- 지금 지도는 **모든 쌍에 오행색 실선**을 그려 너무 복잡하다. 게다가 그 실선 색은 상생/상극 "관계"가 아니라 그냥 **상대 별의 오행색(=별 색과 중복)**이라 정보 가치가 낮다 — 사실상 "호스트↔이 사람 연결됨"을 그리는 바퀴살.
- 오행 상생상극은 **인연 점수(무유불리)**와 **1:1 상세**에만 쓰이면 충분하고, 지도 선으로는 불필요.
- 친구끼리 관계(관계망)는 `compat_visible` 옵트인에 막혀 대부분 안 보인다 → 도령 귀인지도와의 차별점("진짜 관계망")이 안 살아난다.

## 1. 지도 선 재설계

- **오행색 실선 제거.** 지도엔 **특별 인연만** 그린다:
  - 천간합 → 금색 **실선** (끌림)
  - 육합 → 금색 **점선** (결속)
  - 삼합 → 같은 오행색 **glow + 점** (무리 — 그룹 표시, 선 아님. 현행 유지)
- 특별 인연이 하나도 없는 사람 = **선 없이 홀로 뜬 별** (밤하늘 감성, 사용자 결정 A). 오행은 별 색으로 유지.
- 노드 모양(나=원·호스트=큰 별·친구=통통한 별)·배경(밤하늘·별가루·신수)·삼합 표시 방식은 **현행 유지**.

## 2. 관계망 — 친구끼리 공개 (차별점 핵심)

- 특별 인연 선을 **호스트-게스트 + 게스트-게스트 전부** 그린다.
- **API 변경**: 게스트끼리 엣지 게이트를 `compat_visible` → **특별 인연 보유(heavenlyCombo || sixCombo)**로 바꾼다. 즉 게스트끼리는 천간합/육합이 있을 때만 엣지를 내려준다(그릴 것만 = 페이로드 최소화 + 프라이버시 최소노출). 비특별 게스트 쌍은 엣지 미포함.
- 호스트가 낀 엣지는 **현행대로 전부** 내려준다(순위·인연 점수에 필요).
- 삼합(`triads`)은 이미 게스트 포함이라 **무변경**.
- 신원 프라이버시는 기존 **`name_public` 옵트인**이 담당(비공개 = "이 별", 익명 두 별 사이 선까지만 노출).
- `compat_visible`은 게이트에서 제거(DB 필드는 잔존 무해). 노드 payload의 `compatVisible`과 join 폼의 옵트인 UI는 미사용이 되므로 정리.

## 3. 상단 필터 — 사회분류 → 관계타입

- 칩: **[전체 · 끌림 · 결속 · 무리]**.
  - 해당 인연이 맵에 하나도 없으면 그 칩은 숨김(전체는 항상).
  - 특별 인연이 **한 종류도 없으면** 필터 전체 숨김(볼 게 없음).
- 동작: 선택 시 그 인연만 강조, 나머지 dim(현행 `DIM=0.18` 재사용).
  - 끌림 → 천간합 엣지 + 그 끝점 노드 강조
  - 결속 → 육합 엣지 + 끝점 노드
  - 무리 → 삼합 클러스터(멤버 노드 + glow) 강조, 천간합/육합 선은 dim
- stale 필터(사라진 종류 가리킴)는 전체로 폴백(현행 `effectiveFilter` 패턴).
- 사회분류(친구/연인/지인/윗사람)는 지도 필터에서 빠지되 **1:1 상세·순위엔 유지**(정보 손실 없음).

## 4. 범례

- 오행색 범례(노드) 유지 + **선 종류 미니 범례** 추가: 실선=끌림 · 점선=결속 · (같은색 무리 표시)=삼합.

## 5. 용어·등급 정리

- **"인연도" → "인연 점수"**: 1:1 상세("인연 점수 87")·순위 각 행. 순위 헤더 "인연이 진한 순" → **"인연 점수 높은 순"**.
- **등급명 (하늘/별 계열)** — 점수 공식·경계·tone 키는 무변경, **라벨 문자열만** 교체:
  | 점수 | 등급(신규) | tone |
  |---|---|---|
  | 85–100 | **하늘이 맺은 인연** | high |
  | 70–84 | **깊은 인연** | mid |
  | 55–69 | **이어진 인연** | low |
  | ~50 | **잔잔한 인연** | faint |
- 등급 용법 뉘앙스: "귀함/인연의 강도"를 표현(무유불리 유지) — "이로운 사람"(유불리)로 읽히지 않게.
