# 별자리 지도 시각 재정비 — 설계

작성 2026-08-23. 대상 = `/fortune/byeoljari/[shareId]` 관계망 지도(`components/byeoljari/*`, `lib/byeoljari/*`).

## 배경

로엔 맵(`7uBv0cLKet`, 친구 12명) 실물 + 코드 점검에서 지도 시각의 문제 5건 확인. 전부 "지도 관계망"에 국한(카드/신수/초대는 이번 스코프 밖).

- 끌림(천간합)=골드 실선 11개 = 지배적 · 결속(육합)=보라 점선 5개 · 같은 결(삼합)=오행 가변색 폴리곤 1그룹+glow.
- **범례↔지도 색 불일치(실결함)**: 범례 "같은 결"은 고정 민트 `#5DCAA5`, 지도 삼합은 `starColor(t.element)`(로엔=화국이면 빨강) → 무조건 어긋남.
- **주인 별이 별로 나옴**: `resolveGlyph`는 "나(meId)=원"인데, 공유링크/비로그인/다른 기기에서 `meId`(=`localStorage["byeoljari:me:<shareId>"]`)를 못 찾으면 host를 별로 그림. 사용자가 여러 번 요청했으나 "안 바뀐" 게 아니라 "나를 인식 못 한" 것.

## 확정 설계 (사용자 승인 2026-08-23)

| # | 항목 | 결정 |
|---|---|---|
| ① | 주인 별 | host = **원**(`isHost` 기준, 로그인/기기 무관 항상). 게스트 뷰어 "내 별" = 흰 테두리 강조 별(best-effort, `meId` 있을 때만). 자기 맵에 "내 별 놓기" 버튼 뜨는 버그도 함께 수정 |
| ② | 범례↔지도 | 같은 결 = 청록 통일 → 자동 일치 |
| ③ | 삼합 색 | 오행 가변색 → 청록 `#5DCAA5` 고정 |
| ④ | 삼합 칩 | 2단계 — "같은 결" 누르면 옆에 ①②③ 하위 칩 펼쳐져 그룹 격리 |
| ⑤ | 선 미감 | 또렷·반짝(opacity·두께↑) + 끌림 골드 글로우 강화 |

**색 체계 최종**: 끌림=골드 실선 `#F2D78A` · 결속=보라 점선 `#A98BEE` · 같은 결=청록 실선 `#5DCAA5`.

## 구현 상세

### 색 단일 원천 (선행)

드리프트 방지를 위해 `lib/byeoljari/display.ts`에 관계선 색 상수 신설:

```ts
export const BOND_COLOR = { heavenly: "#F2D78A", six: "#A98BEE", triad: "#5DCAA5" } as const;
```

범례(ConstellationView)·지도 선(ConstellationCanvas)·칩이 전부 이 상수 참조. 기존 하드코딩(`"#F2D78A"`·`"#A98BEE"`·범례 `"#5DCAA5"`)을 대체. `STAR_ELEMENT_COLORS`(별색)와는 별개 유지.

### ① 주인 별 = 원

- `lib/byeoljari/layout.ts` `resolveGlyph(node, meId)` 재정의. 반환 타입 변경:
  - `node.isHost` → `"host-circle"`(원, 주인 — meId 여부 무관)
  - `meId && node.id === meId && !isHost` → `"me-star"`(흰 테두리 강조 별, best-effort)
  - 그 외 → `"star"`
  - 자기 맵(host===me)은 host-circle로 흡수(원 하나).
- `components/byeoljari/ConstellationCanvas.tsx` 노드 렌더 분기 교체:
  - `host-circle` → 원(`sizes.hostOuter` 반경, 오행색 fill + 골드 테두리). 기존 host 별 자리.
  - `me-star` → 별 + 흰 테두리(`stroke #FFFFFF` 강조).
  - `star` → 별(현행).
  - 기존 `me-circle` 원 렌더 로직을 `host-circle`로 이관.
- `app/fortune/byeoljari/[shareId]/page.tsx` 하단 버튼 판정을 `meId` 단독 → `meId || graph.viewerIsOwner`:
  - 주인(또는 참여자) → "🔗 친구 초대하기"
  - 그 외 → "이 별자리에 내 별 놓기"
  - ⚠️ 비로그인·다른 기기의 주인은 `viewerIsOwner=false`+`meId` 없음이라 여전히 join 버튼(근본 한계 — GET이 세션↔member 매칭을 안 줌). 글리프(host=원)는 `isHost`라 이 한계와 무관하게 항상 정확.

### ②③ 삼합 청록 통일 + 범례 일치

- `ConstellationCanvas.tsx`:
  - 삼합 폴리곤 `stroke={starColor(t.element)}` → `BOND_COLOR.triad`.
  - triadRing glow `starColor(t.element)` → `BOND_COLOR.triad`.
  - 끌림/결속 선 색도 `BOND_COLOR.heavenly`/`.six` 참조로 교체.
- `ConstellationView.tsx` 범례 3선 색을 `BOND_COLOR` 참조로(현재 청록은 이미 `#5DCAA5`지만 상수화). 지도 삼합이 청록이 되면 자동 일치.

### ④ 삼합 2단계 칩 (그룹 격리)

핵심 신규 로직. 삼합 그룹 = `graph.triads[i]`(API 순서 = 결정적). 그룹 번호 = `i+1`(①②③).

- 필터 상태 확장(`ConstellationView`): 기존 `activeFilter: BondFilter | null`에 더해 `activeTriadGroup: number | null`.
  - `activeFilter==="triad"` && `triads.length >= 2`일 때만 하위 칩 `[①][②][③]`(triads 개수) 렌더.
  - 하위 칩 클릭 → `activeTriadGroup=i`(그 그룹만 강조). 다시 "같은 결"/"전체"로 리셋.
  - `triads.length === 1`이면 "같은 결" 칩이 곧 그 그룹(하위 칩 없음).
- `lib/byeoljari/bond-filter.ts` 확장:
  - `edgeActiveForBond`/`nodeActiveForBond`에 `triadGroup?: number` + `triads` 인자 추가. `triadGroup`이 지정되면 해당 `triads[triadGroup].memberIds`만 매칭.
  - 삼합은 엣지가 아니라 노드(멤버)로 판정하므로 그룹 격리도 노드 기준.
- `ConstellationCanvas.tsx`: `activeTriadGroup` 받아 해당 그룹 폴리곤·멤버 glow만 표시(나머지 삼합 폴리곤 dim/숨김). 포커스 뷰는 무관(overview 전용).
- ⚠️ 실데이터상 삼합 2그룹+는 인원 ~20명일 때만 발생(대부분 0~1). 하위 칩은 `>=2`일 때만 등장 = 흔한 케이스 UI 불변.

### ⑤ 선 미감 (또렷·반짝)

- `lib/byeoljari/scale.ts`: `lineWidth`·`goldLineWidth` 상향(FEW/MANY 둘 다). 소규모 회귀 최소 폭으로.
- `ConstellationCanvas.tsx`: 특별 선 `strokeOpacity` 상향(현 `special?0.62`, 삼합 `0.5` → 약 `0.82~0.85`).
- 끌림 골드 글로우: `<defs>`에 `feGaussianBlur` 필터(`goldGlow`, triadGlow 관례) 추가 → 끌림 선 뒤에 굵은 반투명 골드 겹선 또는 filter 적용. **글로우 강도는 목업 ②보다 조금 더 강하게**(사용자 지시).
