## 2. 콘솔 실측이 확정한 것 (토큰 역산)
- **실제 캐시 히트율 90.5%** (read/(read+write)). 메모리 "96%"보다 낮지만 정적블록 캐싱이 잘 작동. → 이론 원가 히트율 0.9 시나리오가 실제에 가깝다.
- **입력:출력 토큰 = 25.8:1** (입력 70.7M : 출력 2.74M). 원가는 입력이 지배.
- **출력(분량)은 원가의 34%(비용)·4%(토큰)** — 단가($15)가 높아 비용 비중은 있으나 토큰은 작음.
- **Haiku 이미 2.5%** — 보조 콜(요약·민감판정)은 이미 저가 모델.
- 한국어 실측 ≈ 1자/토큰 (`CHARS_PER_TOKEN=1.6`은 과소추정, 배분엔 무손상).

## 4. 무료별 → 결제 전환 (인과)
- 결제자 86명 첫 결제 전 리딩: **0판 62% · 1판 34% · 2판+ 4%. 평균 0.44판** (7/25 1.00보다 감소). "무료로 여러 판 체험→결제" 경로 사실상 0. 지불의사 있는 사람은 웰컴 소진 즉시/전에 산다.
- 미결제자 893명: **73%가 딱 1판만** 하고 이탈. 웰컴 20별로 타로 1판 맛보고 안 옴.
- **무료별(웰컴 20)의 대부분이 "1판 맛보고 떠나는 미결제자"에게 태워진다** = 매출 0, 원가만. 이게 "무료별=원가 87%"의 정체.
- 교차이용 ARPU: chat만 ₩166 → +운세 ₩544 → 3개 다 ₩3,467(21배). 근데 그 풀 9명뿐.

## 5. 통념 3개 반전 → 레버 우선순위 재배열
1. **모델 믹스 기대효과가 작다** — Haiku 이미 2.5%, 캐시 90.5%, 원가는 입력 지배. 무료 상품(daily)은 이미 원가 극소, 주력 타로 다운그레이드는 매출 품질 리스크.
2. **진짜 레버는 무료별 + 입력(정적블록·히스토리)**.
3. **분량은 원가 34%** — 축소해도 입력만큼 안 빠짐. 가성비 체감용(reading-depth)이면 별개.
