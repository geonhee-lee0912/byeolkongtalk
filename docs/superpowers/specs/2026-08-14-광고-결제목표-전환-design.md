## 0. 이번 라운드가 답하는 질문 하나

> "Meta 최적화 대상을 **가입 → 결제**로 바꾸면 수익이 나아지는가?"

지금까지 광고세트는 `등록 완료`(CompleteRegistration)를 최적화해 왔다(첫 스크린샷 "사용" 컬럼 = 등록 완료에만 광고세트 1개 귀속). 즉 Meta 는 **"가입할 사람"**을 사왔고, 그 결과가 소재귀속 ROAS 0.69 · CPA ₩2,968 이다. 이 라운드는 최적화 대상을 **"살 사람"**으로 바꿔 14일 안에 개선 여부만 깨끗이 잰다.

### 기대치 (정직하게 고정)

- 이번 목표는 **"흑자 전환"이 아니라 "적자 폭 축소 + 처음으로 결제 기준 최적화"**다.
- 현행 CPA ₩2,968 > AOV ₩2,049. 카피·타겟만으로는 흑자 불가(최선 시나리오 ROAS ≈ 1.09, star_10 코호트가 전부 ₩2,800 이동 + 이탈 0 가정).
- 진짜 흑자는 재결제(현 11.5%)·가격 정합·모델 원가에서 나온다 → **다음 사이클**.
- 판정 창 14일은 **효과 크기를 재는 도구가 아니라 재앙을 막는 가드레일**이다(주 24.5건 규모에서 1.3배 차이 감지에 16.5주 필요 = 검정력 사실상 없음).

|---|---|---|
| 최적화 대상 | 등록 완료 → **구매** | — |

| 소재 목적 | 다양성 노출(승자 선택 아님) | 소재별 판정 안 함 → 신호 분산 문제 소멸 |
| 예산 | 일 ₩10,000 **유지** | 증액·2층 분할(보류) |
| 2층(부스팅) | **이번 라운드 안 함** | 예산상 판정 불가 + auction overlap(다음 라운드) |
| 계측 | **픽셀 재발화 + EMQ 생년월일 + 방침** 둘 다 | — |
| 어트리뷰션 창 | 7일 클릭/1일 조회 **유지**(손 안 댐) | 결제 lag 중앙값 4.8분이라 창이 병목 아님 |

**왜 시뮬·daily·웹툰이 빠졌나**: 셋 다 "유입형"이다 — daily 는 100% 무료(결제 0), 시뮬은 무료 런웨이 3판 + 주간 무료 + 웰컴 20별이 15별 흡수라 5판째쯤에야 실결제, 웹툰은 브랜드 서사. 결제 최적화에 넣으면 Meta 가 노출을 스스로 줄여 안 나간다. 유입/인지 목표(별도 캠페인)가 맞고, 그건 이 라운드 판정 후.

## 3. 코드 작업 (내 손 · writing-plans 로 구현)

### 3-1. 픽셀 PageView 라우트 재발화 (A안)

- **수정**: `usePathname()` 감시 → 경로 변경 시 `fbq('track','PageView')`. 파일 1개.
- **주의**: PageView 총량이 급증(랜딩만 → 전 페이지)하므로 기존 PageView 추세와 **연속성 단절 시점 기록**. Purchase 기반 결제 최적화와는 교락 없음(배급 영향 없음).

## 4. 판정 장치

### 4-1. `ad_spend` 최신 입력 (사용자 손, 필수)

- 현재 `ad_spend` 마지막 = 08-09. 유입은 08-14 까지 계속 → 최근 5일 회수율 분모가 빔. **08-10~현재 지출을 CSV 업로드**해야 R 계산 가능.
- 겸: (일자, 소재) 중복 3그룹(약 ₩7,377, 2.3%) Meta 리포트 원본과 대조.

### 4-2. 회수율 R — 두 앵커 동시 출력

```
R = [ Σ광고귀속매출 × (1 − PG요율) − Σ광고귀속유저_별소모 × 별당원가앵커 ] / Σ광고비
```

- 매출: `payments` status='completed', 탈퇴 익명보존이라 **NULL 포함 SUM**(3값 논리 주의).
- PG요율: 3.3~3.7% 확정 필요(사용자 확인).
- 별당원가앵커: 티어링 前 ₩8.9 / 後 ₩0.57 — **오늘 티어링 배포됨**. pre 를 ₩0.57 로 재계산해야 광고 효과만 남음. 두 값 동시 출력.
- 코호트: `users LEFT JOIN user_acquisition`(오가닉은 행 없음). 창: `(created_at at time zone 'UTC' + interval '9 hours')::date`.

### 4-3. 7열 고정 리포트 (R 단독 보고 금지)

`결제건수 · CPA · AOV · package_type 믹스 · 별소모/유저 · 건당순기여 · R`

- 강제 분해: `R = (1/CPA) × [ AOV×(1−PG) − 건당변동원가 ]`. 좌항만 개선되고 우항이 무너지는 게 **AOV 하락 트랩**(전환수 극대화라 Meta 가 ₩1,000 최소 SKU 로 몰 수 있음). R 단독 숫자만 보면 다음 세션이 "건수 증가"를 성공으로 오독.

### 4-4. 가드레일 — 랜딩→가입 전환율

- 현재 50.1%(Meta) / 57%(DB). 이번 라운드는 랜딩·웰컴 문구를 안 건드리므로 크게 변하면 안 됨. 급락 = 이상 신호.

### 4-5. 중단 기준 (원복은 한 번에 하나 = 동시 원복도 교락)

- **T0 (0~48h) 배급 실패**: "오디언스 너무 작음"/"게재 안 됨" 경고 → 즉시 원복 · 일 소진 < ₩7,000 이 2일 연속 → 원복 · CPM > baseline×1.5 가 3일 연속 → 원복.
- **T1 (7일) 신호 붕괴**: Meta 귀속 구매 주간 < (before 스냅샷 Meta 귀속 주간의 절반) → 이벤트만 등록완료로 원복, 타겟 유지 · 주간 클릭 < baseline×0.6 → 타겟 원복.
  - ⚠️ 임계는 **Meta 귀속 건수** 기준(before 스냅샷에서 확정). DB 전체 24.5건과 혼동 금지.
- **T2 (14일) 경제성**: R < baseline R × 0.8 → 둘 다 원복 · AOV < ₩1,600 이면서 R 개선 없음 → 이벤트 원복 · 결제 CPA > ₩3,858 → 원복.
- **T3 (14일) 카나리아**: 만 35세+ 광고 유입 남으면 18-34 가 하드 컨트롤 아님(제안 모드) → 타겟 원복, 이벤트 축만 판정. 판독 = `user_profiles(is_primary).birth_date`(커버리지율 병기, 크게 흔들리면 무효 선언).
