# 연애 시뮬레이션 — 상품 형태 설계

**작성** 2026-08-01 · **상태** 형태 확정 · 세부 미정(하단탭 세션으로 이월)
**선행** `specs/2026-07-27-연애-시뮬레이션-아이디어.md`(아이디어 등재)를 잇는다. "리허설 도구" 정체는 이 문서에서 **"초상화 + 대화 게임"**으로 재정의됐다.
**맥락** T1(신상품 설계 → 하단탭 IA 재설계)의 첫 상품. 이 문서 = **시뮬 상품 자체**. 탭 배치·기존 상품(연애 상담)과의 관계는 하단탭 세션에서.

## 한 줄

내가 아는 상대를 **초상화**로 세우고, 난감한 상황을 **대화로 플레이**하며, 별콩이가 그 대화에서 **통찰**을 건네주는 상품. **게임의 형식으로 안전을, 대화 경험으로 값을** 판다.

## 확정된 형태

### 정체 — "네가 그린 초상화 + 공동창작"
- 이 AI는 "진짜 그 사람"이 아니라 **유저가 그린 상대의 초상화**다. 입력값 = 상대의 데이터가 아니라 **유저의 인식**.
- 별콩이랑 **같이 다듬어간다**(공동창작). 플레이할수록 초상화가 두꺼워짐 = 리텐션·소유감.
- → 이 프레임이 "정확도 0"(E6 리스크 2)을 **소멸**시킨다: "완벽 재현"을 약속하지 않으므로 *"안 맞잖아"* 클레임이 성립하지 않는다.

### 엔진 — 상황 대화형 플레이
- 상황을 고르고(**무게별 카드 프리셋 + 자유 서술**) 대화로 플레이.
- 선택지 = **하이브리드**(자유입력 + 별콩이가 보기 몇 개 곁들임). 백지 마찰↓ 개인화↑.

### 소비/과금 — 대화 진행형 + 인챗 연장
- **대화가 이어지는 진행형.** "같은 상황 리셋 반복 완결"은 기각(반복 노동 느낌, 메리트 없음).
- 다른 선택지 탐색·대화 연장 = **인챗 결제로 유도**.
- → 기존 **continuation(이어가기) + 인챗 칩(extend)** 패턴 재사용. **"상황 단발 고정가"는 폐기**.

### 목적 — 상황 무게별 스펙트럼
| 무게 | 예 | 앞서는 목적 |
|---|---|---|
| 가벼움 | 이번주 데이트·썸 톡 | 설렘·재미 |
| 중간 | 마음 떠보기·밀당 | 탐색·통찰 |
| 무거움 | 고백·화해·갈등 | 불안 해소·용기 |

- 공통: **거울 서사를 끝까지 유지**(가벼운 상황도 순수 판타지 머신 금지).

### 산출물 — 대화 경험이 핵심
- 정리된 리포트가 아니라 **대화 경험 자체가 심장.** 산출물은 그걸 **보완·연장**하는 것이어야 한다(닫는 게 아니라 여는 것).
- 통찰은 별도 리포트가 아니라 **대화 중 별콩이의 관찰**로 녹인다.
- "갈래 지도" = 대화가 흘러가다 (결제로) 갈라져본 **가지들의 기록**. ⚠️ **형태 재설계 필요** — 초기 목업은 "완결 3판" 전제라 무효화됨.

### 게임성 — 형식은 최대, 승리 목표는 금지
- **형식(O)**: 상대를 캐릭터/초상화 카드로 · 별콩이 = 게임 마스터/해설자 · 판·갈래·"다시" · 결과 연출.
- **승리 목표(X)**: 호감도 게이지·점수·"공략 성공 엔딩"·랭킹 → 판타지 머신·대상화로 미끄러짐.
- 근거 = **매직 서클**: "놀이 중"이라는 인지가 심리적 거리를 만들어 거울을 보강한다. 이기려 들수록 거울이 깨진다.

### 안전 — 이중 프레임
- 거울("초상화지 진짜 걔 아님") + 게임(매직 서클). 화면 문장은 전부 *"걔는 이럴 거야"*(예측 ❌)가 아니라 *"넌 이렇더라"*(관찰 ✅).

## 핵심 판단 (재론 방지)

- **정확도 0 → "완벽 재현을 약속하지 않음"으로 회피.** 정확도를 높이려는 시도는 밑 빠진 독.
- **거울 문제 → "머릿속 불안을 꺼내 마주 → 용기"로 재정의해 소멸.** 유저가 못 보내는 이유는 실제 걔가 아니라 자기 머릿속 불안 → 거울(내가 그린 걔)이어야 맞다.
- **게임성 = 안전장치**(형식만, 승리 목표 금지).
- **대화 연속 > 반복 완결.**

## 보류 — 하단탭 세션으로 이월

- **스킬 포함 여부**(걔 속마음 등) — 시뮬은 **스킬 없이 순수 구성이 기본**, 완성 후 포함 검토
- 패스·스레드 존폐 / 그 사람 탭 전체 위계 / 하단탭 구조
- 코호트(이별·짝사랑) 취급 · 입력 범위(MBTI·성격 옵션) · 가격 구체 · 게임성 장치 구체 · 갈래 지도 최종 형태 · 3화자 아키텍처 재확인

## 기각 (재론 방지)

| 대안 | 기각 이유 |
|---|---|
| 상대 예측 체험("걔는 이럴 거야") | 근거0 단정, 페르소나 코어 §단정금지 위반 |
| 감정 해소·카타르시스 | 이별 코호트 위기 신호 최다 + 망상 강화 |
| 같은 상황 리셋 반복 완결 | 반복 노동, 메리트 없음 (2026-08-01 사용자) |
| 상황 단발 고정가 | 대화 진행형과 안 맞음 |
| 승리 목표형 게임화(호감도·점수·공략엔딩) | 판타지 머신·대상화 |
| 스킬 억지 흡수 | 실제 겹치는 건 "걔 속마음"뿐, 나머지는 제자리 |
