# 별콩이 아이콘 시스템 재설계 (컨셉 기획서)

작성 2026-08-15 · 상태: 컨셉 확정, 제작 전 리뷰 대기

## 0. 한 줄 요약

서비스 전역의 뒤죽박죽 아이콘(MDI 벡터 + 구식 래스터 PNG + 이모지)을, **별콩이 세계관의 "마법 도구함" 오브제 시스템**으로 통일한다. 목적은 **비주얼 품질 ↑**. 현재 형상을 재스킨하지 않고 **형태(메타포)를 새로 발명**한다.

## 1. 배경 — 현재는 3가지 매체가 섞임

| 지면 | 현재 매체 | 문제 |
|---|---|---|
| 하단탭 5 | MDI SVG (제네릭) | 세계관 무관, 범용 |
| 홈 감정태그(타로톡 분류) 10 | 래스터 PNG `class01~10` (61~155KB) | 구식·무거움 |
| 사주 운세 목록 6 | 이모지 🗓️💞📅 + RedHorse SVG 1 | 잡다 |
| 우리 사이 목록 2 | 이모지 💬🎭 | — |
| 보관함 상품 배지 | 혼합(saju PNG + 🔮 + 이모지 + 🎭) | 최악의 뒤섞임 |
| 상점 별 | 커스텀 SVG `StarIcon` | 이미 벡터(양호) |

## 2. 방향 결정 (확정)

- **비주얼 스타일 = C · 별콩이 일러스트**(회화풍, 세계관 몰입). 사용자 확정 2026-08-15.
- **메타포 = 컨셉 1 · 별콩이의 마법 도구함**(오브제/부적). 사용자 확정 2026-08-15.
- **현재 형상과 다른 새 형태**로 발명(이모지→세계관 사물 치환).
- **스코프 결정 (2026-08-15):**
  - 🚫 **하단탭 5 아이콘은 이번 스코프에서 제외** — 사용자가 하단탭 형태도 바꾸고 싶어 하나, 하단탭 자체 색상/레이아웃 개편 가능성이 있어 **그 개편과 묶어 별도 판**으로 미룸. → 이번 Tier 1 = **상점 별 1개만**.
  - ✅ **사주/운세 이모지는 전 지면 통일** — 목록뿐 아니라 result·생성화면·보관함까지 한 세트로 교체(§8).

## 3. 2티어 구조 (기술적 고정)

아이콘을 **역할**로 가른다. 하나의 매체로 전부 통일하면 오히려 품질이 하락한다.

- **Tier 1 — 기능 아이콘(벡터 SVG)**: **상점 별 1개**(하단탭 5는 이번 스코프 제외, §2). 18~22px 리컬러·상태 필요 → 래스터 불가, 벡터 고정.
- **Tier 2 — 장식 분류/상품 아이콘(힉스필드 C 일러스트)**: 타로톡 분류 10 + 사주 운세 6 + 우리 사이 2 = **18개**. 48~64px, 단일 상태, 일러스트풍 → 힉스필드 생성이 적합. **여기가 "새 형태" 재발명의 핵심.**
- **보관함 배지**: 위 타입 아이콘을 **재사용**(신규 0).
- **이번 판 신규 총 = 19개**(T2 18 + T1 1). 하단탭 5는 별도 판.

## 5. Tier 2 비주얼 規格 (C 일관성 — feasibility 리스크 대응)

세트 일관성이 이 방향의 최대 리스크다. 아래를 **생성 규격으로 고정**한다.

- **구도**: 오브제 1개를 **정중앙**, 프레임의 ~60% 채움, 균일한 여백.
- **배경**: **투명**(오브제만). 기존 지면이 이미 그라데이션 타일(`EMOTION_GRADIENTS`/`FORTUNE_GRADIENTS`)을 깔고 그 위에 아이콘을 얹으므로, 아이콘은 배경 없는 오브제여야 타일 위에 자연스럽게 앉는다. → 배경 변수 제거 = 일관성 관리 대폭 단순화.
- **팔레트 고정**: cream `#FAF6F0` / lilac `#D4C7EE` / lilac-deep `#9F8AD0` / gold `#E8C26A` / gold-soft `#F2D78A`, 깊이용 night `#1F1735`. 오행 색(사주)은 별콩이 톤 유지.
- **라이팅/질감**: 부드러운 상단광, 말랑한 무광~반광, 은은한 내부 글로우, 골드 별 스파클 1~2개 액센트. "mystical-cute, dreamy, soft painterly 3D talisman."
- **금지**: 텍스트·글자, 사실적 사진톤, 강한 그림자/네온, 캐릭터(별콩이) 등장(Tier 2는 오브제만 — 캐릭터 포즈 일관성 문제 회피).

## 6. Tier 2 제작 파이프라인 + 일관성 세이프가드 (✅ 2026-08-15 실측 검증 완료)

🔴 **모델 = `nano_banana_pro`** (런타임 alias `nano_banana_2`). **Recraft 탈락**: standard=거친 페인터리(사용자 리젝트), vector=플랫 로고풍 + `background_color` 무시하고 그라데이션 넣음(플랫 요구 실패). nano 는 소프트 카와이 애니 셀셰이딩 + 플랫 배경을 프롬프트로 지킴.

🔴 **목표 톤 = `byeolkong-main.png` 캐릭터의 귀엽고 애니메이션 같은 톤**(사용자 2026-08-15) — 실사/거친 페인터리 금지. 깨끗한 셀셰이딩·얇은 아웃라인·파스텔.

1. **스타일 앵커 확정 = 달-모래시계 (job `6690bfee-52a7-4446-b206-d02becd313b0`)**. 크림 플랫 배경·라일락+크림+골드 균형·귀여운 마스코트. **이 이미지가 앵커이자 "연락 타이밍" 실제 아이콘.** (로컬 사본 `scratchpad/r2_nano_3.png`)
2. **일관성 = 앵커를 이미지 레퍼런스로** (`medias:[{value: 앵커 job_id, role:"image"}]`). ✅**크로스-오브젝트 검증**: 나침반·로켓을 앵커 레퍼런스로 뽑으니 톤·팔레트·플랫배경 통일 + **캐릭터 안 새어듦**(오브제만). ⚠️ **레퍼런스 없이 템플릿만 쓰면 드리프트**(나침반 골드과다·로켓에 임의 앱타일) → **레퍼런스 필수**.
3. **고정 프롬프트 템플릿** (오브제 묘사만 교체):
   > `A cute kawaii mobile app icon: <OBJECT>. Adorable soft anime illustration, clean thin outlines, smooth gentle cel shading, dreamy pastel mood, cute mascot style. Colors: cream white, soft lilac purple, warm gold. Rounded friendly shapes. Single object centered, filling most of the frame. Flat solid cream background, no gradient, no scenery, no shadow. No text, no animal, no creature, no face.`
   - `aspect_ratio:"1:1"`, `resolution:"1k"`.
4. **배치 생성** → **QA 패스**: 오프-스타일·팔레트 이탈·56px 판독성 미달은 리젝트·재생성.
5. **후처리**(PIL): 배경 제거(`remove_background`) → 정사각 균일 패딩 → 리사이즈 → **WebP ≤150KB**. 파일: `public/icons/tag/{slug}.webp` 등. ⚠️ 아이콘은 기존 그라데이션 타일 위에 얹히므로 **투명 컷아웃 필수**.
6. **예산 실측**: nano ~**2크레딧/컷** · Recraft ~1.25/컷. **검증에 22 소모(270→248)**. 전량 18개 × (1~2 변주) ≈ **40~72 크레딧**. 잔액 248 여유.
