# 별자리 포커스 보완 + 목록/헤더/상한 — 설계 (2026-08-21)

방금 배포한 포커스/걸어다니기(2026-08-21)를 사용자 피드백대로 보완하고, 순위 목록·헤더·최대 인원까지 한 배치로 손본다.

## 0. 배경

포커스 기능 실사용 피드백:
- 걸어다니기(breadcrumb)는 과함 → **1단계로 제한**, "전체 지도 보기" 버튼이 낫다.
- 포커스 카드가 `나↔X` 하나뿐 → X의 **다른 인연(이웃)과 전체 해석**도 보고 싶다.
- 오버뷰에서 이름이 안 보이면 뭘 누를지 모른다 → **최대 20명**(라벨 상한과 일치)로 상한.
- 순위 목록 디자인·헤더 표기 개선.

## 1. 포커스 1단계 고정 + "전체 지도 보기" 버튼

- 걸음(walk)·breadcrumb **폐기**. 상태를 `focusPath: string[]` → **`focusId: string | null`**(단일).
- 오버뷰에서 별 탭 → `focusId = 그 별`(1단계). 포커스 뷰에서 **이웃 별/선 탭은 재포커스 안 함**(대신 카드 연동, §3).
- 포커스 뷰 **지도 좌상단 코너**에 "전체 지도 보기" 오버레이 버튼 → overview 복귀. 배경 탭·나 탭도 복귀.
- 포커스 렌더(부분그래프 X 중심 재배치·중립선·`focusMode`)는 **현행 유지**(`buildFocusGraph`/`computeLayout centerId`/Canvas focusMode 그대로).

## 2. 포커스 카드 = 나↔X + X의 관계 전체 & 해석

카드 두 부분:
- **① 나 ↔ X** — 현행 `InyeonDetail`(pivotIsMe true, 인연 점수 + 40칸 카피). (§5로 별콩이 한마디만 빠짐)
- **② "{X}이의 인연" 섹션**(그 아래):
  - **해석 한 문장** — 룰 기반(`focusSummary`): X의 특별 인연 수 + 끌림/결속/무리 개수 + 톤 코멘트. **별콩이 접두 없음.** 예: *"서윤이가 강하게 엮인 인연은 5명 — 끌림 2·결속 2·같은 무리 1. 여기저기 잘 통하는 별이네."*
  - **X ↔ 이웃 리스트**(나 제외) — 이웃별 행: 이름 · 인연 점수 · 등급 · 태그(끌림/결속/무리). 탭하면 그 관계 상세(오행+뱃지, `InyeonDetail pivotIsMe:false`) 펼침.

## 3. 지도 ↔ 카드 연동

- 포커스 뷰에서 **이웃 별(노드) 또는 그 spoke(선) 탭 → 카드 ②의 그 이웃 행이 펼쳐지고 강조**(스크롤). 재포커스(걸음) 아님.
- 상태 `expandedNeighborId: string | null` — 지도 탭·리스트 행 탭이 공유(둘 중 하나로 세팅). 기존 `inspected`(카드 스왑) 폐기.

## 4. 순위 목록 리스타일

- **1위 = 다크톤 카드**(night 배경 `#1F1735`/`#2A1F4D` + 크림·금 글씨) — 확실히 구분.
- 행을 **두꺼운 카드형**(패딩↑ `py-3`+, `rounded-2xl`, 은은한 구분).
- **인연 점수 강조** — 숫자 크게·볼드(현재 `text-xs text-text-light` → 눈에 띄게).
- 아코디언 동작·나 기준 상세는 유지(§5로 별콩이만 빠짐).

## 5. 별콩이 한마디 삭제

- `InyeonDetail`에서 `별콩이 — {comment}` 줄 **삭제**. 그에 따라 `inyeon.comment` 소비 없음 → View의 `inyeonInfo.comment`·`inyeonComment()` 호출 정리(데드 제거). `inyeonComment` 함수/테스트는 존치 여부 자유(미사용이면 제거).
- ⚠️ §2의 X 서클 "해석"은 별콩이 한마디와 **다른 것**(focusSummary) — 이건 유지·추가.

## 6. 헤더 "{신수}자리"

- h1 `우리 별자리 · {신수}` → **`{신수}자리`**(예: "불새자리"). 앞 엠블럼 아이콘 유지. `shape` 없으면 `우리 별자리` 폴백.

## 7. 최대 인원 20명

- 한 별자리 **최대 20명(호스트 포함)**. 상수 `MAX_STAR_MAP_MEMBERS = 20`(`lib/byeoljari/` 또는 `lib/constants.ts`).
- **join API**(`[shareId]/join`)에서 인원 조회 후 `>= 20`이면 삽입 거부: `{ ok:false, reason:"full" }` (409 또는 400). 클라 join 폼/딥링크에서 이 사유를 "인원이 가득 찼어(최대 20명)"로 안내.
- 이유: 라벨 규칙(20명까지 이름)과 일치 → 오버뷰에 항상 이름 표시 → 뭘 누를지 알고 탭. 신수 진화 최종(15+)도 여유 도달. 무한 등록·과밀 차단.

## 8. 파일

- `lib/byeoljari/focus.ts` — `focusSummary(centerId, pivotId, graph)` 추가(순수, TDD).
- `lib/byeoljari/constants.ts`(또는 기존 상수 파일) — `MAX_STAR_MAP_MEMBERS = 20`.
- `app/api/fortune/byeoljari/[shareId]/join/route.ts` — 인원 상한 게이트.
- `app/fortune/byeoljari/[shareId]/page.tsx`(+딥링크 join UI) — "full" 사유 안내.
- `components/byeoljari/InyeonDetail.tsx` — 별콩이 한마디 삭제.
- `components/byeoljari/ConstellationView.tsx` — focusId 단일화·breadcrumb 폐기·"전체 지도 보기" 버튼·카드 ② 섹션·지도↔카드 연동·순위 리스타일·헤더 "{신수}자리".

## 9. 테스트

- `focusSummary` 순수 유닛 TDD(이웃 수·끌림/결속/무리 카운트·나 제외·톤 코멘트 경계).
- join 상한: 20명 맵에 21번째 join → `full` 거부(로컬 실호출).
- 브라우저 E2E(로엔 `7uBv0cLKet`): 별 탭→1단계 포커스+"전체 지도 보기" 버튼(걸음 없음)·카드 ①+② (해석+X↔이웃 리스트)·이웃 탭→카드 행 펼침·순위 1위 다크·점수 강조·헤더 "불새자리"·별콩이 한마디 없음·콘솔0.

## 10. 스코프 밖

- 포커스 렌더 자체(부분그래프·재배치·중립선)는 유지, 재작성 아님.
- 전환 애니메이션(재배치 스냅)·삼합-only 선 폴백 문구 — 여전히 후속.
- 관계분류 40칸 카피는 지인끼리 무관(유지).
