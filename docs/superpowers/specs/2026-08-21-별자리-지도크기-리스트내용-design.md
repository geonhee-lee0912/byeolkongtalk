# 별자리 지도 크기·스크롤 + "같은 결" + 리스트 디자인/내용 — 설계 (2026-08-21)

포커스 지도의 크기·스크롤 거슬림을 고치고, 어색한 "무리"를 "같은 결"로 바꾸고, 순위 리스트를 재디자인(순위·점수·분류 칩)하며, 상세 내용을 A(줄글)+B(키워드 칩)+D(잘 맞는 점/조심)로 풍성하게 한다.

## 0. 배경

포커스 실사용 피드백:
- 별 탭(포커스) 시 노드가 적어져 `scaleForCount`가 별을 크게 만들어 **지도 스케일이 튄다**. + 카드 자동 스크롤로 **지도가 화면 밖으로 밀린다**.
- 삼합 라벨 **"무리"가 어색**.
- 순위 리스트를 **순위·점수·분류(색 칩)**로 재디자인 + 상세 내용 **다채롭게(줄글 포함)** 원함.

## 1. 지도 크기·스크롤

- **스케일 고정**: `sizes`를 `scaleForCount(viewGraph.nodes.length)` → **`scaleForCount(graph.nodes.length)`**(전체 인원 기준)로. overview↔포커스 노드 크기 동일 → 포커스해도 안 튐.
- **처음부터 조금 크게**: overview 지도가 지금보다 살짝 크게. 구현 선택 — (a) 페이지 `px-4`→`px-3` 등으로 지도 폭 확대, 또는 (b) `scale.ts` FEW/MANY 별·반경 소폭↑. **(b) 소폭 상향** 채택(별·라벨이 조금 커짐, 반지름 34 유지). E2E로 미세 조정.
- **자동 스크롤 제거**: 포커스 진입(`focusId` 세팅) 시 `detailRef.scrollIntoView` **하지 않음** → 지도 그대로 보임. (리스트 아코디언 `listOpenId`·선/이웃 펼침 `expandedNeighborId`은 스크롤 유지 여부 자유 — 지도 밀지 않는 선에서. 기본: 포커스 자체는 스크롤 안 함, 카드 내부 행 펼침만 부드럽게.)

## 2. "무리" → "같은 결"

- 단일 원천 `BOND_FILTER_LABEL.triad`를 `"무리"` → **`"같은 결"`**(`lib/byeoljari/bond-filter.ts`). 이걸 쓰는 칩·태그·범례가 자동 반영.
- 하드코딩된 "무리" 전수 교체: 선 범례(View), 이웃 태그(View), 삼합 메시지(InyeonDetail "같은 무리 (삼합)" → **"같은 결 (삼합)"**), focusSummary 조립 문자열(View "같은 무리 c" → "같은 결 c").

## 3. 순위 리스트 재디자인

행 = **순위 · 이름 · 점수(강조) · 분류 칩(들)**:
- 분류 칩 = 그 사람과 나의 특별 인연 종류. `heavenlyCombo`→**끌림**(골드), `sixCombo`→**결속**(라일락), `triadShared`→**같은 결**(민트). 여러 종류면 칩 여러 개. 특별 인연 없으면 칩 없음.
- **등급(하늘이 맺은 인연 등)은 행에서 빼고 펼침 상세로** 이동.
- 1위 다크톤·두꺼운 카드·점수 강조는 유지.
- 칩 색: 끌림 `bg-gold-soft/60 text-eye-purple`, 결속 `bg-lilac-soft text-eye-purple`, 같은결 `bg-[#DCF3EC] text-[#1f6b57]`(민트, 목오행톤). 1위(다크) 행에선 칩 톤 대비 유지(예: 반투명 밝은 배경).

## 4. 상세 내용 풍성화 (A+B+D)

`InyeonDetail` 상세에 신규 룰기반 콘텐츠 추가(별콩이 톤 아님·담백 서술·"나" 명시 없이 pivot 관점):
- **A. 관계 한 줄 서술** — 오행 관계별 한 문장.
- **B. 키워드 칩 2~3개** — 오행 키워드 + 특별 인연 키워드(끌림/결속/같은 결).
- **D. 잘 맞는 점 / 살짝 조심** — 오행 관계별 2줄.

### 순수 모듈 `lib/byeoljari/relation-detail.ts`(신규, TDD)
`relationDetail(element, { heavenlyCombo, sixCombo, triadShared })` → `{ prose, keywords: string[], good, caution }`.

오행 관계(element ∈ 생아·아생·극아·아극·비화) 데이터:
| element | prose | good | caution | kw |
|---|---|---|---|---|
| 생아 | 곁에 있으면 기운을 받아 힘이 나는 사이 | 함께면 안정되고 북돋아져 | 자꾸 기대게 될 수도 있어 | 보완, 안정 |
| 아생 | 챙기고 베풀게 되는 사이 | 돌봐주며 뿌듯한 사이 | 혼자 애쓰다 지칠 수도 있어 | 돌봄, 베풂 |
| 극아 | 팽팽하게 자극이 오가는 사이 | 긴장이 성장으로 이어져 | 세게 부딪힐 수 있어 | 자극, 긴장 |
| 아극 | 내가 끌고 나가게 되는 흐름 | 주도적으로 이끌어가 | 밀어붙이게 될 수도 있어 | 주도, 추진 |
| 비화 | 닮아서 말 안 해도 통하는 사이 | 편하고 공감이 잘 돼 | 비슷해서 무뎌질 수도 있어 | 공감, 편안 |
- 알 수 없는 element → 폴백(`prose:"이어져 있는 사이", good/caution 빈 문자열 또는 생략, kw:[]`).
- 특별 인연 키워드 추가: `heavenlyCombo`→"끌림", `sixCombo`→"결속", `triadShared`→"같은 결"(kw 배열 뒤에 append).

### InyeonDetail 렌더 구조(신규 반영)
1. **인연 점수 + 등급**(기존 블록, 등급 여기 포함 — §3에서 행에선 뺌).
2. **A prose**(`relationDetail.prose`) — 한 줄.
3. **B 키워드 칩**(`relationDetail.keywords` → `#키워드` 칩들).
4. **(pivotIsMe만) 40칸 카피** 내가 보는 X / X가 보는 나(기존 유지). 게스트끼리(pivotIsMe false)는 A prose로 대체(오행 라벨 단독 줄 제거).
5. **D 잘 맞는 점 / 살짝 조심**(good/caution 2줄, good/caution 비면 생략).
6. **뱃지**(케미 스파크/결속, 기존).
- `oriented` 없음(삼합-only) → §2의 "같은 결 (삼합)" 메시지(A/B/D 스킵) — 쌍 오행이 없어 서술 불가.
- `relationDetail(oriented.element, ...)` 호출. element·bond 는 InyeonDetail에 이미 들어오는 값(oriented.element, heavenlyCombo, sixCombo, inyeon.reasons엔 이미 triadShared 반영). triadShared 는 §1 폴리시로 이미 prop 있음.
