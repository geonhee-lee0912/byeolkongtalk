## 3. 진단 — 숫자가 말하는 것

1. **결제는 첫 세션 안에서 끝난다.** p90 49분. 리텐션은 결제를 만들지 못하고(D7 5%), 재결제 25명이 매출 31%를 만든다 → 재결제는 소수 고밀도.
2. ~~**가입당 매출은 오르고 있다** (₩231→₩309, +34%).~~ 🔴 **정정 (같은 날 A·B·C 심층분석)**: 위 수치는 캘린더 월 기준이라 구 코호트 재결제가 섞였다. **가입 코호트 기준 W3 ₩351 → W4 ₩225 → W5 ₩252 로 하락 중**. 앵커 상향(08-28)은 ARPPU 만 회복(₩2,753→₩3,392). 원인 위치 = 리딩 후 잔액 5별 페이월의 결제율 붕괴(4.7%→2%) — `2026-09-19-페이월-재결제-소재-심층분석-findings.md` §A-3·§D.
3. ~~**love 소재는 볼륨 엔진이지만 유저 질이 가장 낮다**~~ 🔴 **기각 (심층분석 C)**: 시기를 통제하면 오가닉도 같은 궤적(D7 18%→9%→0%)으로 떨어진다. 리텐션 하락은 소재가 아니라 시대(제품 상태) 효과. 소재 교체는 레버가 아님.
4. **오가닉이 유료보다 덜 산다**(5.3% vs 8.9%) — 무료 바이럴(별자리·MBTI)이 노출 0 이라 실측 불가. "무료 신상품 → 오가닉 → 매출" 가설은 아직 검증된 적 없음.
5. **8월 확장(우리 사이·시뮬·허브)은 매출 기여 0** — 패스 6·스킬 1·시뮬 16. 이미 08-31 철수 결정.
6. **대화 품질 개선은 실재하나 매출로 번역되는 폭이 작다** — 결과열람 33→65% 동안 결제율은 8~9% 대에 머묾. 결제 병목은 대화 뒤 페이월(§2-6)에 있을 가능성.
