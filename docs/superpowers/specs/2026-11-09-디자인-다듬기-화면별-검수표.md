## 결정

### 묶음 0 앱 껍데기 (11-09~11-12)
- 앱 아이콘: 캐릭터가 너무 큼 → 폭 65%(B안), iOS·안드로이드 같은 비율. 안드로이드는 앞판(투명 얼굴)·뒤판(밤색 번짐) 분리
- 스플래시: 어두운 바탕은 별로 → **흰 바탕 + 캐릭터 뒤 연보라 번짐 + '별콩톡' 타이틀**(진보라 디스플레이 글꼴). 캐릭터 크기는 그대로, 꼬리 때문에 틀어져 보이던 가운데를 몸 중심선에 맞춤
- 알림 아이콘: 네 갈래 별은 다른 앱(글램)과 비슷 → **카드 두 장 + 별(B 보강 — 틈·별 키움)**. 알림 색 진보라 그대로
- 알림 모양: 그대로 · 앱 로딩 덮개: 그대로
- 오프라인 화면: 웹 규칙대로 — 주 버튼(accent·12·52), 보조색 #726398, 별콩이 그림

### 묶음 1 홈 (11-12)
- ① 맨 위 배너: 글자가 그림 위에 겹치고 버튼이 옛 연보라 → **흰 카드(그림 200 + 아래 글자 칸)**, 주 버튼, 좌우 화살표 뺌
  - 30일 운영 실측: 홈 방문자 중 배너를 누른 사람은 고민 카드의 약 1/7. 얇은 배너가 맞지만 지금 그림은 얇게 자르면 얼굴만 남아 → ROADMAP 나중(가로 그림 새로 + 배너 구성)
- ② 고민 카드: 그림 칸 바탕이 한 구역 안에서 번갈아(분홍·살구 / 하늘·연보라) → **구역마다 한 색**(연애 분홍 · 별마루·상담 연보라 · 다른 고민 하늘, A안). `EMOTION_GRADIENTS` 라 `/start`·`/concern` 도 같이 바뀜
  - 같이 고침: ① 때 가운데 ✦ 를 지우며 끊긴 구분선(홈 + 가이드 스프레드·무료→유료 안내·사주 MBTI 결과) → 한 줄, 규칙 테스트 추가 · 별마루·상담 카드 제목 15→17 · 해시태그 색 하나로
- ③ 푸터(웹만 — 앱은 `web-only` 로 숨김, 실측 확인): 반투명 판·7줄 넓은 간격 → **판 없이 위 선만, 링크 먼저(개인정보처리방침 굵게), 사업자 정보 묶어서 5줄**(A안). 로고·소개 줄은 헤더와 겹쳐 뺌. 사업자 정보는 접지 않음(법정 표시). `BusinessInfo` 라 앱 약관·사업자 정보 화면도 같은 5줄
- 미확인: 홈의 '이어서 나눌 대화' 띠·첫 방문 안내 띠(데이터 있는 계정에서만 보임)

### 묶음 1 공통 틀 (11-12)
- ① 아래 탭: 칸 사이 세로선·선택 탭을 통째로 감싼 큰 칸·안 고른 탭도 진한 아이콘 → **아이콘 뒤 작은 알약(C안)**, 안 고른 탭 아이콘은 연보라(lilac-deep, 아이콘만)·라벨은 text-light
- ② 헤더: 앱 탭 제목이 검정 굵은 고딕이라 웹 로고(진보라 디스플레이)와 따로 놀고, 비로그인 '로그인'이 회색 글자라 안 보임 → **앱 탭 제목 진보라 + 로고 글꼴(B안)**, **로그인은 테두리 알약(2안)** — 로그인하면 같은 자리에 뜨는 별 잔액 알약과 같은 모양(웹·앱 같이). 바탕을 채운 버튼은 과해서 뺌. 앱 하위 화면 '‹ 제목'도 진보라로(글꼴은 그대로)
  - 로그인 뒤 웹 헤더: 잔액 알약 + 얼굴·이름 알약 두 개가 걸림 → **잔액 알약만(A안)** — 앱 헤더와 같아짐. 내 정보는 아래 '마이' 탭(웹도 있음)
