## 결정

### 묶음 0 앱 껍데기 (11-09~11-12)
- 앱 아이콘: 캐릭터가 너무 큼 → 폭 65%(B안), iOS·안드로이드 같은 비율. 안드로이드는 앞판(투명 얼굴)·뒤판(밤색 번짐) 분리
- 스플래시: 어두운 바탕은 별로 → **흰 바탕 + 캐릭터 뒤 연보라 번짐 + '별콩톡' 타이틀**(진보라 디스플레이 글꼴). 캐릭터 크기는 그대로, 꼬리 때문에 틀어져 보이던 가운데를 몸 중심선에 맞춤
- 알림 아이콘: 네 갈래 별은 다른 앱(글램)과 비슷 → **카드 두 장 + 별(B 보강 — 틈·별 키움)**. 알림 색 진보라 그대로
- 알림 모양: 그대로 · 앱 로딩 덮개: 그대로
- 오프라인 화면: 웹 규칙대로 — 주 버튼(accent·12·52), 보조색 #726398, 별콩이 그림

### 묶음 1 홈 (11-12)
- ① 맨 위 배너: 글자가 그림 위에 겹치고 버튼이 옛 연보라 → **흰 카드(그림 200 + 아래 글자 칸)**, 주 버튼, 좌우 화살표 뺌
  - 30일 운영 실측: 홈 방문자 중 배너를 누른 사람은 고민 카드의 약 1/7. 얇은 배너가 맞지만 지금 그림은 얇게 자르면 얼굴만 남아 → ROADMAP 나중(가로 그림 새로 + 배너 구성)
- ② 고민 카드: 그림 칸 바탕이 한 구역 안에서 번갈아(분홍·살구 / 하늘·연보라) → **구역마다 한 색**(연애 분홍 · 별마루·상담 연보라 · 다른 고민 하늘, A안). `EMOTION_GRADIENTS` 라 `/start`·`/concern` 도 같이 바뀜
  - 같이 고침: ① 때 가운데 ✦ 를 지우며 끊긴 구분선(홈 + 가이드 스프레드·무료→유료 안내·사주 MBTI 결과) → 한 줄, 규칙 테스트 추가 · 별마루·상담 카드 제목 15→17 · 해시태그 색 하나로
- ③ 푸터(웹만 — 앱은 `web-only` 로 숨김, 실측 확인): 반투명 판·7줄 넓은 간격 → **판 없이 위 선만, 링크 먼저(개인정보처리방침 굵게), 사업자 정보 묶어서 5줄**(A안). 로고·소개 줄은 헤더와 겹쳐 뺌. 사업자 정보는 접지 않음(법정 표시). `BusinessInfo` 라 앱 약관·사업자 정보 화면도 같은 5줄
- 미확인: 홈의 '이어서 나눌 대화' 띠·첫 방문 안내 띠(데이터 있는 계정에서만 보임)

### 묶음 1 공통 틀 (11-12)
- ① 아래 탭: 칸 사이 세로선·선택 탭을 통째로 감싼 큰 칸·안 고른 탭도 진한 아이콘 → **아이콘 뒤 작은 알약(C안)**, 안 고른 탭 아이콘은 연보라(lilac-deep, 아이콘만)·라벨은 text-light
- ② 헤더: 앱 탭 제목이 검정 굵은 고딕이라 웹 로고(진보라 디스플레이)와 따로 놀고, 비로그인 '로그인'이 회색 글자라 안 보임 → **앱 탭 제목 진보라 + 로고 글꼴(B안)**, **로그인은 테두리 알약(2안)** — 로그인하면 같은 자리에 뜨는 별 잔액 알약과 같은 모양(웹·앱 같이). 바탕을 채운 버튼은 과해서 뺌. 앱 하위 화면 '‹ 제목'도 진보라로(글꼴은 그대로)
  - 로그인 뒤 웹 헤더: 잔액 알약 + 얼굴·이름 알약 두 개가 걸림 → **잔액 알약만(A안)** — 앱 헤더와 같아짐. 내 정보는 아래 '마이' 탭(웹도 있음)
- ③ `/start`: **건너뜀** — 운영 실측 14일 광고 방문자 전원이 홈(`/`)으로 들어오고 `/start` 조회 0회. 다시 광고 착지로 쓰게 되면 그때 카카오 버튼 45→52 맞춤(A안)부터
- `/select`: 볼 화면 없음(옛 주소 → `/concern` 넘김만)
- ④ `/concern` 고른 고민 띠: 연보라 보조 버튼 안에 제목·'변경'(흐린 작은 글자)·설명이 몰려 있음 → **흰 카드 한 줄(A안)** — 홈 고민 카드와 같은 구역색 그림 칸(48) · 제목 15 · 설명 · 오른쪽 '바꾸기' 테두리 알약
- ⑤ `/concern` 별콩이 대화 칸: 별콩이 인사가 오른쪽 노란 말풍선(내 말 자리)·위 큰 프로필 카드 → **카카오톡 대화방 틀(K1안, 밤하늘 유지)** — 위 바는 작은 얼굴+이름만, 왼쪽 둥근 네모 프사+이름+흰 말풍선(왼쪽 위 뾰족), 입력칸은 판 아래 끝까지 붙는 입력창. 운영자가 카톡 화면을 참고로 줌(원래 노린 느낌). 밝은 연보라 판(K2)과 비교함
- ⑥ `/concern` 아래 '뒤로': 앱은 위 헤더 ‹ 와 겹침 → **앱에서만 숨김(A안, web-only)**, 웹은 그대로
- ⑦ `/concern` '바꾸기'·고민 고르기 창: 뒤로(웹 아래 '뒤로' · 앱 ‹)와 같은 일을 하는 두 번째 길 → **'바꾸기'와 고르기 창을 없앰**(운영자). 고민 카드는 보여 주기만. 글 적다 바꾸면 적던 글이 사라지는 차이만 있음(드묾). 누른 횟수 기록은 없었음
- ⑧ `/login`: 위로 몰리고 아래 40% 빔 → **그림·인사 위쪽 가운데 + 로그인 버튼 아래(A안)**. 같이: '이미 카카오로 가입했다면…' 안내 뺌(운영자 — 카카오 회원이 Apple 로 새 계정을 만들 수 있다는 위험은 설명함, 병합은 나중) · '카카오로 시작하기'→'카카오로 계속하기'(Apple 과 같은 말) · 두 버튼 52 · 제목 로고 글꼴 · '나중에 할래' 대신 **왼쪽 위 ‹**(들어오기 전 화면으로, 기록 없으면 홈). 약관 줄('시작하면 … 간주돼')은 그대로 — 운영자 질문으로 법·심사 점검만 함(만 14세 이상 넣기는 선택지로 남김)
- ⑨ `/how-to-use` '뭘 할 수 있어': 카드 4개 제목 위가 빈 칸(① 이모지 정리 때 이모지만 지움)·이름이 옛 것(별콩 운세·연애 시뮬, 별마루 없음)·눌러도 안 감 → **그림 + 지금 탭 이름(타로톡·사주 운세·별마루·연애 상담) + 누르면 그곳으로(A안)**

### 공통 — 화면 바탕 (11-12, ① 에서 미뤄 둔 것)
- 크림→연보라 세로 그라데이션: 아래쪽이 연보라라 보조 버튼·칩·비활성 버튼이 묻히고, 크림인 헤더·아래 탭과 띠가 지고, 흰 카드 대비가 위아래로 달라짐 → **따뜻한 회색 단색 #F6F5F2(D안)**. 크림 #FAF6F0 · 옅은 연보라 · 회보라 #F4F3F7 · 웜그레이 #F4F2EE 와 비교해 고름(회보라가 가장 덜 AI 같지만 차가워서 그 사이)
  - `--color-cream` 값만 바꿔 화면·헤더·탭·시트가 같이 바뀜(이름은 그대로). `themeColor` · 앱 웹뷰 바탕 · 앱 오프라인 화면도 같은 색. 알약(`cream-warm`)은 그대로
  - 함정: `@theme` 안 색 값 줄 끝 메모에 다른 색 코드(#…)를 쓰면 Tailwind 가 그 값을 집었다 — 메모에 색 코드 쓰지 말 것

### 공통 — 못 누르는 주 버튼 (11-12)
- 주 버튼 색 40% 흐리게 → 회색 바탕과 섞여 탁한 회보라 → **회색 바탕 #E7E5E1 · 회색 글자 #A5A1AA(B안)**. `btn-primary` 한 곳이라 전 화면 같이. 옅은 연보라(A)는 보조 버튼과 같은 색이라, 흰 바탕+테두리(C)는 눌러도 되는 버튼처럼 보여서 뺌. 보조·글자 버튼의 못 누름은 그대로(흐리게)
