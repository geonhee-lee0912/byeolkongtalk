# 별자리 포커스/걸어다니기 재설계 — 설계 (2026-08-21)

지도 확대/축소를 "나+누른 별 2개만" → **"나 + 누른 별 + 그 별과 연결된 지인들"(3단 포커스)**로 바꾸고, 이웃 별을 눌러 **관계망을 걸어다니게** 하며, 지인-지인 선을 눌러 그 관계를 **열람**할 수 있게 한다. 위계 이동은 **breadcrumb**.

## 0. 배경 / 문제

- 지금 규칙: 지인 X를 누르면 `나+X`만 밝게 확대(focusPair) + 나머지 dim, 아래 `나↔X` 카드.
- 관계망 재설계로 **지인-지인 특별 인연(천간합/육합)** 선이 그려지는데, 현재 확대 규칙으론 그걸 **콕 찍어 보거나 정보를 열 수 없다**(탭은 항상 나 기준, 확대하면 X의 다른 인연이 dim돼 사라짐). "진짜 관계망"을 그려놓고 나-중심 관계만 열람 가능한 상태.
- 또, 특별 인연 없는 나-X는 확대 시 **둘 사이 선이 없어 붕 뜬다**.

## 1. 포커스 규칙 (지도 탭)

- 아무 별 **X 탭 → 포커스(X)**: 화면에 **{나, X, X와 연결된 지인들}**만 남기고, 나머지 노드/선은 dim이 아니라 **제거**.
  - "연결된 지인" = X와 **천간합/육합 엣지**가 있거나 **같은 삼합 국**인 게스트. (그게 유일한 지인-지인 관계)
  - 나(호스트)는 항상 포함(나-X 호스트 엣지는 늘 존재, 나 = 관계망 뿌리).
- **걸어다니기**: 포커스 뷰에서 이웃 별 **Y 탭 → 포커스(Y)**(같은 규칙 재적용). 지금의 "나+그 별 확대"를 대체.
- 빈 공간 탭 → 전체 지도 복귀.

## 2. 포커스 렌더 — 재배치 + 새 선

- **재배치(= 확대 효과)**: 포커스(X)에선 **X를 중심**에 두고 {나, 이웃들}을 그 둘레에 배치(overview 는 호스트 중심). `computeLayout`에 **중심 노드 지정** 파라미터를 추가해 재사용. 노드 수가 적으니 `scaleForCount(focusSet.length)`로 자연히 커짐 → **별도 transform 줌 없이** "확대"가 됨(구현 단순화; 부드러운 애니메이션은 후속).
- **새 선**(overview 선은 안 쓰고 포커스 전용으로 새로):
  - `나 – X`: 항상. 특별 인연이면 금색(끌림 실선/결속 점선), 아니면 **옅은 중립 연결선**("지금 보는 관계" 표시 — 붕 뜸 방지).
  - `X – 각 이웃`: 실제 인연(끌림 실선/결속 점선).
  - 삼합 이웃: 기존 삼합 표식(같은 국 색 glow+점) 유지. (삼합은 선 아님)
  - 성상: X 중심 방사(spoke). 이웃끼리(나-이웃 포함) 선은 안 그림 — 걸어가면 그 노드 중심으로 다시 보임.
- 노드 모양: 나=원 / X·이웃=별(현행). 오행색 유지.

## 3. 상세 — 탭 대상으로 구분

- **별(노드) 탭 = 걸어가기** → 아래 카드 = `나 ↔ 그 별`(현행 `InyeonDetail` 그대로, 나 기준 40칸 카피 포함).
- **선 탭 = 관계 열람** → 그 선 두 끝(A–B)의 상세를 카드에:
  - 나-X 선 → `나 ↔ X`(위와 동일).
  - **지인-지인 선(X–이웃) → 그 둘의 상세**: 인연 점수 + 등급 + 근거(끌림/결속/삼합/오행 관계 라벨). **관계분류 40칸 카피 없음**(지인끼린 분류 미지정) → 오행 관계 라벨 + 천간합/육합 뱃지로 구성. `InyeonDetail`의 경량 변형 또는 분기.
- 선 탭은 **포커스/걸음 상태를 바꾸지 않음**(그 자리서 카드만 A–B로 스왑, 다시 다른 데 탭하면 복귀). 노드 탭만 걸음(breadcrumb 갱신).

## 4. 위계 이동 — breadcrumb

- 상단에 걸어온 경로: `전체 › 하준 › 서윤`.
  - 크럼 탭 = 그 지점 포커스로 점프(그 뒤 스택 잘라냄).
  - "전체" = 전체 지도(스택 비움).
- 걸어온 노드 id **스택**(`focusPath: string[]`)으로 관리. 비면 overview.
- 이름 비공개 노드는 크럼에 "이 별".

## 5. 상태 모델 (ConstellationView)

- `focusPath: string[]` — 지도 걸음 경로(빈 배열=overview). 현재 포커스 = 마지막 원소.
- `listOpenId: string | null` — 순위 리스트 아코디언(지도와 별개·상호배타: 리스트 열면 focusPath 비우고, 지도 포커스 진입 시 listOpen 닫음).
- `inspectedPair: [string, string] | null` — 선 탭 열람(포커스 뷰 한정, transient). 노드 탭·크럼·배경 탭 시 해제.
- 카드 우선순위: `inspectedPair` 있으면 그 A↔B, 아니면 포커스 노드의 `나↔X`.

## 6. 필터·순위 상호작용

- 관계타입 필터(끌림/결속/무리)는 **overview에서만** 노출/작동. 포커스 뷰에선 숨김(한 별의 이웃만 보는 화면이라 불필요).
- 순위 리스트 아코디언(나 기준)은 **그대로**(§5 상호배타). 순위 행 탭은 지금처럼 아코디언(지도 포커스와 별개).

## 7. 파일 (예상)

- `lib/byeoljari/layout.ts` — `computeLayout(nodes, { center? })` 중심 노드 지정 지원(순수, 테스트). 포커스 세트 계산 헬퍼(`neighborsOf(X, edges, triads)`)도 순수 TDD.
- `components/byeoljari/ConstellationCanvas.tsx` — 포커스 모드 렌더(포커스 세트만, X 중심 재배치, 새 선 3종), 선 클릭 핸들러(`onEdgeSelect`), 중립 나-X 선.
- `components/byeoljari/ConstellationView.tsx` — 상태(focusPath/inspectedPair) + breadcrumb UI + 카드 분기 + 필터 overview 한정.
- `components/byeoljari/InyeonDetail.tsx` — 지인-지인용 경량 표시(관계분류 없을 때 40칸 카피 생략, 오행+뱃지).
- (전체 지도↔포커스 전환은 focusPath 로만, 기존 focusPair/pairIds/transform 지도 줌 로직은 정리.)

## 8. 테스트

- `neighborsOf` / `computeLayout(center)` 순수 유닛 TDD(이웃 추출: 천간합·육합·삼합·나 포함; 중심 노드 배치).
- 브라우저 E2E(로엔 `7uBv0cLKet`): 별 탭→3단 포커스(나+X+이웃, X 중심, 새 선) · 이웃 탭→걸어가기+breadcrumb 갱신 · 지인-지인 선 탭→그 관계 상세 · 크럼/전체/배경 복귀 · 순위 아코디언 무회귀 · 콘솔0.

## 9. 스코프 밖 / 후속

- 전환 애니메이션(재배치라 부드러운 줌 아님 — 우선 즉시 전환, 후속 개선).
- 레이아웃 시안(나·X·이웃 배치 미세)은 구현·E2E에서 실물로 조정.
- 지인-지인 방향 카피(A→B 40칸)는 지인끼리 관계분류가 없어 스코프 밖(오행+뱃지로 충분).
