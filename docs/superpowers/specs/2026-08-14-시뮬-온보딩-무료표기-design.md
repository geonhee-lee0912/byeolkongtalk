# 시뮬 온보딩 안내 + 허브 무료 표기 (2026-08-14)

시뮬 무료 런웨이/초상화(`2026-08-14-시뮬-무료-런웨이-초상화-design.md`)의 **후속 UX** — 무료 정책과 "고도화해야 즐긴다"는 가치를 화면에 노출한다. 라우트·DB·마이그레이션 변경 0(순수 프론트).

## 배경
무료 런웨이·초상화·훅은 dev에 구현됐으나 유저가 그 존재/의미를 화면에서 못 느낀다. 두 곳에 안내를 붙인다.

## ① 시뮬 상황 선택 화면(`SituationSelect`) — "이게 뭐야?" 안내 칩

- **관계 칩 맨 앞에 새 칩 추가**: `🎭 이게 뭐야?` (관계가 아니라 안내 탭).
- **진입 시 이 칩이 기본 선택** — 처음 들어오면 설명부터 보인다. 관계 칩을 탭하면 그 관계 상황 목록으로.
- 이 칩 활성 시 아래 영역은 상황 카드 대신 **설명 블록**(선택 불가 안내 패널). 다른 칩 = 기존 상황 목록(`getSituations`).
- **설명 카피(정본):**
  > 🎭 **연애 시뮬이 뭐야?**
  > 네가 그린 **그 사람 인형**과 **여러 가지 상황**을 미리 연습하는 리허설이야. 별콩이가 상황을 여럿 준비해두지만, **원하면 네가 직접 상황을 적어도 돼!**
  > 인형은 **네가 다듬을수록 더 걔처럼** 돼 — 이렇게 키워:
  > · 대화 중 인형 대사에 **👍 / 👎**로 "실제론 이래" 알려주기
  > · **디브리핑**에서 "걔는 사실 이런 사람" 한 줄 적어주기
  > · 걔 **기본 정보**(MBTI·성격)를 프로필에 채워두기
  > 안 채워도 쓸 순 있지만, 그만큼 **실제 걔와는 많이 달라질 수밖에 없어.** 몇 판 쌓여야 진짜 걔 같아지니까, **처음 몇 판은 무료**로 부담 없이 만들어봐.
- 밤 무대 톤(cream-warm/lilac) 유지. 불릿 3개는 목록으로.

## ② 허브 상품 목록(`ProductList`) — 무료 배지

- **💬 연애 상담 카드:** 정적 배지 **"첫 3턴 무료 · 이후 패스"**.
- **🎭 시뮬 카드:** 동적 배지(선택 상대의 쿼트로) —
  - `funding='runway'` → **"무료 N판 남음"** (N=`runwayRemaining`)
  - `funding='hook'` → **"이번 주 무료 판"**
  - `funding='paid'` → **"판당 {cost}별"**
  - 쿼트 로딩/실패 → 배지 생략(자리만).
- 배지 = 해시태그 줄과 구분되는 작은 pill/텍스트. 카드 레이아웃 큰 변경 없이.

**데이터 흐름:** 허브(`app/relationship/page.tsx`)가 상대(`selected`)가 실제 사람일 때 `GET /api/relationship/sim/quote?relationshipId=${selected}` 1회 호출(selected 변경 시 갱신, `me` 앵커면 호출 안 함) → `{funding, cost, runwayRemaining}`를 `ProductList` 에 prop 전달. 쿼트 엔드포인트는 기존(rate-limit 있음).

## 갱신 (2026-08-14 디자인 수정 — 사용자 피드백, 최종)
- **무료 표기 = 짧은 설명 + 제목 옆 회수 + 도트 (시안 B, 최종).** 배지(금색 pill) 어색 → 설명글에 다 녹이니 너무 김 + 회수 안 보임 → 목업 3안(우측뱃지/제목옆도트/하단칩) 중 **B 채택·고도화**. 카드 = **짧은 설명 1줄** + 제목 옆 **회수 라벨**(진금색 `#B07E1C`, "무료 N회 남음" / 상담 "무료 3턴") + (시뮬) **도트 ●●○**(런웨이 남은 판 시각화, filled/total) + 주간 노트 "이후 주 1회 무료" + **해시태그 유지**.
  - 설명글: 상담 "별콩이가 너의 연애 이야기를 다 기억해 줄게!" / 시뮬 "그 사람과의 여러 가지 상황을 연습해 봐. 이야기할수록 그 사람과 비슷하게 시뮬레이션할 수 있어!"
  - 헬퍼 `simCount(quote) → {label, filled, total, note}`(TDD). 허브 `/sim/quote` fetch 재연결(funding·runwayRemaining으로 도출 — `weeklyAvailable` 불필요). 쿼트는 진입 정직한가격에도 계속 쓰임.
- **시뮬 설명:** "더 걔처럼" → **"더 그 사람처럼"**.
- **칩 스크롤:** `flex-wrap` 폐기 → **가로 스크롤 + `scrollbar-hover`**(우리 커스텀: 평소 숨김·hover 시 얇은 테마 썸·시스템 스크롤바 아님). globals `.scrollbar-hover::-webkit-scrollbar` 에 가로용 `height:4px` 추가.
