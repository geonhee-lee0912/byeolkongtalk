# 사주 MBTI — 사주→축 매핑 로직 설계 (하위 프로젝트 A)

> 신규 무료 서비스 "사주 버전 MBTI 테스트"의 하위 프로젝트 중 **A(사주→축 매핑 로직)** 만 다룬다.
> B(문항 확정)·C(콘텐츠 집필)·D(결과 화면)·E(프로덕트 플로우)는 각자 별도 스펙.
> 원 기획서: `~/Downloads/saju-mbti-test-기획정리.md`. 작성 2026-08-23.

## 1. 목표 · 범위

생년월일시 → **팔자 유형**(4축 2분법 + 오행 주기질)을 산출하는 **결정론 순수 모듈**. LLM 미경유(별자리 지도와 동일 노선).

- **입력**: `SajuInput`(양/음력 생년월일시 + 시간 모름 허용) → `calcSaju`(tyme4ts, 절기·야자시 정확) → `SajuResult`.
- **출력**: 축별 `{raw, pct, pole}` × 4 + 16 한글코드(예: `음유인생`) + 오행 주기질 + 십신/지장간 raw(결과 카드 양념용).
- **비범위**: 문항 기반 자아 유형(B), 일치율 최종 비교 UI(A·B 통합 지점), 결과 카드 렌더(D).

**핵심 원칙 — 축 간 재료 분리**: 4축이 서로 다른 사주 정보를 써야 유형이 뭉개지지 않는다.
| 축 | 사용 재료 |
|---|---|
| 음/양 | 표기상 음양 + 오행 기질 음양 |
| 강/유 | 신강/신약(득령·득지·득세) |
| 재/인 | 십신 클러스터 |
| 생/단 | 오행 상생/상극 이웃 관계 |
| (주기질) | 오행 분포(개수) |

## 2. 팔자 추출 & 공통 규칙

- **팔자**: `calcSaju(input)` 의 `pillars`(년/월/일/시 각 천간·지지, 한글). tyme4ts 기반이라 절기(입춘 년주·절기 월주)·야자시 정확.
- **위치 가중치표** (전 축 공통):
  | 년간 | 년지 | 월간 | 월지 | 일간 | 일지 | 시간 | 시지 |
  |---|---|---|---|---|---|---|---|
  | 1.0 | 1.0 | 1.2 | **3.0** | 기준점(합산 제외) | 1.5 | 1.0 | 1.0 |
  - 일간은 십신·신강신약의 **기준**이라 합산에서 제외. 단 생/단 축의 이웃 쌍 관계에서는 참여자로 쓰며 가중치 1.5 부여(일주 비중).
- **지지 → 지장간 본기 환원** (★결정②, 전 축 공통): 지지가 **오행·십신으로 환원될 때** 본기 천간을 쓴다(정통성↔난이도 타협, 중기·여기 무시). 정적 테이블:
  `자→계, 축→기, 인→갑, 묘→을, 진→무, 사→병, 오→정, 미→기, 신→경, 유→신, 술→무, 해→임`
  - **예외**: 음양 축의 "표기상 음양" 성분은 정의상 **표면 지지**(자=양, 축=음…)를 쓴다("표기상"=표면 표기).
- **시간 모름** (★결정①): `hourKnown=false` 면 **시주(시간·시지) 제외 = 6글자**로 계산(가중치 합에서 시간·시지 제거). `calcSaju` 는 시간 모름 시 자시로 채우지만 매핑은 그 두 글자를 **버린다**.

## 3. 4축 산출법

각 축은 **원점수(raw)** 를 낸 뒤 §4 하이브리드 보정으로 %·극을 얻는다.

### 3.1 음/양 (표기상 70% + 오행기질 30%) — ★결정③
글자별 음양점수:
```
표기상음양(t)  = 천간/지지 index 짝수 → +1(양), 홀수 → −1(음)   // 지지는 표면
오행기질음양(e) = 목·화 → +1, 금·수 → −1, 토 → 0            // 지지는 본기 오행
글자점수 = 0.7·t + 0.3·e
raw_음양 = Σ(글자점수 × 위치가중치)          // 양(+)일수록 양
```

### 3.2 강/유 (신강/신약)
```
득령 = 월지(본기 오행)가 일간을 비화(같은 오행) 또는 생(생아) → 40점, 아니면 0
득지 = 일지(본기 오행)가 일간을 비화/생아 → 20점, 아니면 0
득세 = 나머지 글자(일간·월지·일지 제외 = 년간·년지·월간·시간·시지, 5글자[시간모름 3], 본기 환원)
       중 비겁(비화)·인성(생아) 세력을 위치가중 합산, (비겁·인성 가중합 / 전체 나머지 가중합) × 40
       ※ 일지는 득지에서 이미 셈 → 득세 중복 제외(위치 기준, 글자값 아님)
raw_강유 = 득령 + 득지 + 득세     // 0~100, 클수록 강(신강)
```
- 오행 관계 판정은 `lib/saju/pairing.ts` 의 `elementRelation`(비화/생아/아생/극아/아극) 재사용.
- 문서 경고(신약 쏠림)는 §4 분위수 컷이 흡수.

### 3.3 재/인 (십신 클러스터) — ★결정④
```
각 글자(일간 제외, 지지는 본기)의 십신 = pairing.ts tenGod(일간, 글자천간)
재 진영 = 재성(편재·정재) + 관성(편관·정관)
인 진영 = 인성(편인·정인) + 식상(식신·상관)
비겁(비견·겁재) = 제외
R = 재 진영 글자들의 위치가중 합, I = 인 진영 위치가중 합
raw_재인 = R − I         // +일수록 재
```

### 3.4 생/단 (관계 카운트법) — ★결정⑤
이웃 글자 쌍 10개의 오행 관계를 판정:
```
쌍 집합 = 각 기둥 간-지 4쌍(년·월·일·시)
        + 인접 천간 3쌍(년간-월간, 월간-일간, 일간-시간)
        + 인접 지지 3쌍(년지-월지, 월지-일지, 일지-시지)
각 쌍의 오행(본기 환원) 관계(elementRelation):
   상생(생아·아생) → G 진영,  상극(극아·아극) → K 진영,  비화 → 중립(제외)
쌍 가중치 = 두 글자 위치가중치의 평균(일간=1.5)
G = 상생 쌍 가중합, K = 상극 쌍 가중합
raw_생단 = G − K         // +일수록 생(북돋움)
```

### 3.5 오행 주기질 (오각차트용)
```
8글자(본기 환원) 오행을 위치가중 합산 → 목/화/토/금/수 분포
  - 일간 포함(오각차트는 본인 오행이 빠지면 안 됨). 일간 가중 = 1.5(일지와 동일, 축 합산의 "기준점 제외"와 별개 예외)
주기질 = 최다 오행, 동점 시 월지(본기) 오행 우선, 그다음 정순(목화토금수)
```
- 결과 카드 오각차트 데이터로도 그대로 사용.
- ⚠️ 본기 기준이라 사주판(SajuBoard, 표면 지지)의 `elementCount` 와 미세하게 다를 수 있음 — 의도된 것(테스트 자체 규칙). D(결과화면)에서 "사주판 오행"과 "유형 오각차트"를 섞어 보여주지 말 것.

## 4. 하이브리드 보정 (합성 샘플) — ★결정③(데이터)

명리 점수(raw) → **인구 백분위 = 축 %**, 극 = 백분위 ≥ 50 여부. 컷(50번째)이 곧 균형점이라 쏠림이 구조적으로 해소된다.

- **합성 샘플 생성**: 1970-01-01 ~ 2010-12-31 **매일**(시각은 정오 고정 = 오시, 시주 노이즈 제거) ≈ 1.5만 건. 각 건의 4축 raw 계산.
- **분위수 테이블**: 축별 raw 분포에서 5% 간격 분위점(P5, P10, …, P95 + min/max)을 뽑아 **코드 상수**로 저장.
- **런타임 매핑**: 유저 raw → 분위 테이블 선형보간 → 백분위(%) = 축 %. `pct ≥ 50 → 앞극(양·강·재·생)`, `< 50 → 뒷극(음·유·인·단)`.
- **보정 스크립트**는 재현 가능한 dev 툴(`scripts/`), 결과 상수만 커밋. 실유저 생일 미사용(프라이버시·재현성).
- **분포 검증**: 합성 샘플로 16유형 분포를 확인 — 특정 유형 과대(예: >15%)·과소(<2%) 시 재료·가중치 재점검. 목표는 "극단 쏠림 없음"이지 완전 균등은 아님.

## 5. 출력 형태

```ts
interface PaljaType {
  axes: {
    yinYang: { raw: number; pct: number; pole: "양" | "음" };
    strength: { raw: number; pct: number; pole: "강" | "유" };
    wealth:   { raw: number; pct: number; pole: "재" | "인" };
    nurture:  { raw: number; pct: number; pole: "생" | "단" };
  };
  code: string;          // "음유인생" (4극 순서: 음양·강유·재인·생단)
  element: FiveElement;  // 오행 주기질
  elementDist: Record<FiveElement, number>; // 오각차트용 가중 분포
  tenGods: string[];     // 글자별 십신 raw (카드 양념)
  jangan: string[];      // 지지 본기 raw (카드 양념)
}
```
- **일치율**은 이 `axes[*].pct`(팔자) 와 문항(B) 자아 %의 **축별 차 평균**. 비교 로직·구간 서사(80↑/50~80/50↓)는 A·B 통합 지점(별도)에 둔다. A는 팔자 %만 책임.

## 6. 코드 구조

- 신규 `lib/saju-mbti/` 순수 모듈:
  - `mapping.ts` — `paljaType(saju: SajuResult, opts): PaljaType`
  - `constants.ts` — 위치 가중치, 지장간 본기 테이블, 분위 테이블(보정 산출물)
  - `mapping.test.ts` — 축별 산출·경계·시간모름 회귀
- **재사용**: `lib/saju/calc.ts`(팔자), `lib/saju/pairing.ts`(`elementRelation`·`tenGod`·`STEM_ELEMENT`).
- **무변경**: `calc.ts`/`SajuResult`/DB 스키마 — 매핑은 `SajuResult` 위에서만 파생(본기·십신은 pairing.ts + 정적 테이블로 자체 계산).
- 보정 스크립트: `scripts/saju-mbti-calibrate.mjs`(합성 샘플 → 분위 테이블 출력, 결과를 `constants.ts` 에 반영).

## 7. 검증 (성공 기준)

- 단위 테스트: 각 축 산출이 손계산과 일치(고정 사주 몇 개), 시간모름 6글자, 음력/윤달 경유.
- 분포 시뮬: 합성 샘플에서 ①각 축 극이 대략 50:50(±무리 없는 편차) ②16유형 극단 쏠림 없음(>15%/<2% 유형 점검).
- 재료 분리 확인: 축 쌍 간 상관이 과도하지 않음(같은 정보 재사용 아님).

## 9. 후속 (다른 하위 프로젝트)

- B 문항 확정 → 자아 유형 % (A와 같은 4축 % 포맷으로 정렬).
- A·B 통합 → 일치율 + 구간 서사.
- C 콘텐츠(16유형 본문·오행 5모듈·일치율 3구간·카드문안), D 결과화면(오각차트·낙관·병렬비교), E 플로우.
