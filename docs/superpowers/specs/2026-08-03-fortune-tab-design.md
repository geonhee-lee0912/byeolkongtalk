# 사주 운세(2탭) 구체화 설계

**방식** 08-02 통합 IA의 "각 탭 구체화" 중 **2탭**. Visual companion 브레인스토밍으로 도출.

**맥락** T1 게이트(로드맵 `plans/2026-08-01-roadmap-t1-t2-t3.md`). 1탭 캐러셀 마무리(dev `6929158`) 다음 작업.

## 목표

- **큰 히어로가 상품을 밀어내던 문제 해소** — 현재 `HeroBanner`가 상단을 크게 먹어 첫 상품 카드가 fold 밖으로 밀린다. 상품(리포트)을 fold 안으로 끌어올린다.
- **확장형 구조** — 앞으로 사주 리포트를 "엄청 다양하게" 추가 예정(특히 기질·정체성 시리즈 + 시즌·이벤트). 카테고리 필터가 상품 증가를 흡수한다.

## 핵심 결정

### 1. 카테고리 = 필터 칩 (A안)

칩을 탭처럼 — **한 번에 한 그룹만** 노출. 다른 칩을 누르면 그 그룹으로 교체.

- **근거**: 지금 상품 6개엔 전체 나열(B/C안)도 가능하나, **미래 상품 증가 대비**가 결정적(사용자). 필터라 칩 추가·재편이 쉽다.
- 기각: **B**(앵커 칩 + 전체 세로 나열) · **C**(칩 없이 섹션 헤더) — 지금은 깔끔하나 상품이 늘면 무한 스크롤이 된다.

### 2. 칩 3개 + 상품 배치

| 칩 | 상품 | 기본 |
|---|---|---|
| 연애·관계 | 궁합(⭐40) · 인간관계궁합(⭐35) | |
| **타이밍** | 이번달(⭐20) · 좋은날(⭐35) · 2026 사주(⭐60) | **✓ 기본 활성** |
| 무료 | 오늘의 운세(무료 5회) | |

- **"시기" → "타이밍"** 개명 — 별콩이 반말·친근 톤과 정합. (기각: 흐름·시운·때)
- **"나" 칩 삭제** — 담을 상품이 지금 `2026 사주` 1개뿐. **미래 기질·정체성 리포트가 쌓이면 부활**. `2026 사주`는 "신년사주·2026 연간 흐름"이라 **타이밍**에 흡수(기각: 상단 고정·새 이름 칩).
- **무료 = 가격 축** (다른 칩은 주제 축) — 성격이 섞이지만 무료 상품 획득 훅으로 유효. `오늘의 운세`는 무료 칩 **전용**(타이밍에서 중복 제외).
- **기본 활성 = 타이밍** — 3개라 첫 화면이 풍성하고 60별 대표(2026 사주)가 노출된다.
- 무료 칩은 지금 1장이라 다소 허전하나 **그대로 시작(a안)**. 미래 무료 상품 추가 시 자연 해소되고, 억지 채움은 과설계. (기각: b 안내 한 줄 · c 훅 배너)

### 3. 간판 (B안 — 풍성)

큰 히어로 대신, 헤더와 분리되는 **적당한 무게의 간판**:

- 별콩이 일러스트(원형) + 세계관 배경(별·구름 장식) + 문구 "생일만 알려줘, 한 장으로 정리해줄게"
- **A(얇은 간판)로 롤백 가능한 구조** — 크기·배경을 변형 prop/플래그로 분리한다(사용자: "여차하면 A로 돌려도 되게").
- 히어로만큼 크진 않게 — 상품을 fold 밖으로 밀면 목표가 무효가 된다.
- 기각: **A**(얇음 — 헤더에 붙어 허전) · **C**(무료 배너 — 무료 칩과 역할 중복).

### 4. 레이아웃 (위 → 아래)

1. **간판 B**
2. **`FortuneGeneratingList`** (생성 중·완료·환불 알림, 조건부) — 간판 아래·칩 위
3. **카테고리 칩** (필터)
4. **필터된 상품 카드** — 현행 카드 디자인 유지(아이콘 + 라벨 + 별 비용 + 태그라인 + 해시태그)
5. **하단 안내문** ("운세는 정해진 미래가 아니라…") 유지

### 5. 제거 · 유지

- **제거**: `HeroBanner`(이 페이지에서) · "이렇게 사용해요" 카드 → 역할은 간판 문구가 흡수.
- **유지**: `FortuneGeneratingList` · 상품 카드 디자인 · 하단 안내문.

## 미래 확장

- **"나" 칩** — 기질·정체성 리포트가 쌓이면 부활. `2026 사주`를 타이밍 → 나로 이동.
- **영역군 칩** — 재물·건강·직업 같은 삶의 영역 상품이 커지면 칩 추가 또는 축 재편(필터라 부담이 적다).
- **"나" 내부 세분** — "나"가 여러 개가 되면 그 안에서 서브그룹(지금은 YAGNI).

## 구현 범위

- `app/fortune/page.tsx` — 히어로/사용법 제거, 간판 B 배치, 칩 필터 상태, 상품 그룹 필터링.
- `lib/fortune/types.ts` — 카테고리 매핑 추가(`FortuneConfig`에 `category` 필드 또는 별도 `FORTUNE_CATEGORIES` 상수) · 칩 순서·라벨. `daily`는 무료 전용으로 타이밍에서 제외.
- 신규 컴포넌트(권장): `FortuneHeader`(간판 B, A 롤백 prop) · `CategoryChips`(칩 필터).
- `FortuneGeneratingList` — 위치만 조정(로직 무변).
- `HeroBanner` — 이 페이지 사용만 제거(타 페이지에서 쓰면 컴포넌트 자체는 유지).

## 측정 (T1 내장 규칙)

- **메커니즘 지표**: `/fortune` 진입 대비 **상품 카드 클릭률**(히어로 제거로 상품 노출↑ → 클릭↑ 기대) · 칩별 클릭 분포.
- **계측 배관**(배포 시점에 함께): 칩 클릭을 `ui_events`(기존 `/api/event` + `lib/analytics/ui-events.ts` allowlist)로 기록. 상품 클릭은 기존 reading 생성 흐름으로 추적.
- **T1 배포일 = 새 baseline day 0**(로드맵 규칙). 전제품 추세와 나란히 놓지 않는다.
