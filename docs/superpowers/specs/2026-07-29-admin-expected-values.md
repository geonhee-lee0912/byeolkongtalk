## d3 판독 소견 (2026-07-29)

**1. 재방문율이 실제로 오르고 있다 — W5 "재방문 0" 의 첫 반증.**
0% → 3.8% → 8.8% → **12.2%** 4일 연속 상승. 유입 규모에 중립적인 지표라(비율) UV 가 79→49 로 준 07-28 에도 올랐다는 게 핵심이다. 다만 **표본이 4일**이고 비콘 배포일(7/25) 탓에 초기 며칠은 신규가 구조적으로 과대 → 재방문율은 **과소** 추정 상태다. 쿠키 삭제·시크릿창·기기 변경도 같은 방향으로 과소를 만든다.
⚠️ 아직 "리텐션이 생겼다"고 판정하지 말 것 — 이 상승분은 **연속(6) 중심이고 복귀는 0~2** 다. 매일 붙는 소수와 돌아오는 사람은 상품 함의가 다른데(캘린더 vs 재상담), 지금 데이터로는 전자만 보인다.

**2. 07-27 PV/UV 13.5 는 행동 변화가 아니라 소수 헤비 세션이다.**
어드민 제외 후에도 남아(어드민 PV 는 67뿐) 실제 유저 현상인데, 상위 5 `anon_id` 가 유저 PV 742 중 **222(30%)** 를 만들었다(최다 56 PV). 5명 모두 로그인 유저이고 제외 목록에 없다. → 평균 지표로 07-27 을 읽으면 안 된다.

**3. 상담 퍼널은 63% 완료 / 80% 열람에서 안정.**
`/tarot/reading` UV 102 → `/tarot/result` UV 68 (**−33%**) 의 라우트 낙차가 미열람 동선 문제와 같은 방향을 가리킨다. 단 분모가 다르므로(UV vs readings) 두 수치를 같은 것으로 읽지 말 것. 미열람 픽스는 d14(8/9) 슬롯 그대로 두면 된다 — **절대수가 안 늘고 있다.**

**4. 봇 0.1% = 계측 건강.** 단 UA 기반 판정이라 하한값이다.

**5. 유입 지표(`landing_variant`·`utm_content`)는 이 정답지에 없다.** `admin_traffic_entry` 는 first-touch 귀속이라 SQL 이 길고, 대조는 Task 4 Step 2 에서 함수 본문 그대로 돌려 맞춘다.
