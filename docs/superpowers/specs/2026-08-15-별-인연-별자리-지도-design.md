# 별 인연 별자리 지도 — 무료 바이럴 콘텐츠 설계 (2026-08-15)

로그인 없이 생일만 넣으면 친구들과의 사주 관계가 **별자리**로 그려지고, 친구를 부를수록 별자리가 자라는 무료 바이럴 콘텐츠. 진행 큐 #3(SEO 무료 유입창구) + #4(무료 재미 포인트)를 하나로 통합한 것. 도령 '귀인지도'가 출발 레퍼런스지만 아류를 피하는 게 설계의 핵심 축.

## 0. 배경

- **근본 과제 = 단위 경제**: 재방문 실유저 ~0, CAC 회수 13~42% ([[pnl-findings-2026-07-25]]·[[cost-unit-economics-2026-08-10]]). 유입을 사는 구조가 안 돌아온다.
- **로그인 없는 미끼 부재**: 별콩톡 전 상품이 카카오 로그인 뒤 → 비브랜드 검색·바이럴 유입이 구조적으로 0 ([[growth-benchmarks-2026-07]]).
- **AI Overview가 정의형 SEO를 반감** → "로그인 없는 인터랙티브 도구" 엔드포인트가 필수라는 벤치마크 결론. 이 콘텐츠가 그 공백을 정면으로 겨냥.

## 1. 목표 & 비스코프

**목표 (우선순위):**
1. **소셜 바이럴** (코어) — 카톡으로 친구끼리 퍼지는 초대 루프
2. **로그인 유입** — 게스트 → 호스트 전환으로 가입 (사업 목표)
3. **SEO** (보너스) — 공개 페이지 색인. 바이럴을 희생하면서까지 색인 욕심 안 냄

**성공 지표(예비):** 공유 링크 발신 수 · 게스트 참여율 · 게스트→호스트(로그인) 전환율 · 별자리당 평균 참여 인원. (측정 설계는 plan에서.)

**비스코프 (의도적 제외):**
- **유료 상품 자체 재설계** — 궁합(진행 큐 #2 방향)·기질(#3 방향)은 별개 트랙. 여긴 그리로 잇는 다리만.
- **LLM 해석** — 전부 룰. Claude/OpenAI 미경유 (원가 0·즉시·결정적).
- **정확도** — 재미 콘텐츠. "믿을 만한 운세"가 아니라 "친구랑 하는 놀이".
- **도감/영구 수집** — 아래 §4에서 제외 확정(복잡도·가벼움).

## 2. 컨셉 — 줌 되는 별자리 지도

**정체성:** 사주 오행으로 친구 관계를 별자리로 그리는 놀이.

**도령 대비 차별화 (아류 회피의 핵심):**

| 축 | 도령 귀인지도 | 우리 |
|---|---|---|
| 렌즈 | 귀인(유불리 랭킹) | 관계의 결 + "남이 보는 나" (무랭킹·무점수) |
| 구조 | 나 중심 1:1 나열 | **진짜 관계망** — 친구끼리도 엮임 (경쟁자 아무도 못한 빈 자리) |
| 뷰 | 평면 한 장 | **줌** (넓게 별자리 / 좁게 1:1) |
| 형상 | 계절·보석 라벨 | 별콩이 우주 세계관 (상징 별자리) |

**두 개의 줌:**
- **넓게 (별자리 뷰):** 나도 무리의 평등한 한 별. 친구끼리도 관계선. 상징 별자리 실루엣. 자라는 빈 자리. → 단톡방에 통째 공유.
- **좁게 (1:1 뷰):** 별 탭 → 그 사람 중심 확대. 궁합 상세 + 별콩이 한 줄 + "남이 보는 나". → 개인 카드 공유.

### 위치 / IA

**독립 라우트가 아니라 사주 운세 탭(`/fortune`)의 "무료" 카테고리 안 서브.** `app/fortune/page.tsx`(탭 메인)는 이미 로그인 가드가 없어 비로그인 공개이므로 탭 정책은 그대로 두고, 별자리 서브만 무가드로 얹는다.

```
/fortune                      사주 운세 탭 · 비로그인 공개 · "무료" 칩에 별자리 진입
/fortune/<별자리>             별자리 만들기 / 내 별자리        (무가드)
/fortune/<별자리>/[shareId]   카톡 공유 랜딩 · 이 별자리 한 장 (무가드 · noindex)
/fortune/[type]  (기존)       유료 사주 리포트 생성            (로그인 가드 유지)
```

**로그인 경계:** 별자리 체험·친구 참여·공유 랜딩 = 무가드(바이럴 생명줄) / 내 별자리 저장·알림·유료 전환 = 로그인 유도(§6). 유료 사주 생성의 기존 로그인 가드(`app/fortune/[type]/page.tsx:62`)는 유지.

**발견성:** 하단탭 사주 운세 → 무료 칩이 상시 진입점(로그인 벽이 상품 구성을 가리던 문제 완화). 게스트는 `shareId`로 직접 랜딩하되 하단탭이 붙어 다른 상품을 자연 발견. 홈 캐러셀 카드는 보조.

⚠️ `daily`(오늘의 운세)는 무료인데도 로그인 가드가 걸려 있음(`app/fortune/daily/page.tsx:43`) — 별자리는 게스트 비로그인이 전제라 다르게(무가드) 가고, daily 정책 재검토는 별도.

## 3. 사주 지표 레이어 (룰 100% · LLM 0 · 일지 기준)

`calcSaju`(`lib/saju/calc.ts`)가 LLM 없이 일간·오행분포·4기둥 글자를 결정적으로 뽑는다. 관계 지표도 전부 룩업 테이블로 계산.

**채택 (전부 시주 불필요·낙인 없음):**

| 지표 | 계산 | 지도 역할 |
|---|---|---|
| 오행 상생상극 | 두 일간 오행 5분류 (생아/아생/극아/아극/비화) | 선의 기본 결 |
| 십신 | 일간↔일간 음양+오행 10종, **방향성** | 상세 + 양방향 화살표 |
| 천간합 | 일간 5쌍 (갑기·을경·병신·정임·무계) | 케미 스파크 반짝임 |
| 삼합 | 일지 3그룹 결속 | **3명 삼각 클러스터 = 별자리 심장** |
| 육합 | 일지 6쌍 | 굵은 결속선 |

**폐기 (낙인·복잡·중복):** 충·형·파·해(충돌·파괴) · 원진살·귀문관살(원망·집착) · 공망(허무·60갑자 복잡) · 납음(오행과 중복). → 별콩이 "불안 자극·단정 금지" 원칙과 정합.

**설계 규칙 2 (리서치 근거):**
1. **모든 지지 지표는 일지(day branch)로만** → 시간 몰라도(hourKnown=false) 100% 정확 = 진입 마찰 최소. (§8 가벼움과 직결)
2. 방향성 지표(십신)는 A→B·B→A 둘 다 노출 → 관계선 양방향 화살표.

🔴 **필수: 십신 한자명 재포장.** 편관·상관·겁재 등 민간 낙인("편관=칠살" 등)이 있어 그대로 노출 금지 → 별콩 톤 라벨 테이블("정관 → 든든한 지원군" 식). 룰이라 라벨만 새로 씀.

**삼합의 발견:** 다른 지표는 2인 엣지인데 삼합만 3인 클러스터 → 별자리 컨셉과 구조적으로 일치 + **친구를 더 모을수록 삼합 확률↑ = 바이럴이 사주 룰 자체에서 저절로 나옴.**

## 4. 상징 별자리 시스템

- **형상 라이브러리**: 동물·사물 별자리 형상을 미리 디자인(별 배치 템플릿 + 실루엣). **(인원 × 지배 오행)**으로 룰 자동 선택 → 조합 폭발 = 다채로움. 같은 7명도 물=고양이·불=용.
- **실루엣 오버레이**: 별점만으론 형상이 안 보이니 반투명 실루엣을 깔아 또렷하게.
- **노드**: ★ 별 모양(별자리 느낌). ⚠️ 원 vs 별은 구현 때 A/B로 확정.
- **성장형 빈 자리**: 형상을 인원 구간 고정이 아니라 "다음 형상을 향해 채워지는 진행형". 빈 자리 = 초대 동기 + 삼합 확률↑ + 수집욕. 완성 순간 = 가벼운 축하 + "한 명 더 오면 ○○로" 예고. **도감(영구 수집)은 제외**(복잡도·가벼움). 격하감은 긍정 프레이밍으로 방지(저장 없이).
- **관계 분류**: 친구/연인/지인/상사 태그가 **궁합 해석까지 바꿈**(문구 테이블 = 5관계 × 4분류). 연인 분류 = §7 유료 궁합 다리.

## 5. 바이럴 루프

- **진입**: 내 생일 하나 → 즉시 내 별 + 빈 별자리 (로그인 0).
- **초대**: **"○○의 별자리를 채워줘" 카톡 공유 링크** (`lib/kakao-share.ts` 재사용). 썸네일에 빈 자리 노출 = 채우고 싶게. 2~3명 콕 집기 권장(K-factor↑).
- **참여**: 친구가 링크 열고 생일만 → 그 별이 내 별자리에 추가 + 궁합 뜸 + **친구도 자기 별자리 씨앗을 받음**(양방향 이득).
- **게이팅**: 전체 관계 다 보려면 친구 N명 채우기 (무료 게이팅 = 초대 유도).

바이럴 근거(§9): 완성이 아니라 빈 자리가 초대를 만든다 · 콕 집기가 전환율↑ · 초대받은 쪽도 득 봐야 루프 유지.

## 6. 비로그인 / 로그인 (사업 목표 = 로그인 유저↑)

**원칙: 참여는 비로그인, 소유는 로그인.** 로그인 강요는 바이럴을 죽이니 진입은 무조건 비로그인, 로그인은 인센티브로 당긴다.

- **게스트(초대받은 친구)**: 비로그인, 생일만. 마찰 0 = 바이럴 생명줄.
- ★ **게스트 → 호스트 전환이 로그인 깔때기**: 참여 후 "너의 별 유형·호스트와 궁합"을 살짝 보여주고 → "네 별자리도 만들어봐" → 내 별자리 만들기 = 로그인 → 걔가 또 자기 친구를 부르는 호스트가 됨.
- **로그인 인센티브(강요 X)**: 내 별자리 저장(안 하면 세션 끝나면 사라짐) · 친구가 채우면 알림 · 웰컴 20별(바로 유료에 씀) · 유료 연결.
- 결과: **바이럴 루프 = 로그인 유입 깔때기.** "로그인 없이 바이럴"과 "로그인 유저 확보"가 충돌 없이 같은 흐름에 실린다.

## 7. 무료 → 유료 다리

- 연인으로 등록된 관계 → "이 인연 진짜 궁합 깊이 보기" → **유료 궁합** (진행 큐 #2)
- 내 별(개인) → "내 기질 자세히" → **유료 기질 리포트** (진행 큐 #3 / [[product-backlog]] 1)
- 별자리 지도 = 무료 입구, 특정 노드/관계에서 유료로 자연 유도.

## 8. 제약

- **가벼움 (컨셉이 보장 안 함 — 의도적으로 지킬 것):** 첫 화면 마찰 0 · 정보 덜어내기(도령이 5개 보여줄 때 우린 1~2개) · 점수·정확도 강조 안 함 · 짧고 장난스러운 문구(별콩이 톤). 리서치가 확인한 "친구 여럿 모으기+관계망"이 MBTI 테스트보다 무거워질 위험을 상수로 경계.
- **프라이버시 (옵트인 3단, 보수적 기본):** ⑴이름 공개(별만 vs 이름) ⑵내 궁합을 다른 게스트에게 보일지(호스트만 vs 전체) ⑶생일 숫자는 계산에만(항상 비공개). 게스트끼리 관계가 보이는 게 §2 진짜 관계망의 힘이자 리스크이므로 명시적 동의 설계 필수.

## 9. 리서치 근거 (2026-08-15, 5개 병렬 리서치 스트림)

- **한국 바이럴 운세**: 포스텔러(궁합=2인 강제 구조가 초대 유발) · 헬로우봇(가벼운 사이드 콘텐츠 유입구, 부캐테스트 수시간 20만 공유) · 청월당(결과 장면화).
- **글로벌 astrology**: Co-Star·SBTI("캡처하고 싶은 카피"가 엔진, 공유버튼 아님) · Nebula("결제 or 초대" 잠금해제) · The Pattern(미가입자도 생일만) · **진짜 다자 관계망 시각화 = 아무도 못한 빈 자리**.
- **공유루프 테스트**: 모임티아이(호스트+친구 채우기 한국 실사례) · tbh(최소 인원 임계치가 초대) · **초고속 성장 = 초고속 소멸(노벨티 감쇠)** 경고.
- **바이럴 메커니즘**: 빈 자리가 초대 · 콕 집기(K-factor = 초대수 × 전환율) · 양방향 이득 · 카톡 3무대(오픈채팅=신규유입 / 단톡방=지인 재확산 / 프사=상시 갤러리).
- **사주 지표**: §3 채택/폐기 근거. 삼합=별자리 정합, 일지 스코프=시간 무관, 십신 재포장 필수, 충·형·파·해·신살은 낙인으로 배제.
