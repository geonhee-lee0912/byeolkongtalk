# 별마루 7일 스트립 — 시각 언어 재설계 (2026-09-24)

허브(`/byeolmaru`) 달력 판 안 **7일 스트립**(`DayStrip`)만 다룬다. 월간 격자는 다음 판.

## 1. 왜

375×812 구독자 계정으로 실물 감사해 나온 결함 중, 이번 범위(C 묶음)는 넷이다.

| # | 결함 | 근거 |
|---|---|---|
| ④ | **오늘이 시각적 1순위가 아니다** | 톤 색면이 위계를 이긴다. 9/24(무난·회색)보다 9/23(잘 맞는 날·금색)이 강하게 보였다 |
| ⑤ | **칸 2/3이 같은 색** | `scripts/byeolmaru-label-freq.ts` 5,400칸: normal **64%** · caution 19% · good 17%. 마크 없음 65% |
| ⑥ | **칸이 좁다** | 실측 `getBoundingClientRect`: 스트립 일반 칸 **35×101px**, 오늘 74×101px |
| ⑦ | **마크의 뜻이 어디에도 없다** | 하단 범례가 셀 칩과 같은 모양·같은 글자라 반복일 뿐. 게다가 격자는 접힘이 기본이라 스트립만 보는 사람은 범례 자체를 못 본다 |

⑥ 보충: WCAG 2.5.8(AA) 최소 타깃은 24×24px이라 **규격 위반은 아니다.** 44px는 Apple HIG·Material 권장치이고, 실제 문제는 옆 칸 오타.

## 2. 이 설계가 뒤집지 않는 것 (재검증 완료)

감사 중 내가 결함이라 부른 것 중 **둘은 오판이었다.** 되살리지 말 것.

- **스트립 범위(지난 3 + 오늘 + 앞 3)는 자의적이지 않다.** [`strip.ts`](../../../lib/byeolmaru/strip.ts) `STRIP_LENGTH = STRIP_PAST_DAYS + 1 + FUTURE_REPORT_DAYS`. 미래 칸 수는 **리포트 생성 가능 일수(3)와 반드시 같아야** 한다 — 어긋나면 "흐려서 눌러본 칸"이 `out_of_range`로 거절된다. 범위를 늘리려면 `FUTURE_REPORT_DAYS`를 올려야 하고 그건 LLM 원가 결정이다.
- **과거 칸이 "그날은 리포트를 안 받았어"로 가는 건 정책이다.** [`report-date.ts`](../../../lib/byeolmaru/report-date.ts) 헤더: *"과거는 있던 것만 — 소급 생성 금지, 그때 받은 글이 아니면 기록이 아니다."*
- **"이번 주 월~일 고정"은 이미 기각된 안이다.** 같은 파일 주석: *"요일 기준이면 월요일 6칸·토요일 1칸으로 흐린 칸이 출렁여 기각."*

## 3. 역할 정의

> **메인 = "이번 주 언제가 좋지?" (7칸 비교)** / **서브 = "오늘 뭐지?"**

비교가 주인공이면 7칸이 **같은 문법**이어야 한다. 그래서 오늘의 *내용*은 칸 밖으로 나가고, 칸 안에서 오늘은 *위치 표시*만 한다.

## 4. 비교 축 = 종합 점수 (`DayCell.score`)

톤 3단은 해상도가 낮다(7칸 중 4~5칸이 동일색). 점수는 그 원재료라 정보 손실이 없다.

실측(8명 × 30일 = 240칸):
```
전체 · 최소 12 · p10 36 · 중앙 56 · p90 73 · 최대 92 · 서로 다른 값 38종
7일 창 192개 · 창 내 점수 폭(max−min): 최소 12 · p25 32 · 중앙 35 · 최대 76
```
**어느 7일을 잘라도 최소 12점, 보통 35점이 벌어진다** → 막대 비교가 실제로 작동한다. ⑤가 구조적으로 사라진다.

- **숫자는 화면에 절대 쓰지 않는다.** 높이로만 말한다. 단정적 예언 금지와 부딪히는 건 "72점"이라는 표기지 크기 비교가 아니다. `aria-label`에는 지금처럼 등급 라벨(`잘 맞는 날`)을 싣는다.
- **스케일은 고정 0~100.** 주간 상대 스케일(창 내 min~max를 늘림)은 나쁜 주와 좋은 주를 똑같아 보이게 해서 기각.
- 높이 매핑 `h = 4 + score/100 × 24` (4~28px). 바닥 4px은 최저점(12)도 막대가 보이게 하는 값.
- **색은 단색 + good만 금색.** `score >= 70`(= `dayGrade`의 good 임계)이면 `gold`, 아니면 `lilac`. caution은 막대가 짧은 것으로 이미 말해진다. 격자·상세의 "잘 맞는 날" 라벨과 어휘가 이어진다.

## 5. 레이아웃

```
오늘 · 내 결대로 가는 날                      3일 연속
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│  ▃  │  ▄  │  █  │  ▃  │  ▂  │  █  │  ▄  │   ① 점수 막대 (good = 금색)
│  월  │  화  │  수  │  목  │  금  │  토  │  일  │   ② 요일
│ 21  │ 22  │ 23  │ 24  │ 25  │ 26  │ 27  │   ③ 날짜 — 24는 #5A3E8C pill + 흰 글자
│     │     │ 척척 │     │     │ 설렘 │     │   ④ 마크 칩 (없으면 빈 자리)
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

칸 안 순서는 위→아래 **막대 · 요일 · 날짜 · 마크 칩**. 요일이 날짜 위에 오는 건 지금과 같다(순서를 바꾸지 않는다). 오늘 pill은 **요일+날짜 두 줄을 함께** 감싼다.

| | 지금 | 안 |
|---|---|---|
| 트랙 | 8 (오늘 span 2) | **7 균등** |
| 칸 폭 | 35px | **43.9px** |
| 칸 높이 | 101px | ~78px |
| 비교 신호 | 톤 색면 3단 | **점수 막대** |
| 오늘 | 2배 폭 + 톤 색면 + 2px 링 + `scale(1.07)` | **`#5A3E8C` pill + 흰 글자** |
| 오늘의 하루 이름 | 칸 안 74px에서 2줄로 깨짐 | 판 폭 343px 쓰는 **리드 줄** |
| 동물 일러스트 20px | 전 칸 | **제거** (상세 히어로에 크게 살아 있다) |

- **43.9px 산식**: main `p-4`(32) → 343 / 판 `p-4`→**`p-3`**(24) → 319 / gap `4px`→**`2px`** × 6 = 12 → `(319 − 12) / 7 = 43.86`
- 판 패딩 변경은 월간 격자에도 걸린다 — 격자 칸이 41 → 42.1px로 **같이 개선된다**(gap은 표면 B에서 함께 본다)
- 오늘 pill `#5A3E8C` 위 흰 글자 = **8.4:1** (AA 통과)
- `ring + scale(1.07)` 제거 — 어두운 면이 이미 위계를 말하고, scale은 grid 틈으로 삐져나온다
- 리드 줄 = 좌 `오늘 · {DAY_NAME}` / 우 `N일 연속`(streak > 1일 때만). 기존 `AttendanceStrip` 한 줄을 이 줄이 흡수한다

### ④가 정의상 풀리는 이유
판 안에서 **어두운 면은 오늘 하나뿐**이다. 톤이 금색이든 회색이든 명도가 이긴다. 지금처럼 "톤이 좋은 날이 오늘을 이기는" 조합이 성립하지 않는다.

## 6. 마크 어휘 재설계

### 문제의 진짜 정체
허브 달력은 **1인칭 전용**인데 마크가 잡아내는 건 **나 ↔ 그날**이다. 그런데 `끌림`·`결속`은 **상대를 요구하는 말**이라 목적어가 빈다 — *"오늘 끌림 → 누구한테?"*. 우리 탭·지도에선 대상이 분명해 문제가 안 보였다.

→ 선정 기준은 "네 말이 한 결로 묶이는가"가 아니라 **"상대 없이 성립하는가"**다.

### 계산 구조
```
마음 축 ── ✧ 천간합(그날 천간 ↔ 내 일간)        짝 없음
현실 축 ── ◇ 육합  ↔  △ 충 (그날 지지 ↔ 내 일지)  같은 축의 + / −
보완 축 ── ＋ 그날 천간 오행이 내 사주에 없음      관계가 아님
```

### 교체
| 글리프 | 지금 | **새 말** | 근거 |
|---|---|---|---|
| ✧ | 끌림 | **설렘** | 상대 없이 성립("설레는 날"). 실측 빈도 10%라 남발 안 됨 |
| ◇ | 결속 | **척척** | 한자 명사 → 상태 의태어. "오늘은 척척 되는 날" |
| △ | 삐걱 | **삐걱** | 유지. 이미 대상 불필요하고 자명 |
| ＋ | 채움 | **채움** | 유지. 원래 상대가 없던 항목 |

`척척 ↔ 삐걱`이 같은 축의 +/− 의태어 쌍이라 **범례 없이 대비가 읽힌다.** 계산 구조가 말에 그대로 비친다.

**→ ⑦이 어휘로 해소되므로 격자 하단 범례 줄은 제거한다.**

## 7. 검증

1. `npm run build` + `npx tsc --noEmit` + 유닛(계약 테스트 3개 포함)
2. 375×812 실물 — 구독자(`11111111-1111-4111-8111-111111111111`)로 허브
   - 오늘 칸이 톤과 무관하게 제일 강한가 (오늘이 good/normal/caution 세 경우 모두)
   - 7칸 막대가 눈으로 구분되는가
   - 칸 폭 `getBoundingClientRect` ≈ 44px
   - 리드 줄 1줄 유지(하루 이름 최장 `생각이 깊어지는 결` 8자)
3. 비구독 상태 — 미래 3칸 점선, 잠긴 칸 탭 → 구독 유도 그대로
4. 마크 없는 주(65%)에서 칩 자리 비어도 칸 높이 균일한가
5. 지도(`/byeoljari`) 필터 칩·선 색 회귀
