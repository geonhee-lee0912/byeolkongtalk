# 어드민 시뮬·슬롯 관측 한판 (design)

날짜: 2026-08-14 · 상태: 설계 확정 (사용자 승인 대기)

## 목적

방금 배포한 두 신규 메커니즘 —
- **시뮬 무료 런웨이·훅** (관계당 첫 3판 무료 → 이후 유료 15별, 유저당 주 1회 무료 훅)
- **1:N 슬롯** (첫 관계 무료 → 2번째+ 슬롯 50별)

— 이 실제로 **"무료 축적 → 유료 전환"으로 도는지** 볼 어드민 창이 0이다. 측정 규율(변경마다 메커니즘 지표를 스펙에 내장)의 실행부. **이번 판의 목표는 신규 지표 추가뿐** — 어드민 전면 고도화는 별건, 나중.

## 비목표 (YAGNI)

- 어드민 nav·레이아웃·proxy 변경 없음 (기존 2화면에만 얹는다)
- 시계열/일별 추세 없음 (누적 카운트만 — 창 없음 = KST 날짜식 불필요)
- 운영 조작(환불·수동 부여 등) 없음 — 순수 관측 + 개별 드릴다운
- 리텐션·코호트 분석 없음 (funding 분포가 케이던스 프록시로 충분)

## 데이터 소스 (정확한 출처)

| 개념 | 출처 |
|---|---|
| 시뮬 판 | `readings` where `consultation_type='relationship_sim'` (관계당 다수, `relationship_id` 귀속) |
| 판 자금원 | `readings.saju_data->>'funding'` ∈ {`runway`,`hook`,`paid`}. **NULL = 레거시 → `paid` 취급**(`coalesce(...,'paid')`, SimMeta 주석 정합) |
| 판 완주 | `readings.saju_data->>'phase' = 'debriefed'` |
| 시뮬 유료 결제 | `star_transactions.source='relationship_sim'` (15별, spend=음수) |
| 답변추천 구매 | `star_transactions.source='relationship_sim_suggest'` (5별) |
| 슬롯 구매 | `star_transactions.source='relationship_slot'` (50별) |
| 관계 수 | `relationships` (유저당, `user_id` 귀속) |
| 초상화 | 관계의 `partner_profile_id` → `user_profiles.personality` (자유 서술, 관찰 append 누적) |

상수(정본 = `lib/relationship/types.ts`): `SIM_COST=15` · `SIM_SUGGEST_COST=5` · `SIM_FREE_RUNWAY=3` · `SIM_HOOK_INTERVAL_DAYS=7` · `SLOT_COST=50` · `slotAllowance = 1 + 구매슬롯`.

**어드민 제외**: 지인 6명(`adminExclusionArray()`)은 기존 `admin_relationship_*` RPC 와 동일하게 `p_exclude` 로 제외. `user_id` 는 세 소스 모두 non-null(FK)이라 NULL 3값 함정 없음.

## A. `/admin/relationship` 확장 — 집계 지표

기존 페이지(등록/스레드·패스·스킬·대화흐름) **아래에** 두 섹션 추가. 기존 4섹션은 무편집.

### ① 시뮬(연애 시뮬) 섹션 — 8지표

집계 카드/한 줄:
1. **총 판 수** — 전체 sim readings
2. **funding 분포** — 무료런웨이 N · 주간훅 N · 유료 N (한 줄 또는 3카드)
3. **유료 전환율** = paid / 전체 (%) — *핵심: 무료 축적이 결제로 넘어가나*
4. **시뮬 매출(별)** = paid판수 × 15 + 답변추천 구매수 × 5 (환불 무시 = 총액, 환불은 희소)
5. **플레이 유저 수**(distinct `user_id`) · **플레이 관계 수**(distinct `relationship_id`)
6. **디브리핑 도달률** = `phase='debriefed'` / 전체 (%) — 판을 끝까지 = payoff 진입
7. **런웨이 소진 관계 수** = funding='runway' 판이 3개인 관계 수(무료벽 도달) · **주간훅 사용 판 수** = funding='hook' 판 수(재방문 케이던스 작동?)
8. **초상화 축적** — 시뮬 플레이 관계 중 성격 서술(`personality`) 보유 비율 + 평균 글자수 (payoff 심장)

### ② 슬롯(1:N) 섹션 — 4지표

1. **슬롯 구매 수** (source='relationship_slot' 건수)
2. **슬롯 매출(별)** = 구매수 × 50
3. **다중 관계 유저 수** — 2명+ 등록 유저 (1:N 실현)
4. **관계 수 분포** — 1명 유저 N · 2명 N · 3명+ N (히스토그램 한 줄)

### 실패 표면화

기존 페이지 규칙 그대로 — 새 RPC 실패 시 각 섹션에 `components/admin/LoadFailed`, 숫자는 `—`(0 아님). 조작된 증감 억제.

## B. `relationship-readings/[id]` 상세 확장 — 개별 드릴다운

기존 상세(스레드 타임라인) **아래에** 두 블록 추가. 페이지 직접 쿼리(관계당 판수·프로필 1행 = 행수 유계, 기존 상세와 동일 패턴 — RPC 불필요).

1. **초상화 블록** — 상대 프로필 `personality` 전문 노출(축적된 관찰 육안 확인). 비어있으면 "아직 없음".
2. **시뮬 판 목록** — 이 관계의 `relationship_sim` readings 를 시간순:
   - 각 행: funding 배지(무료런웨이/주간훅/유료) · 상황(`situationId`) · 완주여부(debriefed) · 통찰(`insight`) · 보낼말(`sendMessage`) 요약
   - **"리딩 보기"** → 기존 범용 `/admin/readings/[id]` (트랜스크립트 재사용 — 사용자 결정 #1). 시뮬 판은 messages 에 인형 대화·디브리핑·노트가 저장되므로 범용 뷰어로 열림.

## RPC 설계

**새 마이그레이션 1개**: `supabase/migrations/<ts>_admin_sim_slots_aggregates.sql`
- `admin_sim_summary(p_exclude uuid[])` → 시뮬 8지표 (한 행 또는 (kind,key,cnt) 분포 + 스칼라)
- `admin_slots_summary(p_exclude uuid[])` → 슬롯 4지표 (스칼라 + 관계수 분포)
- 둘 다 `SECURITY DEFINER` + `search_path` 고정
- 🔴 **`REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated` 셋 다** + `GRANT ... TO service_role` (AGENTS.md 규칙)
- BIGINT → 앱에서 `Number()` 래핑 (PostgREST 문자열화)

### AGENTS.md SQL 함정 체크
- ✅ KST 날짜식 불필요 (창 없는 누적)
- ✅ NULL 3값 논리 — `user_id` non-null이라 `<> ALL(p_exclude)` 안전. 단 `funding`/`phase` 는 NULL 가능 → `coalesce`/명시 비교
- ✅ `_` LIKE 와일드카드 함정 — source 는 정확 문자열 `=` 비교, LIKE 안 씀
- 🔴 **적용 전 두 함수 본문을 prod(read-only)에서 각각 실행 검증** — 하나가 없는 컬럼 참조하면 파일 전체 실패(2026-07-31 사고 재발 방지)

## 검증

- 유닛: 새 헬퍼가 생기면 유닛(예: funding 배지 라벨 맵) — 대부분 SQL/렌더라 유닛 표면 작음
- SQL↔실측 대조: `scripts/run-prod-query.mjs` 로 dev DB 에 RPC 본문 인라인 실행 → 화면 수치와 행 단위 대조(별 소모 이식 때 쓴 방식)
- E2E: dev 마이그레이션 적용 후 `/admin/relationship` 새 섹션 실렌더 + 시뮬 판 있는 관계 상세에서 초상화·판 목록 확인 (어드민 세션 주입, [[admin-local-verify-trick]])
- `tsc` 클린 · 기존 유닛 회귀 0

## 배포

dev 커밋 → **prod(main)는 로드맵 ④에서 dev 누적분 한 판**(단독 배포 아님).
