# 프롬프트 캐시 감사 — findings + 픽스 (2026-07-26)

**계기**: Anthropic 빌링 메일(2026-07-19) "prompt cache hit rate is low, 시스템 프롬프트 캐싱하면 direct API spend 최대 21% 절감". 대상은 별콩톡 앱 서버사이드 호출(Claude Code 제외).
**결론**: **`ttl: "1h"` 한 줄이 유일하게 할 값어치가 있는 변경.** 나머지 후보는 전부 기각. 프롬프트 바이트 무변경 = 모델 출력 무변경 → 측정 창 중간 배포 안전.

---

## 1. 실측 (추정 아님)

두 가지를 실제로 재봤다. 감사 초안의 추정치는 **둘 다 틀렸다**.

### (a) 캐시 히트율 — prod 호출 간격에서 시뮬레이션

staticPart 는 페르소나 파일뿐이라 **유저 무관**이고, 문서상 **읽기가 TTL 을 갱신**(sliding)한다. 따라서 "직전 동일-프리픽스 호출과의 간격 ≤ TTL" 이면 히트. 어드민 제외 6명 적용, `messages.created_at` 기준(assistant 행 1개 = API 호출 1회 — 버블 분할은 클라 렌더링뿐).

| 프리픽스 | 18일 호출 | 간격 중앙값 | 5m 히트 | 1h 히트 |
|---|---:|---:|---:|---:|
| tarot | 2,407 | 1.1분 | 84.1% | **95.6%** |
| saju | 253 | 1.0분 | 80.6% | 85.0% |
| relationship | 10 | 1.2분 | 70.0% | 80.0% |
| fortune | 89 | 171분 | 15.7% | 33.7% |

최근 창에서도 안정적(고민톡 합산): 3일 82.9%/96.3% · 7일 84.4%/96.5% · 18일 84.7%/95.8%, 시간당 ~7콜.

⚠️ 감사 초안은 "총 콜수 ÷ 총 시간"으로 **간격을 40분으로 추정**했다. 실제 중앙값은 1.1분 — 호출이 세션 단위로 몰려서(버스트) 평균이 무의미했다. 이 오류가 초안의 우선순위를 통째로 뒤집었다.

### (b) 정적 블록 실토큰 — API `usage` 로 직접 측정

동일 프리픽스 2회 호출로 실증(`max_tokens: 1`):

```
staticPart: 17,713자
1회차  uncached=17  write=17,426  read=0       1h_write=17,426
2회차  uncached=17  write=0       read=17,426  1h_write=0
```

- **1h TTL 이 실제로 수락되고 캐시가 잡힌다** (베타 헤더 불필요, SDK 0.98.0 이 `ttl?: '5m'|'1h'` 타입 노출).
- tarot staticPart = **17,426 토큰**. 한글은 Sonnet 5 토크나이저에서 **≈1.0자/토큰**.
- ⚠️ 감사 초안은 **바이트를 글자수로 착각**해 ÷1.6 했고(37,225바이트→23,270), 레포 관행인 `CHARS_PER_TOKEN=1.6`(`lib/analytics/apiCost.ts:26`)도 한글엔 **~60% 과소추정**이다. AGENTS.md 의 "페르소나 12-15K 토큰 추정"도 실제 17.4K.
  - **단 P&L 배분은 무손상** — `scoreReading` 은 입력·출력 글자수에 같은 상수를 나누고 콘솔 총액을 비율로 배분하므로 공통 인수가 약분된다. 절대 토큰 추정만 틀렸지 배분 비율은 맞다. 그래서 상수는 **안 고쳤다**(과거 분석과의 비교 가능성 유지).

## 2. 적용한 변경 (1건)

`lib/claude.ts` `streamChat` 의 정적 블록 마킹에 `ttl: "1h"` 추가. 이게 전부다.

**왜 이득인가** (Anthropic 배수: read 0.1× · 5m write 1.25× · 1h write 2.0×):

| | 배수 | tarot 기준 |
|---|---:|---|
| 캐시 없음 | 1.00× | — |
| 5m TTL (히트 84.1%) | **0.283×** | 현행 |
| 1h TTL (히트 95.6%) | **0.184×** | 적용 후 |

미스가 write 라서 **남은 16%가 비싸다**. 1h 는 write 단가가 오르지만(1.25→2.0×) 미스 자체를 1/4 로 줄여 정적 블록 입력비가 **약 35% 싸진다**.

실토큰 기준 절감액 (18일, 프리픽스별 자체 히트율 적용):
- tarot: 17,426 tok × 2,407콜 × Δ0.099 = **+4.17M 토큰 절약**
- saju: 1h 히트가 85.0% 라 **−0.17M 토큰 손해**(콜이 드물어 간격이 벌어짐)
- relationship: −0.005M
- **순 ≈ 4.0M 토큰 / 18일** → 인트로 단가 $2/MTok 기준 **≈ ₩18,600/월**, 인트로 종료(2026-08-31) 후 $3 기준 **≈ ₩28,000/월**

⚠️ **손익분기는 1h 히트율 ~90%**(5m 히트 84% 기준). 지금 95.6% 라 여유는 5.6pt 뿐 — **광고 볼륨을 크게 줄여 호출 간격이 벌어지면 역전된다.** 코드 주석에 재측정 조건을 남겼다.
