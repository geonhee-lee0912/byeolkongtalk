# 하단탭 IA 통합 설계 (1~5탭 큰 그림)

**작성** 2026-08-02 · **상태** 큰 그림 확정 · 각 탭 구체화 대기
**방식** 상품 먼저 설계 → 통합 IA. E1 `2026-07-27-e1-ia-content-hierarchy-design.md`의 "IA 먼저"를 뒤집었다. **E1의 §5 인터랙션 모드 배치 규칙은 유효**하고, 히어로·마이 구조는 이 문서가 갱신한다.
**선행** `specs/2026-08-01-연애-시뮬레이션-형태-design.md` · `specs/2026-08-01-리텐션-채널-전략-design.md`
**맥락** T1 게이트(로드맵 `plans/2026-08-01-roadmap-t1-t2-t3.md`). 이 문서 = **각 탭 구체화의 기준선**. 페이지별 상세(UX·카피·구현)는 각 탭 구체화 세션에서.

## 탭 이름 5개 (URL 변경 0 — 라벨만)

| # | 라벨 | 경로 | 정체 |
|---|---|---|---|
| 1 | **타로톡** | `/` | 타로 실시간 대화 + 홈 겸용 |
| 2 | **사주 운세** | `/fortune` | 사주 리포트 카탈로그 |
| 3 | **우리 사이** | `/relationship` | 특정 상대("그 사람") 파일 |
| 4 | **별콩 상점** | `/shop` | 별 충전 |
| 5 | **마이** | `/mypage` | 리텐션 허브 + 내 것들 |

- **3탭 "그 사람" → "우리 사이"**: 대명사구라 탭 라벨로 어색(나머지 탭은 기능/장소 명사). 스킬 묶음명 "우리 사이"와는 **포함관계로 통일**(탭 = 큰 우리 사이 / 그 안 도구 = 스킬).
- 1·2탭은 "양식"(타로/사주), 3탭은 "대상"(그 사람)으로 축이 다르다 — 의도된 비대칭.

## 상단 문법 통일

두 진입 탭(1·2)은 **"얇은 별콩이 간판"**을 공통으로 둔다. 큰 히어로가 상품을 밀어내던 문제(상단 ~600px, 첫 태그가 fold 밖 · 375 기기 0장)를 해소. 1탭은 간판 자리에 캐러셀, 2탭은 카테고리 칩을 얹는다.

## 1탭 — 타로톡 (홈 겸용)

- **히어로 = 캐러셀** (이미지 영역 유지, **내부 광고 지면**)
  - **첫 카드만 서버가 상태별 결정**: 신규(이력 0)=사용법/브랜드 · 기존=신상품(시뮬)·첫충전
  - `BANNER_MAX` **열어둠**(3 고정 아님) — 도트+자동회전이라 뒤 카드는 노출 급감, **첫 카드 + 카드별 `?b=` 계측이 실질 지렛대**. 운영하며 조정
  - 카드 클릭 → 상품 설명/랜딩. **미래 유료 광고 슬롯 확장 여지**(외부 광고 카드를 같은 슬롯에)
  - 별콩이 브랜드 = 캐러셀 카드가 담당 → **별도 대문 이미지 불필요**
- 캐러셀 아래: 얇은 인사 + 감정 태그 그리드(현행 유지, fold 안으로 올림)
- **"이렇게 사용해요" 독립 카드 제거** → 사용법(온보딩)은 **캐러셀 슬라이드 + 설명 페이지**로, 상품 이해는 태그 카드가 담당(역할 분리)

## 2탭 — 사주 운세

- **큰 히어로 제거** → 얇은 간판(작은 별콩이 + "생일만 알려줘, 한 장으로 정리해줄게") + **카테고리 칩(연애·관계 / 나 / 시기)**
- **캐러셀 광고는 홈(1탭) 전용** — 2탭에 중복하면 리포트를 다시 밀어낸다. 여긴 이미 "운세 보러 온" 카탈로그
- 무료 훅(오늘의 운세)은 선택. "이렇게 사용해요" 제거
- 카테고리 배정(E1-B): 연애·관계=궁합/인간관계궁합 · 나=2026 사주 · 시기=이번달/좋은날/오늘의운세

## 3탭 — 우리 사이

- **미등록 = 콜드스타트**: 최소 입력(이름·관계)만. 사주·MBTI는 게이트가 아닌 **옵션 강화재**
- **등록 후 = 파일 허브**(백지 대화창 아님 = 무발화 14/15 직격) + **시뮬 앞세움**(무료 인트로라 백지보다 덜 막막)
- 결정 3건:
  1. **시뮬 ↔ 대화 스레드 별도 화면 분리** (E1 §4 — 화자 혼동/기억 오염. 시뮬 3화자 · 스레드 2화자, 배경·헤더·아바타 다르게)
  2. **스킬 4종 = 대화 스레드 전용** (시뮬은 순수 구성 — 8/01 시뮬 스펙과 일치)
  3. **패스·스레드 존폐 = 페이지 구체화 때 이월** (시뮬의 대화 진행형 과금과 겹쳐 재검토 필요)

## 5탭 — 마이 (리텐션 허브 + 내 것들)

리텐션은 **두 층**이다. 마이 진열만으론 재방문을 못 만든다 (E1: "탭은 재방문을 만들지 못한다 — 재방문을 만드는 건 알림이다").

- **밖 알림(부름)** — 캘린더 구독(좋은날 D-2)·편지 도착·메일. **진짜 재방문을 만드는 층.** → 리텐션 채널 트랙(E3/E4, 실측 대상)
- **안(마이 화면)** = 알림 보고 돌아온 유저의 착지:
  - **인라인(바로 보임)**: 프로필+별 · **"돌아왔을 때 볼 거리"**(안 본 결과 · 이어갈 대화 · 좋은날 · 새 편지) — 각 항목 클릭 → 목적지(결과 화면·3탭 스레드·좋은날 리포트·편지)
  - **게이트웨이(요약 + 별도 페이지)**: 내 고민톡 보관함(종목별) · 내 캘린더(좋은날·구독) · 편지함 · 내 데이터(내 사주·지인 — **명식 간결화**, 상세는 별도 화면) · 계정(문의·결제·탈퇴)
- 옛 홈 "오늘 블록"(리텐션 진열)이 **마이로 이관**됨 (08-01: 홈엔 리텐션 안 얹는다 — 홈 방문자는 신규 다수, 재방문자는 알림→마이 딥링크)

## 🔴 배포 전 필수 게이트

- **"내 고민톡" = 보관함(구매·이용 결과 내역, `/readings`) 세분화** — ⚠️ **1탭 타로톡 태그가 아니라 보관함**을 말함. 상품이 늘며 결과 종류가 다양해짐(타로·사주 리포트·시뮬·우리 사이 스레드) → 지금의 단순 목록으론 부족, **종목·상태별 분류**. 보관함이 마이 소속이라 **5탭 마이 재설계에 포함**(별도 과제 아님, 마이 작업의 한 축).

## 이관 목록 (별도 브레인스토밍)

- **설문** — 정성 이탈조사(정량으로 못 보는 "떠난 유저의 침묵" 메움, T3의 실질 방법). 진입 = 캐러셀 상시 + 팝업 유도. 미정: **누구에게**(세그먼트, 신규 첫방문 제외) · **무엇을**(이탈 이유·안 산 이유·니즈) · **보상**(무료별 경제성) · **저장·어드민 읽기 화면**
- **편지(E4)** — 마이에 **자리만**(진열 "새 편지" · 게이트 "편지함" · 밖 알림) 잡음. 상품 속(왕복 주기·가격·기억 구조)은 E4 브레인스토밍. "도착 예정일" 붙이면 캘린더 알림 인프라 공유(리텐션 채널 스펙의 "E3·E4 엮기")
- **각 탭 구체화** — **1탭부터**(홈 임팩트 + 힉스필드 캐러셀 아트 🔴 8/3 크레딧 만료). 페이지별 UX·카피·구현
