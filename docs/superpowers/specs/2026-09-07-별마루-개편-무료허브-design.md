# 별마루 개편 — 무료 콘텐츠 허브 (design)

작성 2026-09-07. 정본. 이전 정본(`2026-08-31-별마루-리텐션허브-design.md`)의 "리텐션 허브(캘린더 히어로)" 프레이밍을 **"무료 전부의 집(구경형 허브)"**으로 재편한다. 원가 원칙(무료=변동비 0)과 이미 지어진 별마루 ①~⑦은 그대로 계승한다.

---

## 1. 왜 (문제)

별마루는 "캘린더가 히어로"인 리텐션 화면으로 지어졌다(①~⑦ dev 완료). 그런데 제품 목표는 **무료를 유입/바이럴 엔진**으로 쓰는 것 — "무료로 볼 건 여기 다 있어"라고 링크 하나로 던지는 허브. 지금은:

- 무료 자원(MBTI·별자리)이 별마루 밖(`/fortune`)에 흩어져 노출 0.
- 무료 오늘 사주가 얄팍(등급+골격 1줄)해서 첫 화면이 자석이 못 됨.
- 우리 오늘이 **완전 구독 잠금**이라 초대(바이럴)가 시작도 못 함.

→ 별마루를 **무료 콘텐츠 허브**로 재편하고, 유료는 그 위에 **깊이(LLM)+넓이(30일)**로 얹는다.

## 2. 북극성 원칙

> **무료 = 룰·정적(변동비 0) / 유료 구독 = LLM 개인화 + 30일 breadth.** 모든 콘텐츠가 이 선으로 갈린다.

- 이 선을 흐리는 것은 넣지 않는다. (예: 앞선 논의의 "무료 오늘 사주 배치 캐시 LLM"은 **폐기** — LLM이 무료에 들어가 선을 넘고, nano가 싸져서 캐시 최적화의 이유도 약하다.)
- LLM이 싸진 지금, "무료=룰"은 원가가 강제하는 벽이 아니라 **페이월을 깨끗하게 하려는 설계 선택**이다. 무료에 LLM을 푸는 판단은 원가가 아니라 전환 전략으로 내린다(현재는 안 푼다).
- 무료의 "풍부함"은 개별 콘텐츠의 LLM이 아니라 **허브 breadth**(콘텐츠가 다 모인 것)가 책임진다.

## 3. 정체성 · IA

- **3탭 별마루 = 무료 전부의 집(구경형 허브)**. 하위에 공유형(결과 카드)·초대형(상대 걸어 완성) 바이럴 훅.
- **2탭 별콩 운세 = 유료 리포트 상점**. 무료(daily·tarot_daily·MBTI·별자리)는 별마루로 이사 → 2탭은 유료 전용으로 정체성이 선명해진다.
- 하단탭 5개 유지. 결과: **2탭=사는 곳(유료) / 3탭=노는 곳(무료)**.

## 4. 홈 구조 (안 A — 구경형 그리드)

```
┌─ 별마루 ──────────────────────────┐
│ 오늘 甲子 · 출석            ← 슬림 스트립(허브 공통)  │
├───────────────────────────────────┤
│ 오늘 (데일리 라이브)                          │
│  ┌─────────────────────────┐              │
│  │🗓 오늘 사주   등급 한 줄            │ ← 와이드 히어로 │
│  │  ● ● ○ ● ● ○ ●  이번주 미니 캘린더  │              │
│  │  더보기 → 30일·하루 상세·우리 오늘 │              │
│  └─────────────────────────┘              │
│  ┌────────┐                               │
│  │🃏 오늘 타로│ 한 장 뽑기                        │
│  └────────┘                               │
│ 둘러보기 (정체성 진입)                          │
│  ┌────┐ ┌────┐ ┌────┐                      │
│  │MBTI│ │별자리 │ │우리오늘│                     │
│  └────┘ └────┘ └────┘                      │
├───────────────────────────────────┤
│ [낙수 배너] → 타로톡 / 유료 리포트                 │
└───────────────────────────────────┘
```

- **카드 두 묶음**:
  - `데일리 라이브`(오늘 사주·오늘 타로): 카드 얼굴에 오늘 상태가 살아있음(오늘 타로=오늘 뽑기, 오늘 사주=오늘 등급). 매일 오는 이유(리텐션).
  - `정체성 진입`(MBTI·별자리·우리 오늘): 지금처럼 카드 목록에서 진입. 한 번 하는 것.
- **캘린더의 집 = 오늘 사주 와이드 히어로 카드.** 홈엔 **이번 주 미니 프리뷰**(7일 점)만 보이고, 탭하면 이미 지어진 **30일 그리드 + 하루 상세 + 주차 요약 + 우리 오늘 토글**로 펼쳐진다. (목업 비교 결과 채택 = A안. 대안 B[완전 숨김]·C[상단 항상 펼침] 기각 — B는 캘린더가 묻히고, C는 구경 허브가 캘린더 앱으로 기울어 A 취지와 충돌.)

## 5. 콘텐츠별 무료/유료 선

| 콘텐츠 | 무료 (룰·정적, ₩0) | 유료 구독 (LLM + 30일) | 바이럴 |
|---|---|---|---|
| 🗓 오늘 사주 | 30일 등급 캘린더 + **~400~500자 구조 정적**(전반+애정+일·돈+조언) | **`/fortune/daily` 리포트 재사용**(5섹션 ~2,100자) + 30일 어느 날이든 | (리텐션) |
| 🃏 오늘 타로 | 하루 1장 + **~300~400자 구조 정적**(카드 메시지+오늘 적용+조언) + 키워드 | **리포트급 리치 해석**(카드×사주×일진, 신규 형식) | 공유형 |
| 💞 우리 오늘 | 상대 등록 + **오늘 둘 사이 룰 판정**(톤·끌림·결속·리드 + 정적 한 줄) | LLM 서술 + **30일 우리 캘린더** | 초대형 |
| 🧭 MBTI | 룰 결과 전부 | — (이미 완결) | 공유형 |
| ✨ 별자리 지도 | 룰 지도 전부 | — | 초대형 |

- 🔴 **콘텐츠 depth 재조정 (2026-09-07, 사용자):** 무료 = 유료의 **진짜 20~30% taste**(1~2문장이 아니라 리포트 축소 구조를 정적으로). 근거 = "2줄은 2,100자 리포트의 3%지 20~30%가 아니다".
  - **유료 오늘 사주 = 기존 `/fortune/daily` 리포트 생성기+렌더러 재사용** — 그게 '오늘의 운세 현재 상품 수준'이고 Phase 2에서 어차피 흡수. 현 warm 3~4문단 nano 서술은 대체.
  - **유료 오늘 타로 = 신규 리포트 형식** 저작(재사용할 기존 tarot 리포트 없음. 카드×사주×일진 구조화).
  - **무료 = A(정적·₩0) 확정.** B(유저별 LLM·DAU 원가)·C(배치 캐시) 기각 — 별마루 무료는 바이럴 유입 허브라 **원가가 규모 무관 0**이어야. 무료 변주 = **축 점수 밴드(상/중/하)×톤×관계 조합**(개인화 아님, ⑥식 조합 정적 뱅크). 목표 분량 = 오늘 사주 ~400~500자 / 오늘 타로 ~300~400자.
  - **30일** = 유료가 아무 날이나 리포트 열람, **날짜별 생성+캐시**(오늘 항상·다른 날 탭 시 1회 생성 후 캐시, 재탭 ₩0).
- 우리 오늘 무료 개방 = **현재 완전 블러를 부분 개방으로.** 판정(`pair-day.ts`)은 이미 룰 100%라 무료로 열어도 ₩0. LLM(`pair-narrative`)과 30일 우리 캘린더만 유료로 남긴다.

## 6. 매출 2축

- **축1 — 구독(깊이+넓이).** 20별/30일(기존). 하나로 별마루 전체가 개인화(LLM)+30일로 열림. 값 제안: **"구독하면 그 사람과 나의 매일이 열리고, 별마루 전부가 딱 너 버전으로."** 페이월 무게추의 심장 = 우리 오늘(무료엔 없는 별개 기능 + 관측 수요 76% 정면) + 30일 breadth. 3일 무료 체험 유지.
- **축2 — 낙수.** 무료 결과 하단 맥락 CTA(MBTI→사주 유료 리포트 / 별자리→궁합·관계 / 오늘 사주·타로→고민이면 타로톡) + 별마루 하단 배너(기존 `CrossSellCard` 재배치). 낙수 목적지 = 2탭 유료 리포트 / 타로톡 상담.

## 7. 바이럴 3루프

최상위 = **허브 구경형**, 그 안에 공유형·초대형.

**Loop 1 — 허브 구경형(랜딩).**
- 🆕 **비로그인 구경 모드**: 로그인 안 해도 카드 그리드(뭐가 있는지 + 각 한 줄 소개)는 보이고, **탭하면 그때 로그인/생일 게이트**. 비로그인엔 개인화 0(일반 미리보기만). 이게 없으면 공유 링크가 로그인 벽에 부딪혀 루프가 끊긴다.
- 🆕 `/byeolmaru` 전용 OG("무료로 다 보는 곳") — 홈 다음가는 SEO/공유 착지점.

**Loop 2 — 공유형(결과 카드).**
- 각 무료 결과 = OG 카드로 공유, **탭하면 결과 死페이지가 아니라 별마루로 착지**.
- ✅ 이미 있음: MBTI OG · 별자리 지도 전용 OG · fortune 결과 OG.
- 🆕 신규: 오늘 타로(오늘 뽑은 카드 — 가장 punchy) · 오늘 사주(오늘 등급).
- 규칙 유지: `has_sensitive` → 공유·OG 403(기존 안전망).

**Loop 3 — 초대형(상대 걸어 완성).** → §8.

## 8. 우리 오늘 — 상대 추가 · 초대 · 관계 유형

**두 경로 = 관계 맥락으로 구분(생일 아냐/몰라가 아님).**

| 경로 | 문구 | 맥락 | 완성 | 바이럴 |
|---|---|---|---|---|
| ① **나 혼자 볼래**(직접 입력) | "생일 알아, 바로 볼래" | 짝사랑·재회·일방(76%) | 즉시 | 없음 |
| ② **같이 볼래**(초대) | "둘이 같이 볼래" | 커플·썸(상호) | 상대가 채우면 | 상대 유입 |

- **①이 무마찰 기본(주력).** 상대 추가 = 바로 생일 입력(기존, 이미 아는 사람 pick 포함) → 즉시 활성 카드. 오해·사고 0.
- **②는 작은 보조 문 + 명시 경고(A안).** 화면 한 켠에 작게 `상대에게 직접 물어볼래?` → 누르면 **"상대가 네가 본다는 걸 알게 돼. 보낼까?"** 확인 후에만 발송. → 짝사랑/헤어진 상대에게 실수로 초대가 가는 **감정적 사고를 원천 차단**(두 버튼 동급 제시 금지).
- **②의 데이터**: 초대 토큰 → "○○ 초대함 · 응답 대기" **pending 카드**(회색) → 상대가 링크로 자기 생일 채우면 활성 전환 + 알림. 상대 랜딩 = 자기 무료 오늘 사주 맛보기 동반(상대 유입 훅).
- 두 경로 모두 결국 같은 상대 레코드(`user_profiles` + `byeolmaru_watch`)로 수렴 — ②는 생일 채움만 상대에게 미룬 것. 판정·서술 로직은 하나로 공유, ②만 pending+토큰+상대 랜딩이 얹힌다(제일 무거운 조각 → 단계 뒤로).

**커플.**
- **최소 = 초대 수락 시 양방향 링크** → 둘 다 각자 계정에서 우리 오늘을 봄. 초대 데이터 모델에서 거의 공짜로 나온다.
- **커플 전용 기능(공유 노트·기념일·커플 스트릭·"둘 다 확인함"·알림) = 백로그.** 커플은 소수 경로(76% 일방)에 데이터가 아직 0 → 초대/커플 **사용률을 보고** 투자 결정.

**관계 유형(신규 캡처, 기존 enum 재사용).**
- 정본 = `lib/relationship/types.ts` `RelationshipStatus` = `crush`(썸 타는 중)·`dating`(연애 중)·`onesided`(짝사랑)·`breakup`(헤어진 사이). 라벨·`DOLL_COLORS`(관계별 색)까지 존재. 새 enum 만들지 않는다.
- **캡처**: 상대 추가 시 관계 칩 선택(시뮬 `SituationSelect`이 이미 이 칩 사용). 저장 = `byeolmaru_watch.status`(관계 스레드 테이블 baggage는 안 끌어옴).
- **쓰이는 곳 3**: ①판정·서술 tone(`pair-day` 룰 + `pair-narrative` LLM에 상태 주입 → "짝사랑의 오늘 ≠ 연애 중의 오늘") ②혼자/같이 볼래 기본값(`onesided`·`breakup`→혼자 / `dating`·`crush`→같이 문 노출, 단 안전상 혼자가 여전히 기본) ③인형 색(`DOLL_COLORS`).

## 10. 단계 분해

**이미 있음(별마루 ①~⑦, dev):** 캘린더 · 우리 오늘(유료) · 구독 · 오늘의 카드 · 정적 뱅크 · 캐릭터 12종 · 계측 · 출석 · 크로스셀.

**신규 — 순서(레버리지/비용 순):**

- **Phase 1 — 홈 재편 + 우리 오늘 무료 개방 (뼈대).** 홈 A 레이아웃(데일리 라이브 + 정체성 카드) · 오늘 사주 히어로(이번주 미니 캘린더 + 탭→기존 30일) · **우리 오늘 무료 룰 개방**(완전 블러 → 부분: 룰 무료/LLM·30일 유료) · 오늘 사주 유료 서술을 선택 날짜(30일 중 어느 날이든)로 확장 · 오늘 타로 정적 뱅크 두껍게 · 낙수 배너 재배치.
- **Phase 2 — 무료상품 이사 + 2탭 정리 (IA).** MBTI·별자리를 별마루 정체성 카드로 진입 · 2탭 유료 전용화(무료 daily·tarot_daily 제거) · `/fortune/daily`(유저별 LLM) 폐지 → 별마루 룰 버전이 대체(DAU 원가 소멸).
- **Phase 3 — 비로그인 구경 모드 + 공유 (구경형·공유형).** 비로그인 구경 모드(그리드 미리보기 + 탭 게이트) · `/byeolmaru` OG · 기존 공유 OG를 허브로 착지 배선 + 오늘 타로/사주 공유 신규.
- **Phase 4 — 초대(A안) + 관계 유형 (초대형).** 관계 유형 캡처(`watch.status`) · 혼자/같이 볼래 분기(직접 기본 + 초대 보조+경고) · 초대 플로우(토큰·pending·상대 랜딩·양방향 링크). 제일 무거움 → 마지막.

**백로그:** 커플 전용 기능(공유 노트·기념일·스트릭·알림) — 초대/커플 사용률 관문 통과 후.

각 Phase는 독립 배포 가능. Phase별로 자체 plan → 구현 사이클을 돈다.

## 11. 리스크 · 미검증

1. **페이월 균일 리스크.** 무료가 룰로 꽤 괜찮으면 "이 정도면 됐지"로 구독을 안 살 수 있다(구독이 전부 "LLM 서술 업그레이드"로 균일해짐). 완화 = 유료에 깊이(LLM)+넓이(30일)를 같이 싣고, 우리 오늘(초대·커플)이 견인, 3일 체험으로 체감. **n=1이라 충분한지는 노출 후 측정으로만 안다.**
2. **낙수 전환이 역사적으로 약했다**(회수 19~22%, 인챗 업셀 거의 안 먹힘). 축2에 매출을 의존하는데 검증 필요. 계측으로 낙수 클릭→결제를 추적.
3. **커플/초대 수요 미검증**(76% 일방). Phase 4(초대)가 제일 무거운데 소수일 수 있음 → **사용률 관문**을 두고, 안 쓰면 커플 전용은 짓지 않는다.
4. **초대 사고 리스크**(짝사랑 상대에게 실수 발송) → A안 명시 경고·직접 기본으로 완화(설계에 내장).
5. **비로그인 구경 모드 개인정보.** 비로그인엔 개인화 0(일반 미리보기만) — 누구의 사주도 계산하지 않는다.
