# 설문 "너무 공감한다" 재판독 — 진짜 불만은 공감량이 아니다 (2026-09-12)

## 결론 3줄
1. **공감의 "양"은 문제가 아니다.** 공감 문장 비율은 코호트 내내 14~15% 로 사실상 불변이고,
   오히려 도입부 정서 문장은 17.4%→8.8% 로 **줄었다**. 설문 28건 중 따뜻함·공감을 **장점으로**
   명시한 응답이 **13건(46%)**, 공감 자체를 단점으로 지목한 응답은 **사실상 0건**.
2. 불만 4건의 실제 내용은 공감 과잉이 아니라 **입장 없음 + 유저 따라가기**다.
   → "너무 내가 말하는대로 따라오는거같아서 **신뢰성이 약간 떨어져**"(290fd1ca)
   → "우리 둘이 얘기한 걸 **그대로 말해주는 거** 같아서"(135868af)
   → "공감을 잘해줘서 좋았지만 **조금 더 솔직하게**"(4db38967)
   → "**아리송해서** 알기 힘들어 / 설명이 정확친 않아서"(9ed2b65f)
3. 원인은 모델이 아니라 **프롬프트**다. 2026-08-14 코호트 경계에서 헤지가 2.2배 뛰었고
   그대로 유지된다. **luna 전환(08-31)은 이 지표를 전혀 움직이지 않았다.**

## 기제 — 코어가 직접 지시하고 있다

### ① §6 의 ✅ 모범 예문이 곧 불만의 구문
```
✅ "내가 보기엔 완전히 닫힌 결은 아니야 — 아직 열린 쪽이야. … 확정까진 두 사람이 만들어가는 몫이지만."
```
이 "완전히 ~건 아니야" 꼴이 코퍼스에 152회, "닫힌 건 아니야" 134회.
**"~라기보다 … ~에 가까워"** 는 1,406회(라기보다 565 + 에 가까워 841).

이 구문은 §1 의 헤지 규정("~일 수도", "확정까진 네 몫이지만" — **응답당 1회**)에 **걸리지 않는다.**
판정처럼 들리는데 아무것도 확정하지 않고, **새 정보가 들어와도 "무엇에 더 가까운지"만 옮기면
무한히 재적합**된다. 규칙을 지키면서 규칙의 목적을 어기는 구멍이다.

### ② §3 이 "유저가 반박하면 즉시 판을 다시 읽어라"라고 지시한다
```
- 유저가 "아닌데?"라고 하면 즉시 유연 수정: "그렇구나 — 그럼 이 결은 ~쪽으로 읽히네."
```
관찰형 훅(성향 추측)용으로 쓴 문장인데, 모델이 이를 **사실·결과 판정에까지 일반화**한다.

### ③ 인식 한계를 말할 길이 봉쇄돼 있다
§6 "**회피 선언 금지**" + "한계는 꼬리에만, **대화당 1회**" + ❌예문
("언제 될지는 별콩이가 대답할 수 없는 부분이야")로 인해,
"그건 카드가 말해준 게 아니라 네가 말해준 거야"라고 말할 **licensed 표현이 없다**.

실측: 유저가 새 정보·반문을 던진 직후 1,027턴 중
- 소급 정합화("그 얘기 들으니 카드가 더 선명해져/판이 달라져") **133턴 = 13.0%**
- 인식 한계 선언 **31턴 = 3.0%**  → **4.3배**
- 직전 자기 발언 철회 **1턴 = 0.1%**

②+③ 이 합쳐지면 출구가 하나뿐이다 — **"카드가 원래 그걸 가리키고 있었어."**

- `856e1567`: "**듣고 싶은 대답을 해줘서** 마음이 가벼워졌어요" — 동조를 **효용으로** 받는 유저도 있다.
- 소급 정합화 턴의 다음 턴 유저 재발화율 **92.4% vs 90.8%(z=1.11, 유의하지 않음)**.
  → 동조는 **턴 단위 이탈을 만들지 않는다.** 손상은 그 대화 안이 아니라 **신뢰·재구매**에서 난다.

## 판단 (구현 아님 — 결정은 사용자)
"공감을 줄이고 직설을 넣는다"는 프레이밍은 **측정과 어긋난다.**
공감은 46% 가 값으로 지목한 자산이고 양도 늘지 않았다. 잘라내면 손실만 난다.

교정 대상은 공감이 아니라 **세 구문**이다:
1. **이중헤지 구문**("~라기보다 ~에 가까워", "완전히 ~건 아니야")을 §1 헤지 정원에 편입 —
   지금은 규정 밖이라 무제한이다. §6 의 ✅ 예문 자체를 교체해야 한다.
2. **§3 "즉시 유연 수정"의 적용 범위를 성향 훅으로 한정** — 사실·결과 판정에는 금지.
3. **인식 한계를 licensed 표현으로 신설** — "그건 카드가 아니라 네가 말해준 거야",
   "반지는 카드보다 관찰이 정확해"(실제 좋은 사례 `14ae4549`). 지금은 §6 회피 금지에 막혀 0%.
