# 별자리 인연도 순위 — 설계 (2026-08-17)

별자리에 "종합 인연도 점수 → 전체 순위 → 사람별 근거"를 더한다. 도령 '케미 나래비'(점수·순위 = 강력한 캡처/자랑 훅)를 별콩답게 — **무유불리·관계 중심·근거 투명**하게 — 재해석.

## 0. 배경

- 도령 귀인지도의 바이럴 엔진 = **케미 점수 + 잘 맞는 순 순위**("내 1등 귀인 누구?" 캡처). 강력하나 "유불리 랭킹"이라 낙인 축.
- 별콩 스펙(2026-08-15) §2는 "무점수·무랭킹"이었으나, 순위의 캡처 훅이 바이럴에 중요하다는 판단 → **순위를 넣되 축을 바꾼다**: 유불리가 아니라 **인연의 강렬함/특별함**.
- 이미 지도에 삼합 glow+점·케미 골드선으로 특별관계가 강조됨. 순위는 그걸 **"콕 집어 자랑"**으로 보완(지도=그물, 순위=1등 콕집기). 중복 아님.

## 1. 인연도 점수 공식 (lib, 순수)

`pairRelation`이 이미 계산하는 값(`element`, `heavenlyCombo`, `sixCombo`)과 삼합 소속으로 나(pivot) ↔ 상대 b의 인연도를 계산.

```
인연도(0~100, 정수):
  base (오행관계, 나 기준):
    생아 · 아생 (서로 주고받는 흐름) → 62
    극아 · 아극 (팽팽하게 맞물린 흐름) → 62   // 상극도 낙인 아님, "강렬한 인연"
    비화       (닮은 잔잔한 결)        → 50
  + 천간합(heavenlyCombo)            → +25   // 케미 스파크
  + 육합(sixCombo)                    → +15   // 결속
  + 삼합(나와 b가 같은 삼합 국 멤버)  → +15   // 같은 국
  = min(합계, 100)
```

- **상생·상극 동급(62)** = 유불리 없음(별콩 정체성). 비화만 소폭 낮음(잔잔).
- 특별관계는 별개 축이라 **가점**으로 얹혀 자연히 상위로 올라온다(사용자 직관 충족).
- **숫자 노출**: "인연도 87" 형태로 화면에 표시(사용자 요청).
- 정렬: 인연도 내림차순 → 동점 시 특별관계 수 많은 순 → `created_at`(안정 정렬).

**등급 톤**(숫자 옆, 무낙인):
- ≥85 "인연 진함" · 70–84 "도타운 사이" · 55–69 "이어진 사이" · <55 "잔잔한 사이"

## 2. 순위 UI — 별자리 지도 아래 "인연이 진한 순"

- 별자리 지도 + 범례 아래에 순위 리스트. pivot(나) 기준, 나 제외 **전원**(전체 순위).
- 각 행: `순위 · 이름(또는 "이 별") · 인연도 숫자 · 등급/한줄 요약`.
- 1위(또는 상위)는 살짝 강조(골드 톤). 하위도 "잔잔한 사이"로 무낙인.
- compat_visible 규칙 유지: 호스트 낀 관계는 항상, 게스트끼리는 양쪽 공개 시만 점수/순위 산정. (미공개는 순위에서 제외하거나 "비공개"로 표기 — 구현 시 결정)
- 행 탭 → 해당 인물 1:1 뷰(§3).

## 3. 사람별 근거 — 1:1 뷰(OneToOnePanel) 확장

기존 OneToOnePanel(오행 한 줄 + "내가 보는 그"/"그가 보는 나" 40칸 카피 + 케미/결속 뱃지)에 **"인연도 근거" 섹션** 추가:

- **인연도 숫자 + 등급** (예: "인연도 87 · 인연 진함")
- **근거 리스트** — 점수에 기여한 요소를 별콩이 톤으로:
  - 천간합 → "✨ 케미 스파크 — 유난히 끌리는 기운"
  - 육합 → "🔗 결속 — 단단히 묶인 사이"
  - 삼합 → "같은 국 — 함께면 시너지가 나"
  - 오행 → `elementRelationLabel`(기존): 생아 "나를 북돋아 주는 기운" 등
- **별콩이 한마디** — 종합 코멘트(등급별 톤): 진함 "이 별자리에서 유독 진하게 엮인 인연이야" / 잔잔 "잔잔하지만 분명히 이어진 사이야"

## 4. 카피 (신규)

- 특별관계 3종 근거 문구(천간합·육합·삼합) + 오행 기존(`ELEMENT_RELATION_LABEL`) 재사용
- 등급 톤 4종(진함/도타움/이어진/잔잔) + 등급별 별콩이 한마디
- 전부 무유불리·무낙인·별콩이 반말

## 5. 데이터 흐름

- **`lib/byeoljari/inyeon.ts`(신규)**: `inyeonScore(rel, isTriadShared): number`(0~100) + `inyeonGrade(score): {label, tone}` + `inyeonReasons(rel, isTriadShared): string[]`(근거 문구 배열) — 순수, 방어적. TDD.
- **API route**(`[shareId]/route.ts`): edge에 `inyeon`(점수) 추가. 삼합 공유 여부는 triads로 판정해 각 edge에 반영.
- **`ConstellationView`**: pivot 기준 edges에서 인연도 순위 계산(useMemo) → 순위 리스트 렌더 + 행 탭 시 기존 selectedId 흐름 재사용.
- **`OneToOnePanel`**: props에 인연도(점수·등급·근거) 추가 → "인연도 근거" 섹션 렌더.
