# 별자리(byeoljari) P3-2 형상 렌더 — 설계 (2026-08-16)

P3(별자리 렌더)의 마지막 조각. P3-1(넓게뷰·1:1·줌)·P3-3(관계필터·다인원)은 dev 완료. 이 스펙은 **P3-2 형상(신수) 렌더 코드**를 다룬다. **에셋(신수 15종 투명 PNG)은 이미 제작·추출 완료** (`public/byeoljari/creatures/`, 커밋 `80f8442`). 이 문서로 **다음 세션에서 writing-plans → subagent-driven 구현**.

> ⚠️ 개발은 이 세션이 아니라 **다음 세션**에서 진행(사용자 지시 2026-08-16). 이 문서 = 설계 확정본.

## 0. 입력 / 전제
- 데이터: P2 GET(`/api/fortune/byeoljari/[shareId]`)의 `nodes[]`(각 `element: 목|화|토|금|수`), `nodes.length`(인원).
- 에셋: `public/byeoljari/creatures/{wood|fire|earth|metal|water}-{1|2|3}.png` (오행 매핑 목=wood·화=fire·토=earth·금=metal·수=water, 단계 1/2/3). 전부 배경 투명·정면·둥근 chibi.
- 형상 = **관계망 우선 + 형상 은은 배경** 확정(상위 §2). 별은 관계 기반 배치, **형상 윤곽 path에 별 안 얹음**(윤곽 path 데이터 불필요).

## 1. 사용자 확정 결정 (2026-08-16 브레인스토밍)
1. **엠블럼 위치 = 상단 헤더** — 별자리 위에 "우리 별자리 · [신수 이름]" + 또렷한 엠블럼 이미지.
2. **은은한 배경 레이어 = 사용(opacity ~10%)** — 형상을 별자리 뒤에 아주 연하게.
3. **성장 연출 = 둘 다** — 평소 진행 힌트 + 임계 넘는 순간 리빌 축하.
4. **단계 매핑 = 1~4명: 1단계(소동물) / 5~14명: 2단계(중간) / 15명+: 3단계(신수).** 임계 = 5·15.

## 2. 순수 로직 — `lib/byeoljari/shape.ts` (신규, TDD)
전부 순수 함수·방어적(범위 밖 값 폴백). 단위 테스트 대상.

```ts
import type { FiveElement } from "@/lib/saju/elements";
import type { GraphNode } from "./types";

// 오행 → 에셋 파일 코드
export const ELEMENT_CODE: Record<FiveElement, string> = {
  목: "wood", 화: "fire", 토: "earth", 금: "metal", 수: "water",
};

// 15 신수 이름 [1단계, 2단계, 3단계]
export const SHAPE_NAME: Record<FiveElement, [string, string, string]> = {
  목: ["청개구리", "이무기", "청룡"],
  화: ["반딧불이", "불새", "봉황"],
  토: ["옥토끼", "사슴", "기린"],
  금: ["흰담비", "눈표범", "백호"],
  수: ["물고기", "가오리", "거북이"],
};

const ELEMENT_ORDER: FiveElement[] = ["목", "화", "토", "금", "수"];

/** 최빈 오행. 동률이면 호스트 오행 우선, 그다음 고정순서(목화토금수). */
export function dominantElement(nodes: GraphNode[]): FiveElement | null {
  if (nodes.length === 0) return null;
  const count = new Map<string, number>();
  for (const n of nodes) count.set(n.element, (count.get(n.element) ?? 0) + 1);
  const host = nodes.find((n) => n.isHost);
  let best: FiveElement = ELEMENT_ORDER[0];
  let bestC = -1;
  for (const e of ELEMENT_ORDER) {
    const c = count.get(e) ?? 0;
    if (c > bestC) { best = e; bestC = c; }
  }
  // 동률 중 호스트 오행이 있으면 그것 우선
  if (host && (count.get(host.element) ?? 0) === bestC) return host.element;
  return best;
}

/** 인원 → 진화 단계. 1~4:1 · 5~14:2 · 15+:3. */
export function evolutionStage(count: number): 1 | 2 | 3 {
  if (count < 5) return 1;
  if (count < 15) return 2;
  return 3;
}

export interface ShapeInfo {
  element: FiveElement;
  stage: 1 | 2 | 3;
  assetSrc: string;      // /byeoljari/creatures/wood-3.png
  name: string;          // 현재 형상 이름
  nextName: string | null;   // 다음 단계 형상 이름(있으면)
  membersToNext: number | null; // 다음 단계까지 남은 인원(있으면)
}

/** 노드 집합 → 형상 정보(엠블럼·배경·힌트가 소비). */
export function resolveShape(nodes: GraphNode[]): ShapeInfo | null {
  const element = dominantElement(nodes);
  if (!element) return null;
  const stage = evolutionStage(nodes.length);
  const names = SHAPE_NAME[element];
  const THRESH = [5, 15]; // stage1→2, stage2→3
  let nextName: string | null = null;
  let membersToNext: number | null = null;
  if (stage < 3) {
    nextName = names[stage]; // 다음 단계 이름(0-index: stage(1)→names[1]=2단계)
    membersToNext = THRESH[stage - 1] - nodes.length;
  }
  return {
    element, stage,
    assetSrc: `/byeoljari/creatures/${ELEMENT_CODE[element]}-${stage}.png`,
    name: names[stage - 1],
    nextName, membersToNext,
  };
}
```
- 테스트: dominantElement(최빈·동률 호스트우선·빈입력 null) · evolutionStage(4→1,5→2,14→2,15→3) · resolveShape(assetSrc·name·nextName·membersToNext, 15+는 next null).

## 3. 렌더 — `components/byeoljari/*` 수정
### 3-1. 상단 헤더 (ConstellationView 상단)
- `resolveShape(graph.nodes)` → 엠블럼 이미지(`next/image` 또는 `<img>`, ~56–64px) + 텍스트 "우리 별자리 · {name}".
- 헤더는 별자리 정사각 **위**(기존 `<h1>우리 별자리</h1>` 자리를 엠블럼+이름으로 대체/보강).

### 3-2. 은은한 배경 레이어 (ConstellationCanvas 내부)
- 밤하늘 `<rect>` **위**, 삼합/관계선/노드 **아래**에 `<image href={assetSrc} .../>`.
- 정사각 중앙, 크게(예 viewBox 기준 60×60 중앙 배치), **opacity ~0.1**. `preserveAspectRatio="xMidYMid meet"`.
- 🔴 **줌 transform과 무관하게 고정**(ambient 배경 — transform `<g>` 밖에 둠). 노드/선만 줌.
- ⚠️ **water-3(거북이)는 ~0.9배 축소**(다른 신수 대비 커서). shape.element==='수' && stage===3 이면 배경·엠블럼 크기 살짝 down.
- Canvas는 `shapeSrc`(assetSrc) prop을 새로 받음(없으면 배경 생략 = 폴백 §12 그대로).

### 3-3. 진행 힌트 (별자리 아래)
- `membersToNext` 있으면: "✨ {membersToNext}명 더 오면 {nextName}(으)로 진화!" 
- stage===3: "✨ {name} 완성!" (또는 생략).

### 3-4. 성장 리빌 축하 (둘 다의 "리빌" 부분)
- localStorage `byeoljari:seenStage:{shareId}` = 마지막으로 본 stage.
- [shareId] 페이지 로드(그래프 ready) 시: 현재 stage > seenStage(없으면 0) 면 **축하 오버레이 1회** 표시(신수 이미지 크게 + "{name}(으)로 진화했어!" + `animate-fade-in`), 닫으면 seenStage=현재 stage 저장.
- 이 방식이면 **내가 참여해 임계 넘든, 남이 채워 넘든** 다음 방문에 리빌됨(서버 상태 추적 불필요). 첫 생성자는 seenStage 없음 → 첫 형상도 리빌(원하면 stage 1은 리빌 생략 가능 — 구현 시 택).
